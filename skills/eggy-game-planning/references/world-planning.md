# 世界版地图策划分支

只在地图已确认是世界版后读取。世界版与原点版并行且不互通；本分支围绕统一持续世界、随进随出、更大场景、更多玩家共同互动，以及更即时的射击和动作体验展开。不得把原点版“每位玩家重演同一场游戏”的回合思维当作默认前提。

定位依据来自本地官方资料：`世界编辑器文档-md/快速上手/新手必读`。世界版仍可能更新，具体人数、持续时长、平台服务和规则能力使用前按当前资料查证，不从定位描述外推数值上限。

## 一、世界生命周期

- 这个世界在玩家进入前已经发生了什么，第一名和后加入玩家看到的状态是否相同。
- 世界中的哪些变化持续保留，哪些按事件、区域、房间或条件重置。
- 没有玩家时世界是否继续推进；无法从当前资料确认时标记为能力待查证。
- 地图是长期持续世界、世界内局部回合，还是定期重置的公共世界。
- 公共事件开始和结束时，未参与、刚加入或中途离开的玩家看到什么。

先讲清世界生命周期，再设计依赖时间、公共资源或长期进度的系统。

## 二、玩家加入、离开与状态归属

- 玩家每次加入从哪里出现，如何找到正在发生的主要玩法。
- 后加入玩家从零开始、继承个人进度，还是接入当前世界阶段。
- 玩家离开、掉线、重进时，个人任务、队伍关系、占用对象和交易如何处理。
- 每项状态属于个人、队伍、区域还是整个世界，谁能改变，谁能看见。
- 提示、奖励、音效和界面发给操作者、参与者、附近玩家还是全体玩家。

至少检查一个“中途加入”场景和一个“离开后留下世界状态”的场景。

## 三、大场景与多人密度

- 大场景为什么必须大，各区域分别承载什么玩法，而不是单纯扩大面积。
- 玩家如何移动、传送、寻找目标和返回主要活动区。
- 玩家分散后如何知道哪里有事件、队友、敌人、资源或交易机会。
- 热门区域拥挤和偏远区域无人时，玩法是否仍能运转。
- 区域之间共享哪些世界状态，哪些只影响本区域玩家。

## 四、即时动作、射击与对抗

- 操作精度和即时反馈在核心循环中解决什么体验问题。
- 攻击、命中、受伤、击倒、复活和脱离战斗分别给谁反馈。
- 多人争夺同一目标时，归属、助攻、奖励和失败如何判定。
- 玩家数量变化后，敌人强度、目标数量、队伍平衡和活动难度是否调整。
- 安全区、出生保护、恶意阻挡、重复击杀和挂机怎样处理。

不是射击或动作玩法时跳过本节，不为了使用世界版强行增加战斗。

## 五、公共资源、事件与长期进度

- 公共资源被拿走、占用、破坏或生产后，其他玩家还能做什么。
- 同时操作同一商店、设备、任务目标或世界事件时如何处理。
- 公共事件奖励按个人贡献、队伍参与、最后一击还是全体发放。
- 个人成长、世界成长和服务器内临时进度怎样区分。
- 世界重置或玩家跨次进入后，哪些经济、任务和收集进度保留。
- 重复领取、刷取、交易冲突和后来者追赶机制怎样处理。

## 六、世界版完整性门禁

正式策划前确认：

1. 世界生命周期、公共状态和重置条件已经讲清。
2. 中途加入、离开、掉线和重进都有明确玩家体验。
3. 个人、队伍、区域和全世界状态归属不混淆，反馈接收者明确。
4. 大场景的导航、玩家密度和区域运转方式完整。
5. 公共资源、同时操作、奖励归属和恶意行为有处理规则。
6. 玩法没有依赖原点版全员同步回合或每位玩家重演同一过程的默认假设。

有任一关键项待确认时，从本分支和共用入口的当前前沿选择两个互不依赖的问题继续。
