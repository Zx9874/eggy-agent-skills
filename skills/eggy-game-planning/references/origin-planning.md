# 原点版地图策划分支

只在地图已确认是原点版后读取。原点版与世界版并行且不互通；本分支围绕真实物理、丰富机关、公平与同步一致，以及每位玩家重演同一场游戏的创作思维展开。不得把世界版的持续统一世界和随进随出当作默认前提。

定位依据来自本地官方资料：`蛋仔编辑器文档（原点版）` 与世界版 `快速上手/新手必读` 中的版本对比。定位可以指导策划取舍，具体人数、规则和能力仍按当前编辑器资料查证。

## 一、游戏组织方式

- 玩家是否一起进入完整回合，开始条件是什么。
- 所有人是否经历相同阶段、机关变化、倒计时和结算节点。
- 中途加入、离开或重进时，是旁观、进入下一局还是按当前规则继续。
- 回合结束后哪些场景、机关、分数和玩家状态必须重置。
- 平局、无人完成、全员淘汰或只剩一人时怎样结算。

回合结构尚未确认前，不展开依赖具体阶段的奖励和界面问题。

## 二、物理与机关体验

- 核心乐趣是否依赖碰撞、受力、推动、弹射、载具、运动器或连锁机关。
- 同一机关被多名玩家同时触发时，玩家应看到相同结果还是只影响触发者。
- 可移动物体离开位置、卡住、掉出场景或被反复操作后如何复位。
- 机关失败是淘汰、扣除资源、回到检查点还是允许原地重试。
- 物理偶然性会增加乐趣还是破坏公平，哪些关键结果必须稳定一致。

不要只问机关“有没有”，必须把玩家操作、物理反馈、失败恢复和复位规则问清。

## 三、同步公平与多人冲突

- 哪些结果必须对所有玩家一致，例如机关状态、名次、计分、胜负和公共目标。
- 两人同时到达终点、拾取同一物品或触发同一开关时如何判定。
- 玩家碰撞、阻挡、推挤和道具干扰是玩法的一部分还是需要限制。
- 单人状态、队伍状态和全局状态分别有哪些，谁能改变它们。
- 反馈是只发给操作者、相关玩家还是全体参与者。

至少检查一个“同时触发”场景和一个“结果必须一致”的场景。

## 四、关卡与节奏

- 关卡是线性推进、分支路线、循环赛制还是多轮淘汰。
- 检查点、复活点、淘汰区和安全区怎样影响节奏。
- 领先者和落后者分别在做什么，是否存在长时间等待。
- 难度来自操作精度、物理判断、路线选择、对抗还是团队配合。
- 下一局如何产生变化，避免每轮只是完全相同的重演。

## 五、原点版完整性门禁

正式策划前确认：

1. 回合开始、阶段推进、结束、结算和重置完整闭合。
2. 核心物理或机关的触发、反馈、失败和复位规则明确。
3. 关键公共结果如何保持一致，玩家同时操作如何判定。
4. 中途加入离开、重进、淘汰、复活和平局都有玩家可见结果。
5. 玩法没有依赖世界版持续世界、更多玩家或随进随出的默认假设。

有任一关键项待确认时，从本分支和共用入口的当前前沿选择两个互不依赖的问题继续。
