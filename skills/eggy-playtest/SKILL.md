# 单批次试玩

## 开始前

1. 确认地图工程、原点版或世界版、运行位置和本次验收清单。
2. 记录运行日志当前长度、最后修改时间或备份一份基线。
3. 加载编辑器命令行技能，确认工具存在并动态连接；不得写死端口。
4. 只执行已经在当前工程定义和官方资料中查证的编辑器命令。

## 执行边界

- 一次用户请求只进行一个试玩批次：开始、等待必要时间、读取本次日志、按需截图、停止。
- 不自动执行“发现错误、改代码、再试玩”的循环。
- 不使用保护性调用吞掉命令失败；命令失败要如实报告。
- 用户需要亲自操作的玩法，代理只负责启动和收集证据，不假装已经完成操作。

## 结果

把结果分为：已观察通过、失败、未覆盖、待用户操作、待用户确认。

发现报错时加载日志技能，先用大白话解释最早根因并停止。没有报错也只能证明本次日志未发现错误，不能替代玩法验收。
