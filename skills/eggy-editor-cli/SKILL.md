# 编辑器命令行流程

## 工具与连接

工具从当前用户目录动态定位：

```powershell
$CLI = Join-Path ([Environment]::GetFolderPath('UserProfile')) '.eggitor\cli\editor-cli.exe'
```

如果工具不存在，提示用户启动或更新蛋仔编辑器，不手动创建官方目录。连接信息由编辑器动态维护；先直接调用工具，连接失败再检查编辑器是否启动，不写死端口。

## 执行门禁

1. 明确命令运行在编辑期还是试玩期。
2. 在当前编辑器接口定义中找到完整签名。
3. 查官方手册确认参数语义、运行前提和失败表现。
4. 没有证据的命令、参数、节点属性和默认值不得试猜。
5. 删除、覆盖、移动或批量操作先备份并取得用户确认。

## 输出要求

- 每次调用只做一个清晰动作，保留原始退出状态和必要输出。
- 不使用吞错包装把失败伪装成成功。
- 试玩日志只读取本批次新增部分。
- 截图只能证明画面状态，不能单独证明交互和多人行为正确。
- 发现运行报错时停止自动操作，加载日志技能并先向用户解释。

编辑器命令成功只代表命令被接受；资产保存、玩法效果和多人同步仍需实际检查。
