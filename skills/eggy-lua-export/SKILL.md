# 蛋码导出函数保护

## 外部契约

蛋码和插件可以按函数名调用 Lua 函数，调用位置可能完全不出现在 Lua 文件中。因此“没有代码引用”不能证明函数没用。

导出函数的文件路径、导出注解、描述与参数注解、函数名、参数数量、顺序、类型、返回值，以及紧邻导出块的注释和空行，都按绑定敏感区域处理。

## 修改前扫描

对每个目标文件或目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<总工作区根>\.eggy-agent\scripts\export-contract-audit.ps1" -ProjectPath "<地图工程>" -Target "<目标>" -FailOnExport
```

目录操作必须递归扫描整个目录。扫描命中导出注解、插件导出注解或残缺注解时，立即停止并列出函数名、文件、当前参数、返回值、拟议变化和可视化侧影响。

## 新建或修改导出函数

1. 从当前官方资料确认注解格式、支持类型、参数和返回值限制。
2. 向用户确认蛋码侧变量名称、类型、顺序和调用时机。
3. 无必要不得进行中文和英文名称互改。
4. 确需删除、改名、移动或改变签名时，取得用户对具体函数和具体变化的明确确认。
5. 新函数在首次绑定前一次写全用途、参数和返回值说明；已经绑定的旧导出块不要为了补注释而触碰。

## 修改后

再次扫描整个受影响文件，并逐行检查版本差异。任何未经确认消失或变化的函数名、注解、签名、路径或敏感区内容都视为失败。

无法查看蛋码可视化配置时，只能标记“待用户确认重绑”，不得报告完成。
