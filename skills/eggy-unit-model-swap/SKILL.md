# 世界版场景单位修改

本技能只处理世界版编辑器场景内容，不处理原点版运行 Lua，也不修改官方生成技能或数据映射。

## 先冻结范围

1. 用工程配置确认世界版和当前编辑器实例；版本冲突或目标地图不明确时停止。
2. 明确用户要改的字段：根位置、旋转、缩放、渲染网格、物理网格、外观字段或物理类型。未获授权的字段保持不变。
3. 通过当前编辑器定义、官方资料和命令行帮助确认查询与写入接口；历史地图编号、属性名和枚举值只作搜索线索。
4. 建立目标清单，记录稳定身份、名称、类型、父级、预计数量、原值和排除项。名称重复时不能只取第一项。

## 修改分支

- **根级布局**：只移动已验证的根单位；先确认子级会随根正确移动，不再重复移动子级。
- **外观或网格**：只写冻结的外观、渲染网格或物理网格字段；网格替换成功不代表完整预设、组件和自定义属性都被替换。
- **物理类型**：只写当前版本、当前单位类型的物理类型枚举；不顺手改变重力、碰撞、活动状态或变换。
- **完整预设**：必须作为独立候选重新查证和试点，不能由单项网格成功推断完整同步安全。

## 执行节奏

- 只读盘点可以一次取得有界结果；写入先处理一个代表性对象并立即读回。
- 试点不符合目标时恢复原值并停止，不靠扩大数量掩盖问题。
- 试点通过后再按稳定清单扩大；每批写入后重新读取目标属性，遇到超时、响应异常或数量变化立即停止。
- 场景修改不受 Lua Git 提交保护，批量前只需为本批保存可恢复的对象身份、原值、目标值和处理顺序；不按单位重复复制备份，也不复制整张地图。

## 收尾

重新枚举目标并核对数量、字段、排除项和未授权属性；新确认的正式实例、预设和节点写入资产清单。未经过用户编辑器确认的结果保持待用户确认，不启动试玩来替代场景验收。
