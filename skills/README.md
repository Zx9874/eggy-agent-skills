# 蛋仔公开技能

本目录是技能源码目录。可安装技能、适用任务域、原点版/世界版范围、默认级别和宿主支持以仓库根目录 [`skill-catalog.json`](../skill-catalog.json) 为准，不在这里维护第二份技能数量清单。

代理按任务触发技能，安装器只把选定档案复制到宿主发现目录。技能的参考资料放在对应技能的 `references/` 下，只有遇到该技能的具体问题才按需读取。

地图运行技能与辅助工具技能的边界必须保持：地图规则不能扩散到普通工具项目；`eggy-ponytail`（极简开发）和 `eggy-api-research`（接口研究）可在两类任务中按模式使用。
