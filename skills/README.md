# 蛋仔地图公开技能包

本目录包含十一项按需加载的技能。代理处理相关任务时才读取对应技能正文，不会在每个新会话中一次读取全部内容。

| 技能 | 用途 |
|---|---|
| `eggy-lua-coding` | 代码新增、修改、修复、审查和接口查证 |
| `eggy-design` | 只记录玩家实际体验到的玩法需求 |
| `eggy-dev-plan` | 用户原话、任务、验收标准、进度和待办 |
| `eggy-kb` | 已验证接口、编辑器规则和数值边界的沉淀 |
| `eggy-log-triage` | 日志等级、报错分析和开发批次记录 |
| `eggy-playtest` | 单次试玩过程和本轮日志读取 |
| `eggy-qa` | 新功能与原有功能的测试检查 |
| `eggy-lua-export` | 蛋码按名称调用函数的契约保护 |
| `eggy-custom-event` | Lua 与蛋码之间的事件和参数传递 |
| `eggy-preset-io` | 预设导入、导出、备份和资产登记 |
| `eggy-editor-cli` | 编辑器连接、试玩控制、日志和截图读取 |

公开版不打包官方手册、官方生成技能、具体地图代码或旧知识库。接口和编辑器行为必须回到用户当前工程与官方资料重新查证。
