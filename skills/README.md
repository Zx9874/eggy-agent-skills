# 蛋仔地图公开技能包

本目录包含十一项按需加载的技能。代理平时只看到技能名称和用途，处理相关任务时才加载正文，因此不会在每个新会话里一次塞入整套手册。

| 技能 | 用途 |
|---|---|
| `eggy-lua-coding` | 原点版与世界版代码开发总流程及接口门禁 |
| `eggy-design` | 玩法需求与用户原话 |
| `eggy-dev-plan` | 唯一开发计划与状态管理 |
| `eggy-kb` | 可靠知识沉淀 |
| `eggy-log-triage` | 日志等级、报错解释与开发日志 |
| `eggy-playtest` | 单批次试玩 |
| `eggy-qa` | 功能与多人回归测试 |
| `eggy-lua-export` | 蛋码导出函数保护 |
| `eggy-custom-event` | Lua 与蛋码事件协议 |
| `eggy-preset-io` | 预设导入导出 |
| `eggy-editor-cli` | 编辑器命令行操作 |

公开版不打包官方手册、官方生成技能、具体地图代码或旧知识库。接口和编辑器行为必须回到用户当前工程与官方资料重新查证。
