# 预设导入导出

## 边界

- 仅在用户明确要求处理预设时使用。
- 使用当前用户目录中的编辑器命令行工具和动态连接，不使用工程旧工具路径或固定端口。
- 每个导入、导出、查询和删除接口都先在当前编辑器定义和官方资料中查证。
- 不批量猜测预设编号、保存位置、覆盖规则或返回值。

## 流程

1. 记录源预设名称、编号、用途、来源地图和目标地图。
2. 确认操作是备份、迁移、复制变体还是覆盖；覆盖和删除必须让用户明确确认。
3. 为当前工程建立版本恢复点，并备份相关文件或编辑器资产。
4. 先处理一个预设，读取真实返回结果并让用户在编辑器确认。
5. 确认后再逐个继续，禁止一次性批量执行未验证命令。
6. 把最终编号、名称、用途、重要参数和验证状态写入资产清单。

命令失败时如实报告，不用保护性调用掩盖。编辑器显示成功但用户尚未检查时，状态写“待用户确认”。
