# 蛋仔可靠知识库

这里保存经过证据分级的跨地图知识。它不是聊天记录仓库，也不是把官方手册全文复制一份。

## 证据等级

| 等级 | 可以怎么用 |
|---|---|
| 官方定义 | 证明接口名称、签名和所属对象存在 |
| 官方手册 | 解释参数含义、限制和运行位置 |
| 官方示例 | 证明典型组合方式 |
| 受控测试 | 证明当前版本的实际行为或边界 |
| 项目观察 | 只对当前地图有效，不能直接外推 |
| 旧知识线索 | 只能帮助搜索，必须重新查证 |

## 推荐目录

```text
可靠知识库/

├─ 原点版/

│  ├─ 编辑器规则.md
│  ├─ 数值边界.md
│  └─ 错误经验.md
├─ 世界版/
│  ├─ 接口用法.md
│  ├─ 编辑器规则.md
│  ├─ 数值边界.md
│  └─ 错误经验.md
└─ 资料来源/
   └─ README.md
```

## 每条知识必须包含

- 标题和唯一编号。
- 原点版或世界版，以及可取得的编辑器版本。
- 适用范围和禁止外推范围。
- 提问原话与答复原话；缺少原问题时标记“范围待补充”。
- 来源文件或链接、行号、日期。
- 测试步骤、结果和失败表现。
- 状态：待查证、部分验证、已验证、已失效。
- 关联地图和开发计划编号，但不复制地图私有资产编号。

## 更新规则

普通新事实只更新一个对应主题。只有稳定、高频或犯错代价高，并经过复核的流程规则才升级到技能。发现资料冲突时保留双方证据并标记待确认，不静默选择。
