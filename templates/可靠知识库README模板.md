# 蛋仔可靠知识库

这里保存经过证据分级的跨地图知识。它不是聊天记录仓库，也不是公开官方手册镜像的替代品；手册原文应放在单独的资料来源目录，并按需查阅。

## 证据等级

| 等级 | 可以怎么用 |
|---|---|
| 官方定义 | 证明接口名称、签名和所属对象存在 |
| 官方手册 | 解释参数含义、限制和运行位置 |
| 官方示例 | 证明典型组合方式 |
| 受控测试 | 证明当前版本的实际行为或边界 |
| 项目观察 | 只对当前地图有效，不能直接外推 |
| 旧知识线索 | 只能帮助搜索，必须重新查证 |

## 每条知识保留什么

- 结论，以及原点版或世界版、运行位置、对象和适用范围。
- 来源位置、可取得的版本和验证日期。
- 最小核对或复现方法，以及仍未证明的边界。
- 状态沿用知识技能的“已确认、已观察、待复核、待验证、范围待补充、冲突待处理、已失效”。有替代结论时保留指针。

开发人员答复尽量保留问题和答复原文；官方手册条目直接引用来源，不硬造问答。测试观察才需要复现条件与结果，文档结论不伪造试玩。只在确实有关联时引用任务，不复制私人资产编号、完整接口定义或原始日志。

## 更新规则

每批次收尾只更新命中的主题和必要索引，同一结论补证据时更新原条目，不新建重复项。不预建空主题，也不全库重审。只有稳定、高频或犯错代价高，并经过复核的流程规则才升级到技能。发现资料冲突时保留双方证据并标记“冲突待处理”，不静默选择。
