# {{PROJECT_NAME}} 开发日志

每个有实际交付的批次写一条简短记录，便于回看效果和修改原因。任务载体保存需求与验收，资产清单保存编号，Git 保存代码差异；日志只引用它们，不再抄一份。

## 批次记录格式

### 日期与任务编号

- 效果变化：改前和改后有什么区别
- 关键原因：用户明确说明或已验证的原因，注明依据；未知时不编写
- 验证状态：已做的检查、观察到的结果和仍未验证的部分；未试玩就写“待试玩”
- 任务或提交引用：待填写

只有存在重要风险、外部绑定变更、未完成事项或无法由 Git 恢复的场景修改时才补一条说明。没有新资产、新知识等变化时不填“无”或“无新发现”。不记录每次保存、命令和测试尝试，也不把原始运行日志复制到这里。
