# 安装档案

仓库发布全部经过筛选的可复用技能，但安装器按任务域选择技能，避免无关技能进入代理的技能发现目录。

## 自动选择

- `map-origin`：已识别为原点版地图工程。
- `map-world`：已识别为世界版地图工程。
- `tooling`：目标是编辑器插件、命令行工具、转换器、技能或其他辅助工具。
- `common`：只需要极简实现或接口研究的公共能力。
- `full` 是发布清单的汇总分组，含互不兼容的任务域，不用于直接安装。需要更多能力时选择当前任务域并添加可选技能。

`skill-catalog.json` 是档案唯一清单。技能正文只在对应任务触发时读取，不能把所有参考资料复制进新会话。

## 版本边界

原点版和世界版使用同名公共技能时，技能内部仍必须按当前工程版本选择对应参考；世界版专属技能不会作为原点版默认技能安装。

## 宿主边界

Codex（代码代理）和 OpenCode（开放代码代理）默认使用 `.agents/skills`；ZCode（智谱代码代理）使用 `.zcode/skills`。仓库源码不维护三份技能正文。

全局安装只接受 `common` 或 `tooling` 及适用的工具可选技能，不登记地图。地图技能仍安装在地图外的总工作区。
