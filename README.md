# 蛋仔 Agent 技能包

给用 AI 写蛋仔地图的作者准备的一套技能，支持原点版、世界版，也能用于开发编辑器插件和辅助工具。

包含玩法策划、接口查证和项目文档维护等技能。你可以用中文描述想做的玩法，地图效果仍需要在编辑器里试玩确认。

[安装入口](START-HERE.md) · [更新日志](CHANGELOG.md) · [官方手册](docs/official/README.md)

## 解决什么问题

- 新会话按任务读取技能和资料，少重复加载整套手册。
- 从玩法想法逐步整理出策划，再记录需求、开发进度和资产编号，方便下次接着做。
- 编写 Lua 脚本前核对接口和参数。原点版与世界版分开处理，已绑定的函数名称不能随意改动。
- 测试优先围绕当前问题做小范围验证。没有你的要求，不启动编辑器或试玩。
- 检查玩家操作后能否感知结果。已有场景或界面反馈足够时，不再额外弹提示。
- 多张地图共用一份技能。重复安装没有变化时直接结束，升级保留你已有的玩法文档。

## 按需安装

告诉 AI 你要做哪类工作，它会选择对应的安装组合。封面、界面节点改名和模型操作等技能可以按需添加。

| 工作类型 | 安装组合 |
|---|---|
| 原点版地图 | `map-origin` |
| 世界版地图 | `map-world` |
| 插件、命令行或资源转换工具 | `tooling` |
| 只需要精简实现和接口研究 | `common` |

完整内容见[技能清单](skill-catalog.json)。开发辅助工具时，不会套用地图玩法和试玩流程。

## 安装

支持 Codex、OpenCode 和 ZCode 三款编程助手。把下面这句话发给你正在使用的 AI 助手即可。

> 请按照 `https://github.com/Zx9874/eggy-agent-skills` 仓库中的 `START-HERE.md` 帮我安装技能包。地图开发的共享技能装在地图外的总工作区，不要装进 `LuaSource_*` 地图工程。

**地图技能放在地图外的总工作区，多张地图共用一份。** 总工作区就是你用编程助手打开、存放这些地图的上级文件夹，目录可以这样安排。

```text
<总工作区>/
  .agents/skills/       共享技能；ZCode 改用 .zcode/skills/
  .eggy-agent/         安装脚本、状态和必要备份
  AGENTS.md           工作区公共规则
  LuaSource_Example/  单张地图
    AGENTS.md         这张地图的规则
    README.md         这张地图的总览
    docs/             这张地图的需求、计划等文档
```

即使只有一张地图，也按这个方式安装。地图可以放在总工作区内更深一层的分类目录里；技能、仓库下载文件和手册都留在地图同步目录外。

地图安装时，AI 会确认总工作区、当前地图和单人或多人。工具开发安装在工具自己的项目目录，不询问地图。全局安装只提供公共和辅助工具技能，需要时请明确提出。安装完成后，打开对应工作区并新建会话。

已有安装可以按[升级说明](UPDATE-给agent的升级任务书.md)更新。具体命令见[安装任务书](INSTALL-给agent的安装任务书.md)。

## 官方手册

仓库收录[原点版手册](docs/official/origin/目录.md)和[世界版手册](docs/official/world/目录.md)，版本时间为 **8.28**，抓取日期为 2026-08-27。

手册供你和 AI 按需查阅，不会随技能复制到地图里，安装压缩包也不包含手册。资料可能落后于编辑器更新，开发时仍需核对当前工程接口。
