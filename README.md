# 蛋仔地图 Agent Skill（代理技能包）

这是给蛋仔地图作者准备的 Agent（代理）开发技能包，支持原点版和世界版。安装后，Agent（代理）会按规则确认地图、查证接口、保护已有功能，并记录需求、计划和资产，帮助你减少重复试错。

## 功能介绍

- 写代码前先核对接口是否存在、参数怎么填写，减少猜接口和反复试错。
- 区分原点版与世界版、单人地图与多人地图，避免混用开发规则。
- 保护地图已有功能和蛋码调用的函数，避免被随意删除或改名。
- 为每张地图分别记录玩法需求、开发计划、资产清单、项目说明和开发日志。
- 协助排查报错、检查日志、安排试玩，并把确认有效的经验留给以后使用。

## 安装

把下面这句话完整发给你的 Agent（代理）：

> 帮我安装这个 Skill（技能包）：https://github.com/Zx9874/eggy-agent-skills/blob/main/START-HERE.md

Agent（代理）只会向你确认三个信息：蛋仔工程总文件夹（总工作区）、要开发的地图、单人还是多人。回答以后，等它完成安装和检查即可。

这里的 Skill（技能包）是给 Agent（代理）使用的蛋仔地图开发规则和工具，不是蛋仔编辑器自动生成的官方技能。

安装完成后，请始终让 Agent（代理）打开蛋仔工程总文件夹。多张原点版和世界版地图共用一份 Skill（技能包），每张地图的需求、计划和资产分别保存。

Agent（代理）说“完成”不代表地图已经通过试玩。请进入编辑器亲自确认效果，并检查原有功能没有被破坏。
