# 蛋仔地图 Agent Skill（代理技能包）

这是一个用于蛋仔地图开发的 Agent（代理）技能包，面向使用代理协助编写 Lua（脚本语言）的地图作者，支持原点版和世界版。

## 包含的技能

- `eggy-lua-coding`（蛋仔脚本开发）：组织代码新增、修改、修复和审查，并在编码前核对所用接口。
- `eggy-design`（玩法需求）：记录玩家实际体验到的玩法内容，不写技术实现。
- `eggy-dev-plan`（开发计划）：记录用户原话、任务拆解、验收标准、开发进度和待办事项。
- `eggy-kb`（知识沉淀）：保存经过验证的接口用法、编辑器规则和数值边界。
- `eggy-log-triage`（日志排查）：区分日志等级，分析报错并记录开发批次的改动。
- `eggy-playtest`（试玩检查）：管理单次试玩过程并读取本次试玩产生的日志。
- `eggy-qa`（质量检查）：整理测试项目，检查新功能和原有功能的运行情况。
- `eggy-lua-export`（蛋码函数保护）：检查蛋码按名称调用的函数，保护函数名称和参数关系。
- `eggy-custom-event`（自定义事件）：处理 Lua（脚本语言）与蛋码之间的事件和参数传递。
- `eggy-preset-io`（预设处理）：管理预设的导入、导出、备份和资产登记。
- `eggy-editor-cli`（编辑器命令行）：连接蛋仔编辑器，控制试玩并读取日志和截图。

这些技能按任务需要分别加载，不会在每个新会话中一次读取全部内容。

## 安装

把下面这句话完整发给你的 Agent（代理）：

> 帮我安装这个 Skill（技能包）：https://github.com/Zx9874/eggy-agent-skills/blob/main/START-HERE.md

Agent（代理）只会向你确认三个信息：蛋仔工程总文件夹（总工作区）、要开发的地图、单人还是多人。回答以后，等它完成安装和检查即可。

这里的 Skill（技能包）是给 Agent（代理）使用的蛋仔地图开发规则和工具，不是蛋仔编辑器自动生成的官方技能。

安装完成后，请始终让 Agent（代理）打开蛋仔工程总文件夹。多张原点版和世界版地图共用一份 Skill（技能包），每张地图的需求、计划和资产分别保存。

Agent（代理）说“完成”不代表地图已经通过试玩。请进入编辑器亲自确认效果，并检查原有功能没有被破坏。
