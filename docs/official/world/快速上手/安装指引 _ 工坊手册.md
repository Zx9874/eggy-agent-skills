# 安装指引

## 安装包下载

前往官网下载PC编辑器安装包

>>> [官网下载链接](https://adl.netease.com/d/g/party/c/mgc)

## 安装配置要求

**最低配置**

系统：Win10(版本19H2 内部版本18362)

空间：20GB可用存储空间

内存：8G内存

CPU：Intel CPU Core i5-8500 / AMD CPU Ryzen 5600G

GPU：不支持集成显卡，最低NVIDIA GTX 1050ti 或 同等级别独立显卡

**推荐配置**

系统：Win10(版本19H2 内部版本18362或更高)/Win11

空间：30GB可用存储空间，推荐使用ssd固态硬盘

内存：16G内存

CPU：Intel CPU Core i7-12700 / AMD CPU R7 5700X

GPU：推荐使用N卡，NVIDIA GTX 2060 或 同等级别独立显卡

## 安装与启动

1. 打开官网下载的蛋仔派对PC版安装包，根据安装指引进行安装。
2. 安装后在网易发烧游戏启动器界面找到《蛋仔派对》,选择版本为<蛋仔派对编辑器>。

   ![](https://u5-creator.s3.game.163.com/manual/assets/pc_entry.EOYxhqZl.png)
3. 安装完成后编辑器会自动更新到最新版本，完成后将自动重启客户端。
4. 打开客户端后登录游戏账号，登录成功后会自动同步该账号手机端的地图草稿，在PC编辑器上传到云端的草稿也可以同步到移动端。

## 卸载流程

在网易发烧游戏启动器中，点击开始游戏右侧的按钮，在菜单中选择<卸载>，按照系统指引完成步骤即可。

![](https://u5-creator.s3.game.163.com/manual/assets/pc_uninstall.Pvygcgi0.png)
