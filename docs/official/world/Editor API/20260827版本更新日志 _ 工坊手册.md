# 20260827版本更新日志

## 概览

* **服务开放**: 1（PrefabService 预设服务，11 个方法）
* **服务变更**: 1（AssetService 预设能力迁移至 PrefabService，定位调整为专注编辑器资产能力）
* **Unit 支持**: 可创建单位类型由 3 个扩展至 42 个（新增 39 个）

## PrefabService（预设服务，本次正式开放）

通过 `editor:GetService("PrefabService")` 获取。承接 AssetService 的预设能力，提供预设全生命周期管理：

* **创建/删除**: `CreatePrefabFromUnit(unit, folderKey?)` 将场景中的单位（含子单位树）保存为预设，返回新预设 ID；`RemovePrefab(prefabId)` 删除预设
* **属性读写**: `GetPrefabEditableProperties(unitType)` 查询单位类型的可编辑属性；`GetPrefabValue` / `ChangePrefabValue` 读写预设属性值
* **查询/应用**: `GetAllPrefabIds()` 查询当前全部预设；`ApplyPrefabToInstances(prefabId)` 预设编辑后一键同步到场景中所有使用该预设的实例（缺失的子单位自动补建）
* **导入导出**: `ExportPrefab` / `ImportPrefab` / `ExportPrefabs` / `ImportPrefabs`（.bin 文件，可跨地图复用；导入与已有 ID 冲突时自动生成新 ID，不覆盖已有预设）

## AssetService（资产服务，定位调整）

* **预设能力迁移至 PrefabService**: 预设的创建、删除、属性读写、查询、导入导出等能力，统一迁移至 PrefabService（旧调用会打印迁移提示，具体方法对应关系见 PrefabService 文档）
* 服务定位更新：AssetService 现专注编辑器资产能力（预加载资产清单、自定义资产导入导出）

## Unit 支持

* **可创建单位类型由 3 个扩展至 42 个**: 新增约束（球窝 / 滑轨 / 刚性 / 杆）、SoundUnit（音效）、SpawnLocationUnit（出生点）、Tool（工具）、SkinUnit（皮肤组件）、Folder（文件夹）等常用 39 个Unit类型
