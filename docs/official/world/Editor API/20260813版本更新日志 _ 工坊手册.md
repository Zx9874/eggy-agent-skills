## 类型变更

### 类型新增 (3)

* **DataStoreService**[class] [服务 Service]: DataStoreService 数据存储服务，提供键值数据的持久化读写、版本管理和排序查询等能力。通过 editor:GetService("DataStoreService") 获取，DataStore 数据集合由本服务的 GetDataStore / GetGlobalDataStore / GetOrderedDataStore 获取。 **使用范围**: 仅编辑时可用
* **SpaceUnit**[class] [单位 Unit]: 继承 Unit，具有位置/旋转/缩放的空间单位。通过 World 服务返回的 SpaceUnit 对象访问。 **使用范围**: 仅编辑时可用
* **Task**[class] [服务 Service]: 任务调度服务，提供任务的立即执行、延迟执行、等待与取消等能力。通过 editor:GetService("Task") 获取。 **使用范围**: 仅编辑时可用

## 方法变更

### 方法新增 (4)

* AssetService:AddPreloadAsset: AssetService:AddPreloadAsset(uri: String) -> Bool — 将资源加入预加载清单，进入玩法前会提前加载该资源，减少游戏中的加载等待。支持 custom://（自定义资源）与 official://（官方资源）两种 URI
* AssetService:CreateUnitByAsset: AssetService:CreateUnitByAsset(assetId: String, createPos: Vector3, rotation: Quaternion, createScale: Vector3) -> Unit[] — 通过预设 ID 在场景指定位置创建单位，支持设置旋转与缩放。
* AssetService:GetPreloadAssetList: AssetService:GetPreloadAssetList() -> String[] — 获取当前已配置的预加载资源清单
* AssetService:RemovePreloadAsset: AssetService:RemovePreloadAsset(uri: String) -> Bool — 将资源从预加载清单中移除，移除后进入玩法时不再提前加载该资源

### 方法删除 (4)

* Editor:GetChildNameConflicts
* Editor:OpenPluginManager
* Unit:MoveToFolder

### 描述变更+参数描述变更 (5)

* DataStore:GetAsync: 描述: 获取指定 key 的数据 → 获取指定 key 对应的数据；key 不存在时返回 nil。
* DataStore:GetVersionAtTimeAsync: 描述: 获取指定时间点的数据 → 获取指定 key 在指定时间点（毫秒时间戳）的数据。
* DataStore:IncrementAsync: 描述: 对指定 key 的数值进行原子自增 → 对指定 key 的数值进行原子自增，返回自增后的值。
* DataStore:RemoveVersionAsync: 描述: 删除指定版本 → 删除指定 key 的指定历史版本。
* DataStore:SetAsync: 描述: 设置指定 key 的数据 → 写入指定 key 的数据，若 key 已存在则覆盖。
