## 新增

### 类型新增 (2)

* **EUINode**：编辑器 EUI（编辑器 UI 系统）的节点对象，提供获取/设置属性接口。仅编辑时可用
* **EUIService**：编辑器 EUI 服务，通过 `editor:GetService("EUIService")` 获取。提供 EUI 节点的创建、查找与删除能力，节点属性操作支持撤销/重做，多数操作要求 EUI 编辑器已打开。仅编辑时可用

### 方法新增 (8)

* `Editor:SaveMap()`：保存当前地图（同步 Lua 源码到地图包并持久化地图数据到磁盘）
* `Editor:IsMapDirty()`：判断当前地图是否有未保存的修改，保存成功后自动变为 false
* `World:CreateUnit(unitType, values?)`：创建指定类型的单位；values 可传 Position / Rotation / Scale / AssetId
* `World:GetUnitsByUnitType(unitType, exact?)`：按单位类型查询匹配的 Unit，exact=false 时同时返回继承类型的单位
* `AssetService:ExportPreset(assetId, path)`：将预设导出为单个 .bin 文件（msgpack 打包的序列化数据），返回是否成功；导出的文件可拷贝到其他地图，通过 ImportPreset / ImportPresets 导入
* `AssetService:ImportPreset(path, packageId, folderKey)`：从 .bin 文件导入单个预设，返回新预设 ID（失败返回空串）；与已有预设 ID 冲突时自动生成新 ID，不覆盖已有预设；packageId / folderKey 缺省时进自定义文件夹
* `AssetService:ExportPresets(assetIdList, dirPath)`：批量导出多个预设到目录，每个预设一个 .bin 文件（文件名 = 预设 ID 转换），返回成功导出的文件路径列表
* `AssetService:ImportPresets(dirPath)`：从目录批量导入预设（扫描目录下所有 .bin 逐一导入），返回新预设 ID 列表

## 删除

### 方法删除 (3)

* `DataStoreIncrementOptions:SetUserIds`：移除，使用 AddUserId 逐个添加
* `DataStoreSetOptions:SetUserIds`：移除，使用 AddUserId 逐个添加
* `AssetService:GetAssetEidsByType`：不再对外公开，从公开文档移除

## 修改

### 方法更名 (4)

去掉 Cmd 后缀，旧名保留兼容转发：

* `CreateAssetCmd` → `CreateAsset`
* `ChangeAssetValueCmd` → `ChangeAssetValue`
* `DuplicateAssetCmd` → `DuplicateAsset`
* `RemoveAssetCmd` → `RemoveAsset`

### 参数变更 (4)

* `CreateAsset` / `RemoveAsset` / `DuplicateAsset`：`packageId`、`folderKey` 改为可选——不传时按单位类型自动归位（如 WorldUnit 进组件页签、RenderUnit 进装饰页签），未指定文件夹时进该包自定义文件夹
* `ChangeAssetValue`：移除 `packageId` 参数
* `IsOfficialAssetId`：参数由 `unitType` 改为 `assetId`（预设 ID）
* `SpaceUnit:GetPosition` / `GetScale`：返回值类型 `Vector3` → `Number[]`
