* 类型新增: 1

## 类型变更

### 类型新增 (1)

* **EffectService**[class] [服务 Service]: 特效服务

## 属性变更

### 属性新增 (1)

* LightingService.EnvironmentMap: String — 场景反射立方体贴图

### 属性枚举选项扩展 (3)

* BasePart.OcclusionType 新增取值 `4`：镜头前推（无玩家虚影）
* RenderTriggerUnit.OcclusionType 新增取值 `4`：镜头前推（无玩家虚影）
* RenderUnit.OcclusionType 新增取值 `4`：镜头前推（无玩家虚影）

### 属性描述变更 (3)

* Matrix.Pitch: 描述 俯仰角（ZXY 顺序） → 俯仰角（ZXY 顺序，弧度）
* Matrix.Roll: 描述 翻滚角（ZXY 顺序） → 翻滚角（ZXY 顺序，弧度）
* Matrix.Yaw: 描述 偏航角（ZXY 顺序） → 偏航角（ZXY 顺序，弧度）

## 方法变更

### 返回契约变更 (1)

* Camps:GetCamps: 返回值由 `Iter<Camp>` 更新为 `Camp[]`；调用方应按数组遍历。当前教程兼容既有运行包的迭代器返回形态。

### 参数描述变更 (2)

* AssetService:LoadDataAssetAsync: 参数描述变更
* Matrix.FromEulerAngles: 参数描述变更

## 规范化说明

* MapData:GetSectionData 的 `table|nil` 更新为等价的 `table | nil`/nullable 表达，仅为契约结构规范化，不改变运行行为。
