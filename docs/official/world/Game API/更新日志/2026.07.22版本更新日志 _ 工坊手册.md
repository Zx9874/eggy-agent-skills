* **RodConstraint**[class] [单位 Unit]: 杆约束 → 杆约束用于在两个物理部件之间保持固定的距离，类似刚性连杆。与刚性约束不同，杆约束允许两部件在保持距离的前提下自由旋转。使用时需设置 Attachment0 和 Attachment1 指向两个已存在的 Attachment，并通过 Length 属性指定杆长。物理约束建议在服务端创建。
