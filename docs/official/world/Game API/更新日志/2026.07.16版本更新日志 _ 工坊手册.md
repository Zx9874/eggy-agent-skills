# 20260716版本更新日志

## 概览

* 类型新增: 2
* 属性新增: 2
* 属性类型变更: 1
* 事件新增: 1
* 方法新增: 4
* **合计: 10**

## 类型变更

### 类型新增 (2)

* **ConfigService**[class] [服务 Service]: 配置服务（仅服务端）。提供面向地图作者的高阶 API： - GetConfigAsync(): 拉取最新已发布配置，返回 ConfigSnapshot - GetConfigForPlayerAsync(player): 在 GetConfigAsync 基础上叠加按玩家分桶的覆盖 - SetTestingValue / ClearTestingValue: 在试玩模式下覆盖某个配置值 仅由 game:GetService("ConfigService") 返回，不可实例化。
* **ConfigSnapshot**[class] [单位 Unit]: 配置快照（不可变数据视图）。由 ConfigService:GetConfigAsync() 或 GetConfigForPlayerAsync() 创建。 当后台版本号变化时 Outdated 会被置为 true 并 Fire UpdateAvailable。 调用 Refresh() 可同步到最新数据。

## 属性变更

### 属性新增 (2)

* CameraService.ResetPitch: Bool — 相机跟随重置时是否重置俯仰角(pitch)，默认true
* CameraService.ResetYaw: Bool — 相机跟随重置时是否重置水平朝向(yaw)，默认true

### 属性类型变更 (1)

* EffectUnit.EnemyEffectId: Int → String

## 事件变更

### 事件新增 (1)

* Game.Loaded: Signal<fun()> — 客户端初始单位/属性加载完成时触发，仅触发一次（幂等保护）。服务端不会触发该信号。订阅者通过 game.Loaded:Connect(fn) 接收回调，回调不带任何参数。

## 方法变更

### 方法新增 (4)

* EUINodeBase:GetFullPath: EUINodeBase:GetFullPath() -> String — 返回当前 UI 节点从 UI 根节点到自身（不含 UI 根节点）的 '.' 分隔路径字符串。例：节点层级 root.A.B 中，B:GetFullPath() 返回 'A.B'
* Game:IsLoaded: Game:IsLoaded() -> Bool — 客户端初始单位/属性加载完成时触发 Loaded 信号，本方法返回当前是否已触发。服务端不会触发 Loaded，故服务端恒返回 false。
* SoundService:PlayLocalSound: SoundService:PlayLocalSound(soundId: String, volume: Float, speed: Float) — 本地一次性播放 2D 音效（不创建 Unit，性能开销最小）
* TeleportService:ChangeServerAsync: TeleportService:ChangeServerAsync(player: Player) -> Bool — 将单个玩家迁移到由匹配系统分配的另一服务器战斗实例; 编辑器环境下返回 false; 迁移成功返回 true, 失败返回 false。注意成功的情况下，执行顺序是先迁移玩家，再返回结果，因此收到回调的时候迁移已经完成了。
