通用容器单位，自身不携带任何属性和渲染表现，仅用于在场景层级树中组织和分组子 [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 实例，便于逻辑归类和批量管理。

## 适用场景

用于给场景树中的一组 [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 建立逻辑分组，例如把关卡机关、敌人出生点或临时对象放在同一个父节点下统一查找与清理。

## 使用要点

通过 World:CreateUnit 创建 [Folder](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Folder.html)，再把子 [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 的 Parent 指向该 [Folder](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Folder.html)；可复用 [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 继承成员 GetChildren、FindFirstChild 和 ClearAllChildren 管理分组内容。

## 代码示例

### 创建文件夹并组织子单位

```lua
-- @runtime client
local World = game:GetService("World")
local folder = World:CreateUnit("Folder", { Name = "LevelProps" })
World:CreateUnit("WorldUnit", { Name = "SwitchA", Parent = folder })
World:CreateUnit("WorldUnit", { Name = "SwitchB", Parent = folder })
print("分组内单位数:", folder:GetChildCount())
```
