[SimpleLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleLight.html) 是装饰性自发光单位的抽象基类，集中定义位置、旋转、缩放、启用状态和开关事件名等共有属性。

## 适用场景

用于理解 [SimplePointLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimplePointLight.html)、[SimpleLineLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleLineLight.html)、[SimpleAreaLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleAreaLight.html)、[SimpleSpotLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleSpotLight.html) 及其暗调版本共享的基础契约。

## 使用要点

[SimpleLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleLight.html) 的 creatable=false，不应直接创建；请根据外观选择一个可创建的具体 Simple\*Light 子类，再设置继承属性。

## 注意事项

这些类型表现为自发光装饰，不保证照亮周围物体。OpenEvent 和 CloseEvent 是自定义事件名称字符串；具体视觉表现与挂载要求应在目标运行包验证。
