背包单位，运行时容器，管理玩家携带的所有物品。

## 注意事项

[Backpack](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Backpack.html) 是逻辑物品容器，不自带背包 UI、实物模型或官方预设资源。当前 [Player](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Player.html) 公开 Meta 未声明 [Backpack](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Backpack.html) 属性，示例不得使用 player.Backpack；脚本可在服务端创建明确持有的业务容器，并通过公开 [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 子节点接口管理物品。

## 代码示例

### 创建并遍历业务背包容器

```lua
-- @runtime server
local World = game:GetService('World')

local backpack = World:CreateUnit('Backpack', { Name = 'BusinessBackpack' })
local item = World:CreateUnit('BackpackItem', {
    Name = 'StarterItem',
    Icon = 'official://image/14896',
    Parent = backpack,
})
print('已加入背包物品:', item.Name)
for _, child in ipairs(backpack:GetChildren()) do
    print('背包物品:', child.Name)
end
```
