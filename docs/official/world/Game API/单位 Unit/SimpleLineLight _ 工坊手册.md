[SimpleLineLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleLineLight.html) 是支持两端颜色渐变的线状装饰性自发光体；它呈现发光外观，但不会照亮周围物体。

## 适用场景

用于霓虹灯管、光剑、灯带或建筑轮廓等线状自发光装饰。

## 使用要点

通过 World:CreateUnit("SimpleLineLight", config) 创建实例，用 Color/Color2 设置两端颜色，并用 Pivot、Radius 和 Brightness 调整外观。

## 注意事项

当前运行包实测 [SimpleLineLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleLineLight.html) 即使创建后挂到 [WorldUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/WorldUnit.html) 也没有视觉表现，且公开 API 未说明可用的光照挂载结构。以下代码只展示属性形态，不能作为可见效果验收；在引擎补齐挂载契约或可用预设前，不建议用于正式内容。

## 代码示例

### 创建双色线光源

```lua
-- @runtime server
local world = game:GetService("World")

local light = world:CreateUnit("SimpleLineLight", {
    Position = Vector3.New(-5, 3, 0),
    Brightness = 3.0,
    Color = Color.New(0, 255, 0, 255),
    Color2 = Color.New(0, 0, 255, 255),
    Radius = 8.0,
    Pivot = 0.5,
})
light.Pivot = 1.0
print("SimpleLineLight:", light)
```
