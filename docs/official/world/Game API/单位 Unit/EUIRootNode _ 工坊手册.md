## 注意事项

[EUIRootNode](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/EUIRootNode.html) 是当前玩家 UI 树的根节点，通过当前玩家 PlayerGui.EuiManager:GetRootNode() 获取。常见用法是在根节点上查找已创建的子节点，或把新建 EUI 节点挂到根节点下。

## 代码示例

### 获取 UI 根节点并查找子节点

```lua
-- @runtime client
local Players = game:GetService("Players")
local localPlayer = Players.LocalPlayer
if localPlayer == nil then return end
local EUIManager = localPlayer.PlayerGui.EuiManager

local rootNode = EUIManager:GetRootNode()
local child = rootNode:FindFirstChild("MainPanel", true)
if child ~= nil then
    print("找到 UI 节点:", child.Name)
end
```
