[SimpleAreaShadowLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleAreaShadowLight.html) 是暗调矩形自发光体，用较深颜色呈现面状装饰光效，不会向周围物体投射真实照明。

## 适用场景

用于夜景面板、洞穴标记或暗色界面装饰等低亮度矩形自发光外观。

## 使用要点

通过 World:CreateUnit("SimpleAreaShadowLight", config) 创建实例，用 Color 和 Size 调整暗调自发光面的颜色与尺寸。

## 注意事项

[SimpleAreaShadowLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleAreaShadowLight.html) 创建后需要绑定到引擎支持的光照挂载结构并处于可渲染场景中才可能生效；单独 World:CreateUnit 或简单挂到 [LightingService](https://u5-creator.s3.game.163.com/manual/se/game_api/service/LightingService.html)/[WorldUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/WorldUnit.html) 不一定产生视觉表现。当前表现依赖渲染管线版本，请在目标端实测。

## 代码示例

### 创建暗调面光源并设置尺寸

```lua
-- @runtime server
local world = game:GetService("World")

local light = world:CreateUnit("SimpleAreaShadowLight", {
    Position = Vector3.New(0, 3, 10),
    Color = Color.New(0, 255, 102, 255),
    Size = Vector2.New(4, 3),
})
print("SimpleAreaShadowLight:", light)
```
