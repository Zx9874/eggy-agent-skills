[PhysicsUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/PhysicsUnit.html) 是场景中承担真实物理模拟的单位，具备质量、质心、重力、阻尼等刚体属性，可配置碰撞与射线检测。它提供完整的力与冲量施加接口，能够驱动对象移动、旋转或被击飞，同时通过碰撞组和碰撞对管理单位间的交互，碰撞事件可用于实现打击、触发等玩法逻辑。

## 适用场景

在需要物理反馈的玩法中，例如制作可推动的箱子、受击飞出的道具、触发碰撞的机关或物理弹射装置时，通常会创建 [PhysicsUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/PhysicsUnit.html) 并开启物理，再施加力或冲量使其运动，并监听碰撞事件驱动后续逻辑。

## 使用要点

通过 game:CreateUnit("PhysicsUnit", 配置表) 或 World:CreateUnit 创建实例，并设置 BodyType、PhysicsActive、CollisionGroup 等属性以启用物理。需要驱动运动时，可调用 ApplyForceToCenterOfMass、ApplyImpulse 或 ApplyTorque 施加力、冲量与力矩。碰撞检测方面，监听 OnCollisionEnter 与 OnCollisionExit 事件，并可用 AddCollisionWithGroup、AddNoCollisionPairWithUnit 管理碰撞关系。

## 注意事项

引擎使用 Y 轴向上的坐标系（重力默认 [0, -9.8, 0]）。施加力、冲量或力矩前，应确认单位使用 Enums.BodyType.Dynamic 且 PhysicsActive=true；施加向上的力应使用 Vector3.New(0,正值,0) 而非 Vector3.New(0,0,正值)。

## 代码示例

### 创建动态物理单位并施加向上冲量

```lua
-- @runtime client
local world = game:GetService("World")
local physicsUnit = world:CreateUnit("PhysicsUnit", {
    Name = "JumpingBox",
    Position = Vector3.New(0, 3, 0),
    BodyType = Enums.BodyType.Dynamic,
    PhysicsActive = true,
})
physicsUnit:ApplyImpulse(Vector3.New(0, 120, 0))
```

### OnCollisionEnter

签名：`OnCollisionEnter(otherUnit: Unit)` 触发：`local`

| 回调参数 | 类型 | 说明 |
| --- | --- | --- |
| `otherUnit` | [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) | 与之发生碰撞的另一个物体 |

> 示例代码

> 监听编辑器动态物体开始碰撞

```lua
-- @runtime client

if unit == nil or not unit:IsA("PhysicsUnit") then return end

    print("开始碰撞:", otherUnit.Name)
end)
```

### AddCollisionWithGroup

添加一个允许与当前物理单位发生碰撞的碰撞组。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `groupName` | `String` | 要加入的碰撞组名称 |

**返回值** `void`

> 示例代码

> 注册并添加允许碰撞的组

```lua
-- @runtime server
local physicsService = game:GetService("PhysicsService")

pcall(function() physicsService:RegisterCollisionGroup(groupName) end)
local unit = game:CreateUnit("PhysicsUnit", {})
```
