[SimpleSpotShadowLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleSpotShadowLight.html) 是暗调锥形自发光体，用于低亮度方向性装饰，不会照亮周围物体。

## 适用场景

用于暗色舞台光束、方向指示或需要沉暗锥形外观的场景。

## 使用要点

通过 World:CreateUnit("SimpleSpotShadowLight", config) 创建实例，设置 Color 调整暗调外观，并用 InnerAngleFactor 控制锥形内角因子。

## 注意事项

当前运行包实测 [SimpleSpotShadowLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleSpotShadowLight.html) 即使创建后挂到 [WorldUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/WorldUnit.html) 也没有视觉表现，且公开 API 未说明可用的光照挂载结构。以下代码只展示属性形态，不能作为可见效果验收；在引擎补齐挂载契约或可用预设前，不建议用于正式内容。

## 代码示例

### 创建暗调锥形光源

```lua
-- @runtime server
local world = game:GetService("World")

local light = world:CreateUnit("SimpleSpotShadowLight", {
    Position = Vector3.New(0, 3, -10),
    Color = Color.New(102, 102, 255, 255),
    InnerAngleFactor = 0.5,
})
print("SimpleSpotShadowLight:", light)
```
