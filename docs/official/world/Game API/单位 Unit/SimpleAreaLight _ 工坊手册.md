[SimpleAreaLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleAreaLight.html) 是矩形平面形态的装饰性自发光体；它自身呈现亮色，但不会作为真实光源照亮周围物体。

## 适用场景

用于电视屏幕、LED 广告牌、窗面亮片等需要矩形自发光外观的装饰。

## 使用要点

通过 World:CreateUnit("SimpleAreaLight", config) 创建实例，用 Brightness、Color 和 Size 调整自发光面的外观。

## 注意事项

[SimpleAreaLight](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SimpleAreaLight.html) 创建后需要绑定到引擎支持的光照挂载结构并处于可渲染场景中才可能生效；单独 World:CreateUnit 或简单挂到 [LightingService](https://u5-creator.s3.game.163.com/manual/se/game_api/service/LightingService.html)/[WorldUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/WorldUnit.html) 不一定产生视觉表现。当前表现依赖渲染管线版本，请在目标端实测。

## 代码示例

### 创建面光源并设置基础属性

```lua
-- @runtime server
local world = game:GetService("World")

local light = world:CreateUnit("SimpleAreaLight", {
    Position = Vector3.New(0, 3, 5),
    Brightness = 2.0,
    Color = Color.New(255, 240, 200, 255),
    Size = Vector2.New(4, 2),
})
-- 是否可见取决于当前渲染管线和光源挂载结构，请在目标端实测
print("SimpleAreaLight:", light)
```
