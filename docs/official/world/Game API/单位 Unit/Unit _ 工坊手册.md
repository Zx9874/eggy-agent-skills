[Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 是所有场景单位的基础类型，负责游戏对象树的层级组织与数据管理。它支持子节点的增删查、路径定位、自定义属性附加以及属性变更监听，并提供克隆、销毁等生命周期操作。

## 适用场景

在场景初始化或玩法逻辑中，通常先创建或获取 [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html)，再利用 FindFirstChild、GetChildren 等层级方法检索目标单位，或通过 SetAttribute 为对象附加标记数据。

## 使用要点

[Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 是不可直接创建的场景单位基础类型。应通过 World:CreateUnit 或 game:CreateUnit 创建具体公开 [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 子类（如 [Folder](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Folder.html)、[WorldUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/WorldUnit.html)、[RenderUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/RenderUnit.html)），或从服务和对象树 API 获取实例；随后使用 GetChildren、FindFirstChild、SetAttribute、Destroy 等继承的公共能力。

## 注意事项

[Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 是所有场景单位的基础类型。Meta 公开且可写的属性支持 unit.Property = value，也隐式支持 unit:SetProperty(value)；读取可使用 unit.Property 或 unit:GetProperty()。readOnly=true 的属性只允许读取/Get，不允许直接赋值或 Set。SetAttribute/GetAttribute 只操作按名称创建的自定义属性，不是修改 Name、Parent、Position 等 Meta 属性的通用入口。FindFromPath 使用 '.' 分隔路径（如 unit:FindFromPath("ModelGroup.MyModel.Part1")），与 GetFullPath 返回的路径格式一致，可直接互通。FindFirstChild/FindFirstAncestor 等系列方法用名称匹配，Recursive 参数控制是否递归搜索后代。GetChildAtIndex 的 Lua 入参从 1 开始，GetChildAtIndex(1) 返回第一个子节点，不要传 0。

## 代码示例

### 通过具体 Unit 子类管理子节点

```lua
-- @runtime client
local world = game:GetService("World")
local root = world:CreateUnit("Folder", { Name = "RootContainer" })
world:CreateUnit("Folder", { Name = "ChildA", Parent = root })
world:CreateUnit("Folder", { Name = "ChildB", Parent = root })
print("子节点数量:", root:GetChildCount())
local firstChild = root:GetChildAtIndex(1)
if firstChild ~= nil then print("第一个子节点:", firstChild.Name) end
root:ClearAllChildren()
```

### 安全监听子节点添加与移除

```lua
-- @runtime client
local world = game:GetService("World")
local root = world:CreateUnit("Folder", { Name = "EventRoot" })
```

### GetAttributeChangedSignal

签名：`GetAttributeChangedSignal(attrName: String) -> Signal (自定义属性变化信号)`

获取指定自定义属性变化时的信号对象。

⚙ 该方法监听 SetAttribute/GetAttribute 管理的自定义属性。客户端启动入口对 LocalPlayer 立即注册时，信号代理可能尚未就绪；当前运行包反馈需延迟约 1 秒。延迟时长属于兼容性 workaround，不是稳定 API 契约，注册后还应主动读取一次当前值。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `attrName` | `String` | 要监听的自定义属性名称 |

**返回值** [Signal](https://u5-creator.s3.game.163.com/manual/se/game_api/data/Signal.html) (自定义属性变化信号)

> 示例代码

> 延迟注册本地玩家自定义属性监听

```lua
-- @runtime client
local Players = game:GetService("Players")
local Task = game:GetService("Task")

Task:Delay(1, function()
    local player = Players.LocalPlayer
    if player == nil then return end

    local attributeName = "Ready"
    player:GetAttributeChangedSignal(attributeName):Connect(function()
        print(attributeName, player:GetAttribute(attributeName))
    end)
    -- 避免遗漏注册前已经写入的值
    print(attributeName, player:GetAttribute(attributeName))
end)
```

### FindFromPath

签名：`FindFromPath(path: String) -> Unit (查找到的节点，路径不合法或中途断开返回 nil)`
