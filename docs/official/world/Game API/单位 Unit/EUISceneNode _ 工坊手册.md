[EUISceneNode](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/EUISceneNode.html) 是用于把 UI 放到三维世界中的场景界面节点，可设置世界坐标，也可挂接到 [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 的指定 socket。

## 适用场景

常用于角色头顶名称、血条、交互提示等跟随场景对象显示的 UI。

## 使用要点

通过 Players.LocalPlayer.PlayerGui.EuiManager 的 CreateSceneNodeAtPosition(position, nodeInfo) 创建固定位置节点，或用 CreateSceneNodeAttachUnit 创建跟随节点；需要重新绑定已有节点时调用 AttachUnit(unit, socket)。

## 注意事项

[EUISceneNode](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/EUISceneNode.html) 不能直接调用类型构造函数，也不能通过 World:CreateUnit 创建。应通过 [EUIManager](https://u5-creator.s3.game.163.com/manual/se/game_api/data/EUIManager.html) 的公开创建接口获取实例；Position 的 editable=false 只表示不在编辑器面板编辑，并非 Lua 只读，作者侧可通过公开属性赋值更新。AttachUnit 的第一个参数必须是已存在的 [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 实例，socket 为挂点名称字符串。

## 代码示例

### 创建三维场景 UI 节点

```lua
-- @runtime client
local Players = game:GetService("Players")
local localPlayer = Players.LocalPlayer
if localPlayer == nil then return end
local euiManager = localPlayer.PlayerGui.EuiManager
local sceneNode = euiManager:CreateSceneNodeAtPosition(
    Vector3.New(0, 5, 0),
    { InheritVisible = true, MaxVisibleDistance = 50 }
)
sceneNode.Position = Vector3.New(2, 6, 0)
```

## 函数 (1)

### AttachUnit

签名：`AttachUnit(unit: Unit, socket: String) -> void`

将指定的 [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 实例绑定到 [EUISceneNode](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/EUISceneNode.html) 上，使该场景节点可以跟随目标单位进行显示。通过传入单位对象和挂点名称，可以将场景 UI 元素附着到单位的指定骨骼或挂点上。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `unit` | [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) | 要挂接的目标 [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 实例。 |
| `socket` | `String` | 目标 [Unit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/Unit.html) 上的挂点名称字符串，例如 "Head"。 |

**返回值** `void`

> 示例代码

> 把场景 UI 绑定到已有目标单位

```lua
-- @runtime client
local World = game:GetService("World")
local sceneNode = World:FindFirstChild("QuestMarkerUI", true)
local target = World:FindFirstChild("QuestTarget", true)
if sceneNode ~= nil and target ~= nil then
    sceneNode:AttachUnit(target, "Head")
end
```
