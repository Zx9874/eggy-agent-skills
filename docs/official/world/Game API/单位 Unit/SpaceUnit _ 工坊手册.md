[SpaceUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SpaceUnit.html) 是三维世界中所有可放置物体的空间基类，统一提供位置、旋转与缩放相关的变换能力。它通过轴心（Pivot）读取与写入控制物体在场景中的摆放，并支持标签标记、所属玩家记录以及空间层级顶端查询等辅助功能。实际使用时通常不直接操作该基类，而是通过其具体子类（如 [WorldUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/WorldUnit.html)、[TriggerUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/TriggerUnit.html)）获得继承的空间能力。

## 适用场景

在需要统一处理场景中各类空间物体的变换、标签或层级归属时，可以通过具体子类实例调用 [SpaceUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SpaceUnit.html) 提供的方法。例如在测试用例中，先创建 [PhysicsUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/PhysicsUnit.html) 或 [TriggerUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/TriggerUnit.html)，再通过类型判断确认继承关系，并使用 PivotTo 等方法移动物体。

## 使用要点

[SpaceUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SpaceUnit.html) 本身不能直接创建，需要先通过 World:CreateUnit 创建其具体子类（如 [TriggerUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/TriggerUnit.html)、[PhysicsUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/PhysicsUnit.html)、[WorldUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/WorldUnit.html) 等），获得实例后即可调用继承自 [SpaceUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SpaceUnit.html) 的轴心与标签方法。常见的调用顺序是：使用 GetPivot 读取当前轴心、用 PivotTo 设置新位置或旋转、用 TranslateBy 沿自身坐标系平移；标签管理则通过 AddTag、HasTag、RemoveTag 配合使用；层级查询可用 IsTopLevel 判断是否位于顶层，FindTopLevel 获取顶层对象。

## 注意事项

[SpaceUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/SpaceUnit.html) 是不可直接创建的空间基类，应创建 [WorldUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/WorldUnit.html)、[TriggerUnit](https://u5-creator.s3.game.163.com/manual/se/game_api/unit/TriggerUnit.html) 等公开具体子类后使用其继承能力。TranslateBy(delta) 沿对象自身坐标系平移，不是世界坐标系；例如对象旋转后，TranslateBy(Vector3.New(0, 0, 1)) 会沿对象本地 Z 轴移动。轴心读写只使用当前公开的 GetPivot、PivotTo 与 ApplyPivotDelta。

## 代码示例

### 用具体空间单位调用 SpaceUnit 能力

```lua
-- @runtime client
local world = game:GetService("World")

-- SpaceUnit 是基类，脚本中创建具体子类（例如 TriggerUnit）后使用继承能力
local unit = world:CreateUnit("TriggerUnit", {
    Name = "TaggedTrigger",
    Position = Vector3.New(0, 5, 0),
    Scale = Vector3.New(3, 2, 1),
})

unit:AddTag("checkpoint")
if unit:HasTag("checkpoint") then
    unit:TranslateBy(Vector3.New(0, 0, 1))
end

local pivot = unit:GetPivot()
unit:PivotTo(pivot * CFrame.New(0, 0, 2))
```
