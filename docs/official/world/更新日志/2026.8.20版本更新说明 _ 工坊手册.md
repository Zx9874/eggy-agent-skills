# 2026.8.20 蛋仔世界编辑器更新公告

## 一、编辑器功能更新

### 1.【多人共建】功能更新

1. 【实时共建】现已支持多人随进随出的试玩模式，通过多人测试创建房间进入试玩，后续其他玩家可以随时加入该地图。
2. 修复了共建时不能读取存档的问题，并增加了本地存档的数量上限。

### 2.【插件】功能更新

1. 插件现已支持"添加到菜单栏"功能，设置后可在编辑器"插件"菜单栏中添加快捷打开按钮。
2. 新增停靠记忆功能。插件停靠状态下关闭编辑器后，同设备再次进入时，插件将自动恢复至上次停靠位置。
3. 优化了部分官方插件在停靠状态下的使用体验。

### 3.其他功能更新

1. 【组件】现已支持通过真实尺寸来设置缩放。
2. 开放简易版富文本控件，具备与文本控件相同的尺寸模式，并支持输入富文本内容。
3. 【Lighting 光照服务】下新增漫画效果、水墨效果等后处理特效。

![](https://u5-creator.s3.game.163.com/manual/assets/lighting.CSTajZMu.png)

4. 优化了地图保存时的实际进度反馈。
5. 编辑状态下支持模拟弱网环境，可在【设置】-【通用设置】-【网络设置】中开启。

## 二、编辑器Bug修复

1. 修复了快捷键复制状态不对的问题
2. 修复了在场景中按住 `Shift` / `Ctrl` 复制对象时，复制状态无法取消的问题。
3. 调整了客户端网络参数配置。
4. 修复了灯光无法复制粘贴的问题。
5. 修复了皮肤面板切换为大图标显示后，无法正常打开面板的问题。
