# 2026.8.06 蛋仔世界编辑器更新公告

## 一、编辑器功能更新

### 1.【界面编辑】功能更新

1. 新增“透明度”属性，现已支持调节原生控件的透明度。

![](https://u5-creator.s3.game.163.com/manual/assets/transparency_se.Cz39OBG0.png)

2. 存为自定义预设的界面控件，现会显示于界面编辑的创建面板中，便于快速调用。
3. 界面控件现已支持通过快捷键 Ctrl+C / Ctrl+V 实现跨地图复制粘贴。
4. 现已支持多次点击同一位置时，逐层穿透并选中更下层的控件。

### 2.【剧情对话】功能更新

现已支持将对话中的自定义头像设为空图标

### 3.资源相关更新

自定义上传的受限资源，现已支持上传者对其本人创建或参与共建的地图进行直接授权。授权后，该地图所有共建者均可选用该资源。

> **注意**：权限一经授予，不支持撤回。

### 4.其他功能更新

1. 新增 API，现已支持将指定字符串复制至用户剪贴板。
2. 【属性】面板现已支持显示子组件属性，多选组件时可统一编辑子组件的属性。
3. 现已支持在场景管理器中拖动组件快速将其加入组合或绑定，也可以拖动出组合或解绑。
4. 组件、资源等预设类型属性，现已支持直接复制并粘贴 assetid 进行设置。
