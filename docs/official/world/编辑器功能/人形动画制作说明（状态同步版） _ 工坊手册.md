# 人形动画制作说明（状态同步版）

## 使用FBX文件制作动画

[⬇️ 下载 FBX 文件](https://party.v.netease.com/dl/2026/0806/humanoid.fbx)

### 软件需求

blender，3dsmax，maya（任选其一）

演示所用软件版本：

blender 5.2.0 LTS

3dsmax 2024

maya 2024

### **文件说明**

此骨架为蛋仔派对编辑器世界版内目前使用的人形骨架结构，使用此骨骼文件制作动画，即可直接导入使用。

![图片](https://u5-creator.s3.game.163.com/manual/assets/img_01.Ces8ZT6n.png)

## 通过Blender使用FBX文件

### 注意事项

![图片](https://u5-creator.s3.game.163.com/manual/assets/img_02.DiYnb22q.png)

1. 通过blender导入fbx文件，可以得到如上标准场景
2. 因blender限制，标准fbx骨骼在blender中的八面体显示如上图所示，不能随意修改
3. 不可随意修改场景尺寸
4. 不可增删和重命名任意节点
5. 不允许有关节缩放为 0 的帧

### 使用说明

![图片](https://u5-creator.s3.game.163.com/manual/assets/img_03.DQBDdd1t.png)

1. 切换到Animation workspace
2. 在轨道上制作姿态关键帧
3. 使用默认fbx导出设置，导出场景为fbx文件（如下图）即制作完成

![图片](https://u5-creator.s3.game.163.com/manual/assets/img_04.DDLRC4AN.png)

## **通过3dsmax使用FBX文件**

### 注意事项

![图片](https://u5-creator.s3.game.163.com/manual/assets/img_05.j5Z5sUq5.png)

1. 通过3dsmax导入fbx文件，可以得到如上标准场景
2. 不可随意修改场景尺寸，保持默认
3. 不可增删和重命名任意节点
4. 不允许有关节缩放为 0 的帧

### 使用说明

![图片](https://u5-creator.s3.game.163.com/manual/assets/img_06.CrdbRCsQ.png)

1. 调整轨道插入时间
2. 在轨道上制作骨骼关键姿态并创建关键帧
3. 通过 导出所有（export all）导出，需要勾选 烘焙动画（bake animation）与 重采样（resample all），导出场景为fbx文件（如下图）即制作完成

![图片](https://u5-creator.s3.game.163.com/manual/assets/img_07.Bf7cdKLw.png)

## 使用3dsmax CS骨骼系统（Biped）制作动画

（文件源为3dsmax2024）

[⬇️ 下载 MAX 文件](https://party.v.netease.com/dl/2026/0806/humanoid_max2024.max)

![图片](https://u5-creator.s3.game.163.com/manual/assets/img_11.BFcTvMxN.png)

### **使用说明**

1. 移动时间轴到需要制作关键帧的时刻
2. 通过CS骨骼系统编辑姿态，并添加K帧

![图片](https://u5-creator.s3.game.163.com/manual/assets/img_12.BXGEU3Fr.png)

3. 通过 导出所有（export all）导出，需要勾选 烘焙动画（bake animation）与 重采样（resample all），导出场景为fbx文件（如下图）即制作完成

![图片](https://u5-creator.s3.game.163.com/manual/assets/img_07.Bf7cdKLw.png)
