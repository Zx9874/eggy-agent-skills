# 玩法规则

玩法规则用于针对地图玩法层面调整官方功能的行为，例如组件互动、相机、属性、死亡复位、计时等。

## 入口

点击编辑器顶部工具栏的【规则】按钮打开【规则设置】窗口，左侧选择【玩法规则】。

![](https://u5-creator.s3.game.163.com/manual/assets/rules_1.B1hx0TSz.png)

## 规则列表

玩法规则分为【基础】与【进阶】两个标签页。

### 基础规则

| 规则项 | 用途 |
| --- | --- |
| 组件互动规则 | 玩家与组件互动行为的规则 |
| 任务系统扩展规则 | 任务系统的扩展配置 |
| 相机规则 | 默认相机的行为规则 |
| 物品规则 | 物品相关规则 |
| 基础规则 | 玩法基础规则 |
| 属性规则 | 玩家与组件属性规则 |
| 死亡规则 | 玩家死亡处理规则 |
| 复位规则 | 玩家或组件复位的规则 |
| 按键引导 | 按键引导的显示规则 |
| 观战规则 | 观战相关规则 |
| 匹配和匹配参数规则 | 玩家匹配相关规则 |
| 乐园岛匹配规则 | 乐园岛匹配规则 |

### 进阶规则

切换到【进阶】标签页可查看更高级的规则配置。

## 新增规则

部分规则未默认显示，可通过窗口底部【新增规则】按钮添加。可新增的规则共有 4 项。
