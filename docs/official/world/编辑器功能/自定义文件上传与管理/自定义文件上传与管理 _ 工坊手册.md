# 自定义文件上传与管理

SE 编辑器支持开发者导入本地资源并应用到地图中。在文件管理器中可以上传和管理账号上的自定义文件。

文件管理还支持以下能力：

* 管理和调用**官方资源**，可以快速找到官方 UI 图片素材、音效、组件模型、特效、动作资源的 id 在 LUA 中使用。
* 管理开发者上传的**资源包**中的资源，详见 [资源包](https://u5-creator.s3.game.163.com/manual/se/assetpack.html)。

## 入口

在导航栏中找到【文件】，进入文件管理器。

![功能入口](https://u5-creator.s3.game.163.com/manual/assets/file_entry.BQkiDBC0.png)

## 上传自定义文件

在左侧选中需要上传的资源类型，点击上传。

![界面介绍](https://u5-creator.s3.game.163.com/manual/assets/file_interface.BWqD8jae.png)

目前支持上传的文件类型：

| 类型 | 用途 |
| --- | --- |
| 图片 | 编辑界面、物品、地图商城等系统的素材 / 图标 |
| 音频 | 音效播放器 |
| 模型 | 自定义组件模型 |
| 动作 | 自定义动画动作 |

## 自定义图片

上传的自定义图片支持在编辑界面、物品、地图商城等系统使用，可以作为界面素材或者组件图标使用。

上传标准：

| 项 | 限制 |
| --- | --- |
| 单张大小 | 不大于 3MB |
| 尺寸 | 不大于 1920×1080 |
| 格式 | png / jpg / jpeg |

## 自定义音频

上传的自定义音频支持在音效播放器中使用。

上传标准：

| 项 | 限制 |
| --- | --- |
| 单个文件大小 | 不超过 1MB |
| 时长 | 不超过 60 秒 |
| 格式 | mp3 / wav |
| 其他 | 不能包含封面信息 |

TIP

出现 `-203` 错误码提示一般都是音频格式存在问题，可以使用格式工厂等工具转换音频格式。

## 自定义模型

进入文件管理器后，选中模型分类，点击“选择模型”

![](https://u5-creator.s3.game.163.com/manual/assets/file_modelupload.BNjr-7TK.png)

在跳出的窗口中下拉选中“导入角色（人形骨骼）”的选项，确认后即可呼出文件资源管理器查找本地的模型资源

![](https://u5-creator.s3.game.163.com/manual/assets/file_modelupload2.ie7Hd_WC.png)

## 人形骨骼蒙皮说明

蒙皮与"挂接模型"的区别

`AddMeshByAssetId` 添加的是**蒙皮**，与单位共用同一套骨骼，会跟随所有骨骼动画整体变形，适合衣物、装甲等贴身部件；而挂接模型是作为独立刚体附着在某个骨骼节点上，只跟随该节点的位移旋转，适合武器、道具、饰品等。

### 模型资源规范

具体的骨骼节点规范可参考该模型，导入模型时将校验必选的骨骼节点与命名是否一致

[⬇️ 下载 max 文件](https://party.v.netease.com/2026/0709/model/humanoid_3.5m.max)

### 模型信息设置

模型校验通过后，会先进入骨骼映射关系设置窗口，可在此界面修改模型原骨骼和游戏内的人形骨骼的映射关系

![image](https://u5-creator.s3.game.163.com/manual/assets/file_modelsetting.DpGKO2Uw.png)

确认骨骼关系后，进入模型信息编辑界面，与原流程基本一致

![image](https://u5-creator.s3.game.163.com/manual/assets/file_modeledit.D7A2Fjdt.png)

所有模型资源都拥有对应的资源ID（包括官方资源），使用该ID在接下来的API中索引模型资源

![image](https://u5-creator.s3.game.163.com/manual/assets/file_modeluse.DG4aSy7s.png)
