# 资源包

资源包是一个包含多种类型文件、由其他开发者分享的游戏资产集合。

## 入口

点击文件管理器界面底部的【资源包管理】中可以进入资源包管理器界面。

![](https://u5-creator.s3.game.163.com/manual/assets/assetpack_featureentry.t-tVZ69r.png)

## 资源包的创建与导出

1. 进入资源包管理器后，选择【导出资源包】。

   ![](https://u5-creator.s3.game.163.com/manual/assets/assetpack_output.Z2D7ahaK.png)
2. 在已上传的自定义文件中，选择需要加入资源包的文件，支持多选多个类型的资源。

   ![](https://u5-creator.s3.game.163.com/manual/assets/assetpack_outputfile.DNjbMl_j.png)
3. 在右侧更改资源包的名称和类型，用于标识资源包的用途。

   ![](https://u5-creator.s3.game.163.com/manual/assets/assetpack_outputsetting.BD-PjFgZ.png)
4. 保存资源包后，可以继续配置和修改资源包的内容和信息。确认导出后，即可导出可分享的资源包。

## 资源包分享

如果你是资源包制作方，可以在【导出资源包】里选中之前导出的资源包，点击右下角的详情符号，进入资源包管理界面，再点击右下角导入左侧的省略号。

| 操作 | 说明 |
| --- | --- |
| 复制分享码 | 获得该资源包的分享码，分享给其他玩家使用 |
| 复制并导出 | 复制该资源包的配置创建一个新的资源包项目；由于资源包不能直接修改，可使用这个方法重新创建并在原基础上修改 |
| 删除 | 永久删除该资源包 |

![](https://u5-creator.s3.game.163.com/manual/assets/assetpack_share.Bv1upR0z.png)

分享码使用规则

* 一个分享码的使用时长为 24h。
* 一个分享码最多可以被使用 5 次。
* 已获得资源包的玩家无法重复获得相同的分享资源包。

## 资源包导入

如果你是资源包使用方，在资源包管理器中点击左侧【获取的资源包】，选择【输入分享码】，通过对应的分享码获得其他开发者分享的资源包。

| 选项 | 说明 |
| --- | --- |
| 仅保存 | 资源包将被收录在【获取的资源包】中，一个账号最多可同时拥有 200 个资源包，获取的资源包可以删除 |
| 保存并导入 | 导入的资源包将可以在文件管理中作为已导入资源使用；导入资源跟随草稿，不可被删除 |
