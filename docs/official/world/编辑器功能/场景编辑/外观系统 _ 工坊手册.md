# 外观系统

世界模式编辑器赋予了组件外观编辑更高自由度，你可以使用外观系统更改组件的模型、材质、附加表现，以及更便捷地管理和复用外观相关的数据设定。

## 组件表现

组件属性面板-表现页签能够更改组件的外观和相关设置。

![](https://u5-creator.s3.game.163.com/manual/assets/look_setting.CZW_RP6H.png)

| 属性 | 说明 |
| --- | --- |
| 染色区域 | 修改组件的配色 |
| 模型资源ID | 替换组件使用的模型资源，支持使用自定义文件 |
| 皮肤 | 替换组件使用的材质 |
| 模型可见性 | 运行时模型是否可见 |
| 遮挡玩家时的规则 | 玩家视野被组件遮挡时的渲染处理方式，可设置为不处理\组件半透明\显示玩家虚影 |
| 启用阴影投射 | 打开后运行时会渲染组件在环境光照射下的阴影效果 |
| 使用自定义外观 | 是否使用更多-外观编辑中创建的自定义外观预设，此选项和更改模型资源互斥 |

## 自定义皮肤的创建方式

1. 在上方导航栏中进入预设编辑界面，左侧切换到<组件皮肤>分类。
2. 在通用皮肤中选择一个皮肤作为自定义预设的蓝本，右键选择`复制`，即可创建自定义皮肤预设。

![](https://u5-creator.s3.game.163.com/manual/assets/skinedit_1.DDVBR9g0.png)

3. 选中自定义皮肤预设后，可以在右侧的属性面板中修改预设信息和皮肤材质参数。

![](https://u5-creator.s3.game.163.com/manual/assets/skinedit_2.CDiWtgD5.png)

支持编辑的皮肤参数：

* 粗糙度
* 金属度
* 自发光强度及颜色
* 边缘光开关及强度\颜色\范围
* 纹理缩放\角度\偏移
* 换色\法线\混合贴图

贴图参数区别

| 贴图类型 | 描述 |
| --- | --- |
| 换色贴图 | 更改皮肤的染色区域和总体配色 |
| 法线贴图 | 增加皮肤的凹凸细节信息 |
| 混合贴图 | 控制不同材质在模型上混合生效 |

## 自定义皮肤的应用方式

* 在组件的属性面板中可以用自定义皮肤替换组件原本的皮肤。

![](https://u5-creator.s3.game.163.com/manual/assets/skinuse_1.CtBgq16Y.png)

* 在资源管理器中选中组件右键添加<皮肤组件>类型的子组件

![](https://u5-creator.s3.game.163.com/manual/assets/skinuse_2.BaUGFFpv.png)

在皮肤组件分类下选择空白模版

![](https://u5-creator.s3.game.163.com/manual/assets/skinuse_3.NH4Jdz0h.png)

添加后，在皮肤组件的属性面板可以选择皮肤预设

![](https://u5-creator.s3.game.163.com/manual/assets/skinuse_4.DhxcbP9o.png)

皮肤组件可以移动、复制粘贴为其他组件的子组件，从而替换其他组件的皮肤材质。

当一个组件下存在两个及以上的皮肤组件时，默认应用层级最高的皮肤组件。

## 创建自定义外观

* 制作自定义外观

在主界面导航栏的更多中，打开<外观编辑>

![](https://u5-creator.s3.game.163.com/manual/assets/lookedit_entry.ZOQyKM4K.png)

进入外观编辑界面后，可以新建自定义外观预设。选中创建的自定义外观预设可以进行外观编辑，新建的自定义外观通常为一个ugc方块。

![](https://u5-creator.s3.game.163.com/manual/assets/lookedit_interface.DY5D5Ae4.png)

在右上角的组件列表中添加想加入外观的子组件，支持从预设和场景列表中添加，也可以使用<合并外观>导入之前创建的自定义外观预设。

选中组件列表或视窗中的子组件可以进行编辑，你可以在视窗中更改子组件的大小、旋转角和与主组件的相对距离，在属性面板中调整子组件的精确数值、外观表现和挂点。

在组件列表中选中子组件可以进行复制和删除操作。

作为外观主组件的ugc方块不可以被删除和隐藏，但是可以在属性面板中替换模型资源或更改表现。

* 在资源管理器中选中想要的组件，右键保存为外观预设。 ![](https://u5-creator.s3.game.163.com/manual/assets/lookedit_scene.ui3hvxBV.png)

## 自定义外观的应用

在场景中选中想要改变外观的组件，属性面板-表现中打开<使用自定义外观>，在自定义外观id中选择想要使用的自定义外观预设。

![](https://u5-creator.s3.game.163.com/manual/assets/lookedit_use.BbgFYtjN.png)
