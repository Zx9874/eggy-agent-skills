# 快捷键

掌握世界版/世界模式编辑器快捷键会使我们更容易操作界面，也更加方便制作乐园地图。

点击标题栏【设置】-【快捷键】其中包括主界面，物编界面，触发器界面，表格编辑器等所有操作快捷键。

![](https://u5-creator.s3.game.163.com/manual/assets/settingtool.qR-s0drm.png)

快捷键后边带有“垃圾桶”标志图案可以进行自定义设置。

这里给创作者们附上最常用的系统默认快捷键。
