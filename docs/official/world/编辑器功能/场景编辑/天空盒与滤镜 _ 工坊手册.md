# 天空盒与滤镜

天空盒、灯光、雾效、滤镜等场景渲染相关功能，在状态同步编辑器中通过给 `Lighting` 服务挂接子服务的方式启用，再在子组件自身的属性面板中调整参数。

## 添加方式

1. 在【游戏资源管理器】中右键 `Lighting` 服务，选择【添加子服务】。

   ![](https://u5-creator.s3.game.163.com/manual/assets/lighting_1.qmWo3dpf.png)
2. 在弹出的【选择面板】中选择要添加的子服务类型。

   ![](https://u5-creator.s3.game.163.com/manual/assets/lighting_2.DDA3v_wd.png)
3. 添加后该子服务作为子节点出现在 `Lighting` 下，可在属性面板中调整其参数。

   ![](https://u5-creator.s3.game.163.com/manual/assets/lighting_3.DeB04avI.png)

## 可添加的子服务

| 类型 | 用途 |
| --- | --- |
| 普通天空 | 标准天空背景，含模板预设、旋转、扰动等 |
| 渐变天空 | 通过渐变颜色定义天空 |
| 四色渐变天空 | 四色多段渐变天空 |
| 固定天空 | 固定背景图天空 |
| 泛光效果 | 高亮区域辉光（仅高清模式生效） |
| 色彩分级效果 | 整体颜色调整 |
| 景深效果 | 镜头景深虚化 |
| 雾效 | 大气雾、高度雾、散射 |

## 属性说明

TIP

天空背景、光照、雾效、滤镜的属性与帧同步编辑器完全对标。下面将各类属性逐一列出。

### 天空背景

| 属性类型 | 属性 | 说明 |
| --- | --- | --- |
| 背景图 | X / Y / Z 方向背景偏转 | 天空背景图在 X / Y / Z 轴方向上的偏转角度 |
| 扰动 | 开启扰动 | 扰动功能的总开关 |
|  | 扰动强度 | 扰动强度越高，天空背景缩放的变化越强 |
|  | 扰动密集度 | 扰动密集度越高，天空背景扰动的频率越高 |
| 渐变设置 | 渐变轴向 | 部分天空可自定义渐变颜色，渐变轴向决定颜色的分布方向 |
|  | 渐变颜色 | 决定天空的颜色 |
|  | 渐变轴心位置 | 决定天空颜色的渐变位置的偏移 |
|  | 渐变对比度 | 影响渐变颜色融合的距离 |

### 光照属性

| 属性类型 | 属性 | 说明 |
| --- | --- | --- |
| 太阳光 | 光照强度 | 太阳光是场景中有方向的直接光源，能生成定向阴影。光照强度影响场景的亮度 |
|  | 光的颜色 | 光的颜色直接作用于物体表面的渲染颜色 |
|  | 光照俯仰角 | 光线在竖直方向上旋转的角度 |
|  | 光照偏航角 | 光线在水平方向上旋转的角度 |
| 环境光 | 环境光强度 | 环境光为场景中漫反射的光，影响全局。环境光强度直接作用于漫反射的亮度，天空盒不受该属性影响 |
|  | 环境光颜色 | 直接作用于全场景的光源颜色 |
| 泛光 | 泛光曝光系数 | 直接作用于整个场景的额外曝光度，仅在高清模式下生效 |
|  | 泛光范围 | 亮度的筛选阈值，数值越低，被视为泛光光源的地方越多 |
|  | 泛光强度 | 泛光区域的亮度 |
|  | 泛光扩散度 | 泛光区域的大小 |
| 阴影 | 阴影弱化 | 阴影的不透明度 |
| 高级 | 反射天空图 | 在玻璃、水面等高反射度表面上所呈现的背景图片 |
|  | 颜色细节优化 | 即色调映射，将高动态范围图像转为低动态范围呈现，可有效避免过曝 |

### 雾效属性

| 属性类型 | 属性 | 说明 |
| --- | --- | --- |
| 基础 | 开启雾效 | 雾效的总开关 |
|  | 大气雾颜色 | 大气雾是柱状或环状的雾，颜色将直接作用于场景渲染的一部分颜色 |
|  | 大气雾亮度 | 决定大气雾明度的参数，会乘算与大气雾颜色的明度值 |
|  | 大气雾浓度 | 类似雾的不透明度，越浓参与场景渲染的百分比越高 |
|  | 大气雾能见度 | 雾效开始生效的距离，可为负数，从相机开始计算 |
|  | 雾衰减的起始距离 | 雾效开始衰减不再增长的距离 |
|  | 高度雾颜色 | 高度雾无限广阔但有高度限制，颜色作用于场景渲染 |
|  | 高度雾浓度 | 类似雾的不透明度 |
|  | 天空背景受雾效影响 | 是否将雾效渲染到天空背景之上 |
|  | 高度雾衰减起始高度 | 高度雾不再变浓的高度 |
|  | 高度雾消失高度 | 高度雾彻底衰减为 0 的高度 |
| 太阳光在高度雾中散射 | 散射光颜色 | 太阳光在雾中的弥散颜色 |
|  | 散射光收束度 | 收束度越高，弥散效果越少 |
|  | 散射作用结束距离 | 距离相机此距离开始弥散效果不再增强 |
|  | 散射光高度 | 弥散效果的亮度 |
|  | 散射受大气雾影响程度 | 数值为 0 时散射只受高度雾影响，为 1 时只受大气雾影响 |

### 滤镜属性

| 属性类型 | 属性 | 说明 |
| --- | --- | --- |
| 调节 | 开启调色 | 全局开关，控制是否启用所有颜色调整效果 |
|  | 饱和度 / 对比度 / 亮度 / 色温 | 整体颜色调节参数 |
| 后处理 | 色调映射 | 控制 HDR 到 LDR 的转换曲线 |
|  | 暗角 | 边角变暗效果 |
|  | 颗粒 | 画面颗粒感效果 |

滤镜的具体属性较多，详细列表与帧同步编辑器一致，可参考帧同步文档。

## 注意事项

* 可以在 `Lighting` 下添加多个天空球，但**只有第一个**会生效。
* 运行时可以通过移动、创建、删除天空球子组件来切换天空球。
* 帧同步编辑器中的天空球切换特效（如燃烧、电子等过渡效果）**暂不支持**。
