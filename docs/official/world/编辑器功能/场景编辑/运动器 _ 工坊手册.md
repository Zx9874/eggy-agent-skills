# 运动器

运动器是一种子组件，挂接到场景组件下后，场景组件即可获得对应的位移、旋转或路径运动行为。一个场景组件下可以挂多个运动器，多个运动器的效果会叠加。

## 添加运动器

1. 将场景组件的物理类型设置为**运动物体**（参见 [组件 - 物理状态](https://u5-creator.s3.game.163.com/manual/se/scene_editor/unit.html#物理状态)）。
2. 选中该组件，在右侧属性面板中找到【运动器】标签页。
3. 点击对应的【添加 xxx 运动器】按钮即可添加。

![属性面板运动器标签页](https://u5-creator.s3.game.163.com/manual/assets/motor_1.T5w3aE8z.png)![添加运动器按钮列表](https://u5-creator.s3.game.163.com/manual/assets/motor_2.CXoao7kH.png)

添加后，运动器会作为子组件出现在目标组件下方，并可以通过属性面板修改运动器属性。

WARNING

组件物理类型不是运动物体时，属性面板的【运动器】标签页内不会显示添加按钮。

## 运动器类型

状态同步编辑器提供以下五种运动器：

| 类型 | 说明 |
| --- | --- |
| 直线运动器 | 沿固定方向做匀速直线往复运动 |
| 圆周运动器 | 绕指定轴心做匀速圆周或限定角度旋转 |
| 沿路径运动器 | 按预设路径点依次移动 |
| 单摆运动器 | 绕轴心做钟摆式来回摆动 |
| 变速运动器 | 沿直线或圆周做变速运动 |

## 通用属性

所有运动器共享一组通用属性：

| 属性 | 说明 |
| --- | --- |
| 名称 | 运动器自定义名称，便于在场景管理和脚本中识别 |
| 初始延迟时间 | 运动开始前等待的时间 |
| 运动相对方向 | 局部空间 / 世界空间。世界空间下方向相对世界坐标系不变；局部空间下以父组件为原点，跟随父组件的旋转而变化 |
| 重复执行运动 | 勾选后运动结束自动重新开始；不勾选则单次运动结束后停止 |
| 使运动开启的事件 | 组件接收到该事件时，开始运动 |
| 使运动停止的事件 | 组件接收到该事件时，停止运动 |
| 运动失效时间 | 运动器失效的总时间。当时间结束后，运动器失效，组件运动停止 |

## 直线运动器

将组件沿固定方向做匀速直线运动，可设置直线移动、停顿、返程、重复执行等行为。

### 关键属性

| 属性 | 说明 |
| --- | --- |
| X / Y / Z 方向线速度 | 组件朝 X / Y / Z 轴方向直线运动的速度 |
| 单程运动时间 | 组件运动到中途的时间 |
| 单程停顿时间 | 组件运动到中途，在返程前停留的时间 |
| 到达后返程 | 勾选后到达终点会原速返回起点 |
| 返程后停顿时间 | 组件返回到起点后停留的时间 |
| 被暂停时返程 | 勾选后，物体接收到事件暂停时，会以原速度回到原来的方向 |
| 显示运动指示器 | 勾选后场景中会显示运动方向与终点指示器，便于在编辑期定位运动终点 |

## 圆周运动器

将组件绕指定轴心做匀速旋转，与直线运动器的设置流程相似。圆周运动器没有运动指示器，设置完成后可点击【运动测试】预览效果。

### 关键属性

| 属性 | 说明 |
| --- | --- |
| 角速度 | X / Y / Z 三轴的角速度，决定旋转方向与速度 |
| 单程运动时间 | 组件旋转到中途的时间 |
| 到达后停顿时间 | 组件旋转到中途，在返程前停留的时间 |
| 被暂停时返程 | 勾选时，组件被事件暂停后以原速度旋转回原来的方向 |
| 重复执行运动 | 勾选后组件往返旋转；不勾选时组件在一个方向重复旋转 |

## 沿路径运动器

将组件按路点设置依次移动，路点设置可改变组件在每段路径上的大小、方向、移动时间。

### 关键属性

| 属性 | 说明 |
| --- | --- |
| 路径样式 | 直线 / 曲线插值。直线为路点间直线移动；曲线插值为路点间平滑曲线移动 |
| 是否重复执行运动 | 勾选后运动完毕后会往返继续运动；不勾选则物体在一个方向重复运动 |

### 路点设置

每个路点可独立设置：

| 路点参数 | 说明 |
| --- | --- |
| 路点位置 | 通过移动虚影组件指定路点的世界位置 |
| 到达时间 | 从上一路点到达本路点的耗时 |
| 路点缩放 | 到达本路点时组件的缩放比例 |
| 路点旋转 | 到达本路点时组件的朝向 |

## 单摆运动器

将组件绕指定轴心做钟摆式来回摆动。

### 关键属性

| 属性 | 说明 |
| --- | --- |
| 角速度 | X / Y / Z 三轴的角速度，决定摆动的轴向与速度 |
| 初始延迟时间 | 运动开始前等待的时间 |
| 是否循环 | 勾选后开启循环往返摆动；不勾选时单次摆动结束后停止 |
| 是否启用 | 是否启用该运动器 |
| 开启返程 | 仅在【是否循环】启用后可见。勾选后，到达终点会原速返回起点 |
| 单程运动时间 | 仅在【是否循环】启用后可见。单次摆动从起点到终点的耗时 |
| 到达后暂停时间 | 仅在【是否循环】启用后可见。到达终点后的停留时间 |
| 运动持续时间 | 运动器总持续时间 |
| 运动开始事件 | 收到该自定义事件时启动运动器 |
| 运动结束事件 | 收到该自定义事件时停止运动器 |

## 变速运动器

将组件在加速运动后，按加速后的速度做匀速运动。可选直线或圆周变速。

### 关键属性

| 属性 | 说明 |
| --- | --- |
| 运动类型 | 直线运动 / 圆周运动。分别为沿直线方向的变速运动和绕重心的圆周变速运动 |
| 加速时长 | 组件做加速运动的时长 |
| 匀速时长 | 加速结束后，按照加速后的速度匀速运动的时长 |
| 直线加速度 | X / Y / Z 三轴的加速度（运动类型为直线时） |
| 初始延迟时间 | 运动开始前等待的时间 |
| 是否循环 | 勾选后开启循环 |
| 是否启用 | 是否启用该运动器 |
| 开启返程 | 仅在【是否循环】启用后可见。勾选后，到达终点会原速返回起点 |
| 单程运动时间 | 仅在【是否循环】启用后可见 |
| 到达后暂停时间 | 仅在【是否循环】启用后可见。到达终点后的停留时间 |
| 返程后暂停时间 | 仅在【是否循环】启用后可见。返回起点后的停留时间 |
| 运动持续时间 | 运动器总持续时间 |
| 运动开始事件 | 收到该自定义事件时启动运动器 |
| 运动结束事件 | 收到该自定义事件时停止运动器 |

## 使用案例

### 案例 1：移动平台

利用直线运动器制作可移动地板，配合【重复运动】+【到达后返程】可实现往返循环移动。

![](https://u5-creator.s3.game.163.com/manual/assets/3.1.1.29kgNBNW.gif)

### 案例 2：组合运动

多个组件分别挂运动器并配合时间参数，可实现联动效果。例如礼物盒效果中，盒盖使用圆周运动器实现打开 / 关闭，盒内组件使用沿路径运动器实现缩放变化。

![](https://u5-creator.s3.game.163.com/manual/assets/3.2.1.DGUIBQT3.gif)

## 注意事项

* 同一场景组件下的运动器没有数量上限，但叠加过多可能导致效果难以预期，建议拆分到多个组件上。
* 启动 / 停止事件名称需与触发源（触发区域、蛋码、脚本）发出的事件名严格一致。
