# 蛋仔 AI 编程助手

## 什么是 AI 蛋仔编程助手？

蛋仔派对开发团队研发提供的 AI 智能体系统，帮助您在地图编辑器内：

1. 编写 Lua 代码来制作完善您的地图。
2. 帮您查询官方文档、手册等资料，解答您在开发过程中遇到的问题。

![](https://u5-creator.s3.game.163.com/manual/assets/ai_assistant_1.CauoRfPH.png)

## 如何安装和使用？

### 安装

1. 需要安装 Visual Studio Code（最低版本：1.82.0）
2. 通过编辑器顶部菜单栏找到 “LUA” ，打开子菜单后选择“蛋仔开发助手”，创建并通过 Visual Studio Code 打开当前地图的 Lua 工程后，会自动下载安装
3. 在 “LUA” 子菜单中找到 “Editor CLI” 分支并选择启用，编辑器将会自动在地图的 Lua 工程中初始化编程助手的工作目录，并且启用编辑器与编程助手的连接机制

### 使用

1. 在 Visual Studio Code 的插件栏中找到并点击编程助手的图标打开页面
2. 在底部的聊天框内打字聊天即可与 AI 编程助手通过自然语言交流的方式开始工作

### AI 大语言模型选择

* 使用官方提供的大语言模型
  1. 在聊天输入框的底部找到模型显示/选择按钮
  2. 点击后在打开的列表内直接选择
* 连接您个人的大语言模型账户
  1. 在聊天输入框的底部找到设置按钮
  2. 点击后找到“自定义模型服务商”的选项，随后点击右边的配置按钮
  3. 在弹出的窗口中可以根据提示配置你个人的大语言模型账户（目前暂只支持 OpenAI 兼容形式的接口）
  4. 接口信息填写完成后系统会自动检测可以使用的模型
  5. 配置完成后，可以通过选择官方模型一样的方式选择您配置好的模型

## 功能扩展与自定义

系统支持三级扩展

### 一、规则（ Rule ）扩展

类似于给 AI 指定规则规范，通过纯文本的形式扩展，每一轮对话都会**强制** AI 阅读所有生效的规则的文本，适用于编写通用的规则规范、补充当前工作区的信息等。

**扩展方法**：

1. 在聊天输入框的底部找到“自定义 Rules”的按钮
2. 点击后在打开的窗口的右上角找到“管理 Rules”
3. 点击后可在窗口内新建、编辑、删除所有当前工作目录中的规则

**注意事项**：

1. 直接使用自然语言编写即可，最好是 Markdown 格式的文本
2. 规则文件不宜过多或者单个文件不宜过长，建议只将通用的信息放在规则文件中，其他的信息可以通过其他方式扩展给智能体使用

### 二、工具（ Tool ）扩展

类似于给 AI 增加特殊能力，通过 MCP 服务的形式扩展，每一轮对话都会把可用的所有工具的描述告知给 AI，AI 会在需要使用的时候**自行**选择使用。

**扩展方法**：

1. 在聊天输入框的底部找到设置按钮
2. 点击后找到 “MCP Server” 的选项，随后点击最右侧的配置按钮
3. 在弹出的窗口中选择“更多 MCP”页签，然后点击“添加自定义服务”

**注意事项**：

1. 避免配置过多的工具（大于 40 个），会造成大模型的使用费用显著增加

### 三、技能（ Skill ）扩展

类似于给 AI 灌输特定的知识，通过纯文本的形式扩展，每一轮对话都会把可用的所有技能的名字和描述告知给 AI，AI 会在需要使用的时候**自行**选择使用。

**扩展方法**：

遵循 Agent Skills 的开放标准，在 Lua 工程的根目录下的 `.codemaker/skills` 目录下创建新的文件夹和相关 `SKILL.md`。也可和智能体直接对话，让它帮助你处理。
