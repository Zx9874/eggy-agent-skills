# 原点编辑器 · 角色 · 资产目录

本表汇总了该分类下的全部组件资产，方便你在搭建地图时快速检索可用的组件。每条记录的列由导出配置（config.json 的 export\_fields）指定，列表头为属性的中文名。

「描述」列（若有）用于概括组件的外观特征，帮助你在没有预览图时大致判断组件的样子；它不代表组件的功能或用途。

> 资产数量较多，建议使用浏览器的页内查找（Ctrl + F）按名称或编号快速定位。

> 原始数据：[下载角色信息 CSV](https://u5-creator.s3.game.163.com/manual/fs/char.csv)，可作为检索或二次加工的数据源。
