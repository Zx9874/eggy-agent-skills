# 初期使用（编辑器限制&潜规则）

## 1.蛋仔编辑器为什么发布地图失败

* 检查地图占用值/文件大小；
* 确认地图名称是否合法；
* 检查账号地图发布数量限制；
* 确保满足过关条件（仅限于lua地图）

## 2.蛋仔编辑器的项目文件保存在哪里？

蛋仔编辑器项目文件均保存在云端，在本地除了lua文件之外，没有项目的其他明文文件。

## 3. 蛋仔编辑器如何做版本管理？

蛋仔编辑器拥有端内自带的草稿存档功能，可以在编辑器内的【设置】-【云存档】-【存档管理】界面进行“存档”、“读档”工作进行版本管理

每张地图草稿有六个存档栏位

![](https://u5-creator.s3.game.163.com/manual/assets/6.AGw6MJUY.png)

## 4. 蛋仔编辑器如何使用AI写代码，比如cursor？

暂时无法使用外部ai编程工具写代码，未来我们会有内置的ai编程工具，可以考虑使用vscode安装蛋仔开发助手进行ai编程。

[**详情请点击这里**](https://u5-creator.s3.game.163.com/manual/pc_md/lua/lua_eggitor.html)

## 5. 如何上传自定义图片当做封面（KV）?

目前只支持PC端编辑器，在地图发布的时候点击【+】上传

## 6. 蛋仔编辑器无法识别IDE工具的文件夹？IDE软件找不到插件

目前只支持1.8.0以上的VScode版本

如果存在IDE软件无法打开插件，请前往【蛋仔派对PC编辑器创作者交流群】（qq：667875764）的【群文件】下载群插件

![](https://u5-creator.s3.game.163.com/manual/assets/7.B8H_ZuS6.png)

## 7. 云存档表格在哪，是jason表或者msgpack表么？

目前蛋仔不支持外部的json表格，数据库都在云端，访问只能通过端内的多维表格编辑器

## 8.目前编辑器有哪些大小及性能限制？

| 类型 | 单个文件 | 全部文件 |
| --- | --- | --- |
| 自定义外部文件大小 | 100MB | 无 |
| 存档（云变量）表格大小 | 20K | 50K |
| 地图存储大小 | 5MB | 无 |
| 玩家存档的数据（字符串存储限制） | 25.6k | 无 |

## 9.如何上传自定义模型和图片？上传自定义模型的限制？

目前上传自定义模型和自定义图片都有权限限制，自定义图片需要10000工匠点，自定义模型需要工匠级别7级以上，如果需要可以找地图蛋申请

| 类型 | 组件 | 生物 |
| --- | --- | --- |
| 面数 | 10000面 | 20000面 |

## 11.组件占用值有哪些限制？

组件占用初始为25000，后续上限和工匠点数量有关。达到五十万工匠点后可以解锁无限占用值。

## 12.性能问题，同屏单位数量有无限制？

目前蛋仔编辑器底层是帧同步编辑器，同屏人数建议在30个单位以下，未来会有性能强大的状态同步编辑器

## 13.游戏场景大小有无限制？超了怎么办？

目前游戏对场景大小有限制，限制为 + / - 5000

如果超过了5000，需要您自己修改地图场景

## 14.自定义文件大小的限制问题？

目前蛋仔单张地图可的自定义文件大小最大为100M。

## 15.关于【新建地图】的一些问题

如果是专业团队，不建议使用预制模版，直接新建一个【空白地图】

因为模版一般都有依赖库限制（蛋仔无法本地改依赖库内容），可能需要强制通关才能发布

## 16.PC编辑器如果有一些不符合预期的设定，比如商业化不允许修改商品折扣

目前建议使用移动端编辑器解决这类问题，之后也会追加PC编辑器对部分功能的支持。

## 17.关于蛋仔的版本发布及审核机制

蛋仔目前没有正式【游戏版本】的审核，点击【发布】地图后游戏在机审之后即刻上架，但是如果地图内存在商业化商品，则会有明确的人工审核，如果人工审核不通过，地图也无法发布。

其中：

1.商城内【道具】每次需要提审，且过审之后只能修改【分类】和【折扣】，价格无法修改，每个【道具】可以对应多个【商品】，商品不需要审核。

2.盲盒只有第一次需要审核，后续改变盲盒内【道具】之外的东西也无需审核。

3.手册商品，提审通过之后无法修改。

## 18.外部IDE工具连不上怎么办？

外部IDE工具（比如vscode）连接不上蛋仔开发助手，重启工程/换端口号也失效

可以考虑先把外部IDE工具关掉，再重新打开蛋仔小助手

## 19.相似度和限流相关问题

目前会对【发布】（无论是否公开、上下架状态）都会检测组件相似度，如果相似度过高就会被限流，如果发现地图流量异常很可能是命中了这条限流规则

如果出现这种情况，请尝试【销毁】之前自己相似的地图，并且重新发布，或者大幅度改变后发图的地图场景组件。如有其他问题，请联系官方。

## 20.载具默认就开了？默认开启的【规则】问题？

蛋仔编辑器【规则】默认开启载具，所以您的游戏没有相关设计，最好关闭一下载具
