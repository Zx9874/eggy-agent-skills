# 物品商店

玩家可以在物品商店购买或出售物品，也可以将地图商城的道具上架到物品商店。

## 功能入口

【更多】→【物品系统】→【物品商店】 ![](https://u5-creator.s3.game.163.com/manual/assets/equip_10.BavIDd_q.png)

## 上架商品

点击【添加商品】即可弹出商品选择列表 ![](https://u5-creator.s3.game.163.com/manual/assets/equip_11.BGOMlyo9.png)

选择要上架的物品或商场道具进行上架 ![](https://u5-creator.s3.game.163.com/manual/assets/equip_12.BGAjjkqX.png)

这里选择了【圣诞礼物盒1】，新的商品就成功上架啦！ ![](https://u5-creator.s3.game.163.com/manual/assets/equip_13.M7OQdsKn.png)

注意：在商店内，相同的物品不能重复进行上架

## 商品属性

| 名称 | 描述 |
| --- | --- |
| 出售物品 | 该商品出售的物品，可点击修改为其它物品 |
| 获取方式 | 拥有【购买】和【合成】2种获取方式 |
| 商品价格 | 获取方式为购买时显示，可配置购买该商品所需的货币 |
| 合成素材 | 获取方式为合成时显示，可配置购买该商品所需的素材 |
| 购买开始时间 | 游戏开始多久后该商品在物品商店可购买 |
| 初始库存 | 该商品初始的库存数量，每次购买会消耗1库存 |
| 最大库存 | 该商品的可恢复的最大库存 |
| 库存恢复时间 | 每隔多少秒恢复1库存，库存不足时无法购买 |
| 上架状态 | 上架状态关闭时，不会在商店显示 |
| 上架事件 | 触发该事件时，物品的上架状态会开启 |
| 下架事件 | 触发该事件时，物品的上架状态会关闭 |

  

备注：

1. 商品价格最多可配置4种货币，货币实质上是规则设置中的玩家属性
2. 合成素材既可以选择物品，也可以选择货币（玩家属性），从而实现类似合成费用的概念
3. 购买物品所需的资源与物品本身的价值是无关的，你可以在不同的商店给同一个物品配置不同的出售价格，但是将物品出售给这些商店所获得的货币是一致的，即：将物品卖给商店所获得的货币由物品本身决定，在商店购买物品所消耗的货币由商店决定 商店管理

  

## 商店管理

可以在顶部的分类中修改分类的名称或者增加新的分类，可以通过长按拖拽修改商品的分类和排序 ![](https://u5-creator.s3.game.163.com/manual/assets/equip_14.BSDMrPza.png)

如果不想要该商品了，也可以选中商品点击属性界面底部的【删除商品】 ![](https://u5-creator.s3.game.163.com/manual/assets/equip_15.DF_nfpMC.png)

左下角的商店管理进入后可配置商品的属性 ![](https://u5-creator.s3.game.163.com/manual/assets/equip_16.C_sEcL38.png)

可新建、删除商店，修改商店的名称以及配置商店的显示事件

显示事件：当触发显示事件时商店界面会显示 ![](https://u5-creator.s3.game.163.com/manual/assets/equip_17.DVC8wLZB.png)

## 互动配置

商店怎么能没有老板呢！为生物添加一个商店让它当老板吧！在场景编辑界面放置任意一个蛋仔生物，选中该生物，进入高级设置，添加互动 ![](https://u5-creator.s3.game.163.com/manual/assets/equip_18.D_5MHVU6.png)

将互动类型更改为【物品商店】，将商店属性配置你想要的商店，就可以在游玩时与它互动打开商店啦！ ![](https://u5-creator.s3.game.163.com/manual/assets/equip_19.ByjRYhQC.png)

试玩时靠近它会显示交互按钮，点击即可打开商店了。 ![](https://u5-creator.s3.game.163.com/manual/assets/equip_20.xmepAuVQ.png)![](https://u5-creator.s3.game.163.com/manual/assets/equip_21.BwWmK6qH.png)

如果你觉得从头配置一个商店很麻烦，也可以直接使用生物中的探险蛋，它配置好了默认的商店互动
