# 物品概述

物品是一种特殊的组件类型，具有**可携带、可使用、可交易**的特性，可以灵活地在实体形态和抽象形态之间切换。

比如，它既可以是能拾取收集的组件，也可以是用来强化角色能力的装备，还可以是商店货架上的商品。

![](https://u5-creator.s3.game.163.com/manual/assets/equip_1.B_ey06RJ.png)

### 可携带

场景中的物品组件可以被拾取，玩家进入物品组件的拾取范围内可以触发物品交互，点击后玩家获得该物品并收纳至物品格或背包中，背包里同类物品可以堆叠。

玩家可以使用、移动和丢弃携带的物品，玩家持有的物品可以在【游玩进度】（规则设置）中开启存档。

> [物品格]：用于收纳物品的界面控件，可以在【编辑界面】中拖出使用。
>
> [背包]：一个完整的背包界面，包括【编辑界面】的打开背包ui（用于开启背包），以及更多-【物品系统】里物品背包页面配置的背包界面样式（用于预览背包界面排版），以及【预设编辑】里角色身上配置的装配区数量与储物区数量（决定背包能够放多少东西）。

### 可使用

物品组件支持附加特殊功能，比如在角色装配物品时给角色添加外观表现、属性加成和技能预设，甚至可以将操作模式转为射击模式。

你可以利用物品的特性，将它制作成可充能的枪械、附带挥斩技能的长剑、具有属性加成的装备，也可以将它制作为消耗型的道具，使用后为角色带来增益效果。

物品特性可以在实体（高级设置）或预设（预设编辑）上设置，还支持使用蛋码编写更多逻辑。

### 可交易

物品组件可以在地图当中进行交易，在【物品商店】（物品系统）界面上架物品到局内商店后，玩家可以使用局内货币购买商店里的物品。

物品的价格和价值属性并不等同，价值在物品实体或预设上设置，等于商店回收价格（玩家向商店出售该物品的价格）；价格在商店商品设置界面设置，等于商店售卖价格（玩家从商店购买的价格）。

除了购买，物品也支持设置为合成获取，可以设置玩家属性和其他物品作为合成素材，玩家将在商店进行合成兑换。

物品商店是物品交易的主要场所，仅涉及玩家与系统之间的物品交换。商店可以作为互动挂载到普通组件以及生物上，也可以在蛋码中编写界面弹出逻辑。

> [局内货币]：使用规则设置中属性规则设置的玩家属性制作，地图草稿会默认附带一个金币属性，你也可以添加额外的属性作为货币使用。局内货币与地图商业化收益无关。

## 功能入口

物品系统的入口位于【更多】→【物品系统】

![](https://u5-creator.s3.game.163.com/manual/assets/equip_2.DXU4emLE.png)

进入后，启动物品功能，即可在当前地图使用物品系统，使蛋仔可以拾取和使用物品。

![](https://u5-creator.s3.game.163.com/manual/assets/equip_3.BVwvj9di.png)

## 关联功能

物品系统是一个由多个功能模块组合的系统，包含以下模块：

### 物品预设

>>>[点击跳转物品预设详情](https://u5-creator.s3.game.163.com/manual/mobile/equip/equip_prefab.html)

物品系统的核心部分，操作的物品对象均来自物品预设，入口位于【更多】→【预设编辑】→【组件库】→【物品】

### 物品商店

>>>[点击跳转物品商店详情](https://u5-creator.s3.game.163.com/manual/mobile/equip/equip_shop.html)

物品商店可以购买、出售、合成物品，是物品系统中作为RPG玩法的一部分

### 物品背包

>>>[点击跳转物品背包详情](https://u5-creator.s3.game.163.com/manual/mobile/equip/equip_backpack.html)

物品背包是官方预设的持有物品后的交互表现界面，可以查看拥有的所有物品并进行丢弃、移动、使用、查看详情等行为

### 功能控件

编辑界面中存在以下与物品关联的功能控件：

```
- 物品格：显示持有的物品，可进行使用、拖拽，查看详情。
- 放进背包：将物品拖拽到该按钮上，即可将物品放入【储物区】内。
- 物品丢弃：将物品拖拽到该按钮上，即可将物品丢弃。
- 打开背包：点击该按钮即可打开背包。
- 物品技能：可施放指定物品槽位上的物品技能。
- 选中物品技能：可施放当前选中物品的技能。
```

## 预设界面

物品系统中默认配备了一套物品的交互界面，可以在【界面功能显示】中进行对该界面内的每个控件的显示进行配置，同时该交互界面自带了一些交互上的功能处理，当关闭【界面功能显示】时，所有的功能均会失效，界面也不再显示

武器获得自动选中：开启后，获得武器时会自动将其选中

拾取物品丢弃切换：当装配区的物品格已满，拾取新武器时会丢弃当前选中的物品，拾取该物品

物品格样式：

* 枪械物品格x1：显示1个枪械物品格
* 枪械物品格x2：显示2个枪械物品格
* 枪械物品格x3：显示3个枪械物品格
* 固定物品格列表：显示一行方形物品格，会根据角色的装配区数量自适应显示
* 滑动物品格列表：显示2行物品格列表，如果角色的装配区数量超出2行可以向下滑动显示更多，但是该样式需要长按拖动物品

隐藏左侧开火键：隐藏左侧的物品技能使用按键

隐藏右侧开火键：隐藏右侧的物品技能使用按键

隐藏丢弃物品键：隐藏右上角的物品丢弃按键

隐藏放入背包键：隐藏右上角的放入背包按键

隐藏打开背包键：隐藏右下角的背包按键

隐藏物品格：隐藏物品格的显示

物品格显示类型：

* 获取武器时显示：获取武器类型的物品时才显示物品格
* 获取物品时显示：获取任意类型的物品都会显示物品格
* 常驻显示：默认保持显示物品格
