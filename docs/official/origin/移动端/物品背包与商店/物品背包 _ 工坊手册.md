# 物品背包

物品背包是官方预设的游玩时物品查看界面，可以使用、丢弃、移动物品位置。

## 功能入口

【更多】→【物品系统】→【物品背包】

![](https://u5-creator.s3.game.163.com/manual/assets/equip_5.mX2Tshjm.png)

角色可以配置背包属性，游玩时如果拾取了物品就会显示出背包按钮，点击背包按钮打开背包界面即可查看当前持有的物品

![](https://u5-creator.s3.game.163.com/manual/assets/equip_6.DtLmduz8.png)![](https://u5-creator.s3.game.163.com/manual/assets/equip_7.BxGxz98-.png)

## 属性释义

**背包属性**

* 名称：背包的名称，不会在游玩时显示，仅编辑时可见
* 绑定角色：该背包绑定了哪些蛋仔角色
* 显示事件：触发该事件时，会显示背包界面
* 是否分类：开启后，背包可以配置多个分类，根据需要设置不同分类显示的内容，通常不需要开启

**分类属性**

* 分类名称：分类的名称，不会在游玩时显示，仅编辑时可见
* 布局模板：分类的布局模板，拥有以下方案
  + 通用模板：通用的布局模板，区分了装配区和储物区，装配区的物品格未进行功能名称划分
  + 储物背包：仅拥有储物区的模板，如果不需要装配区的显示可使用该模板
  + 角色扮演：在通用模板的基础上，为装配区的物品格配置了角色模板玩法的功能区分
  + 枪战射击：在通用模板的基础上，为装配区的物品格配置了枪战玩法的功能区分
  + 分类图标：分类的图标

**物品格属性**

* 物品格名称：物品格的名称，会显示在物品格的底部，游玩时可见
* 显示物品格名称：关闭后不会在物品格底部显示物品格的名称
* 物品格图标：物品格的图标，该物品格未放置物品时显示，适用于对物品格功能进行分类标识
* 物品格图标叠加色：可影响物品格图标的颜色
* 物品格ID：物品格的槽位ID，通常用于与功能控件的物品格进行对应
* 放置标签要求：物品放置到该物品格槽位需要满足该要求

## 背包管理

在功能左下角点击【背包管理】可进入管理界面 ![](https://u5-creator.s3.game.163.com/manual/assets/equip_8.CfFlVX7d.png) 在管理界面可创建、复制、删除、修改背包的属性，以及将背包绑定到角色上 ![](https://u5-creator.s3.game.163.com/manual/assets/equip_9.BBlTtq31.png)
