# 物品预设

物品预设是物品系统的核心，各个系统交互的对象均是物品预设

## 功能入口

【更多】-【预设编辑】-【组件库】-【物品】

## 属性释义

物品预设的属性较为繁杂，根据自己的使用所需进行配置

**基础属性**

* 名称：物品的名称
* 描述：物品的描述，在查看详情时会显示
* 标签：物品的标签，可以作为蛋码的逻辑判断使用
* 物品类型：物品分为基础和武器两类，武器类物品被拾取进入装配区时，会显示预设的物品交互界面。

**表现**

* 图标：物品在物品格、背包、商店等界面中显示的图标
* 编辑物品外观：影响物品摆放在场景上时的显示
* 引用场景对象为外观：可以选择场景上的组件作为该物品的外观，先在场景上合并出一个模型，然后使用该功能即可将合并结果作为物品外观
* 适配骨骼：影响持有物品时的绑定外观表现，只有适配骨骼与持有者的骨骼一致时绑定表现才会正常显示
* 选中物品时角色表现：游玩时选中物品格可激活选中态，此时会显示该属性配置的绑定表现，适合绑定需要切换的武器外观
* 选中物品时角色表现
  + 操作模式：分为【默认】和【射击】，操作模式为射击时会开启屏幕准星，适用于需要瞄准的功能。
  + 持有动画类型：分为【默认】和【射击】，影响表现中可使用的动画，类型为默认时可单独配置待机、移动、跳跃动画，类型为射击时可配置射击动画组。
  + 选中时镜头变化：选中该物品时的镜头变化。
  + 储物区是否生效：该物品在储物区被选中时，该选中物品时角色表现是否生效。
  + 表现
    - 选中时待机动画
    - 选中时移动动画
    - 选中时跳跃动画
  + 准星配置
    - 辅助瞄准开关：开启后，准星会在接近敌人时自动吸附。
    - 自动开火开关：开启后，准星对准敌人时会自动施放物品的技能。
    - 显示自动开火按钮：影响游玩时自动开火按钮的显示。
    - 准星样式：屏幕中心准星的样式。
    - 准星图标：准星样式为自定义时可编辑，能自定义准星的样式。
    - 准星颜色：可影响准星的颜色。
    - 准星选中颜色：准星瞄准敌人时的颜色。
    - 默认准星半径：准星的默认半径
    - 最小准星半径
    - 最大准星半径
    - 开启散射：开启后物品技能施放时会产生一定的随机散射效果。
    - 每次射击扩散距离：影响每次施放物品技能后准星的增大幅度。
    - 扩散恢复速度：影响准星缩小的速度。
    - 扩散恢复延迟时间：施放物品技能多久后开始扩散恢复。
* 装配表现：只要物品在装配区就会激活该表现，适用于盔甲、翅膀等常驻外观。

**特殊**

* 堆叠类型：分为【基础】和【充能】；基础类型适用于数量的堆叠，例如5块石头堆叠到一起；充能类型适用于可恢复的堆叠，例如枪械的子弹。
* 自动堆叠：开启后，重复获得该物品时会自动进行堆叠直到最大堆叠层数。
* 初始堆叠层数：物品在创建时默认的堆叠层数。
* 最大堆叠层数：单个物品格内可堆叠的最大层数。
* 使用消耗层数：使用该物品时消耗的层数。
* 编辑充能表现：该物品进行充能时的表现，可配置充能时间、消耗、动画、提示等。
* 能否使用：关闭时，物品无法使用。
* 自动拾取：开启后，靠近物品会自动拾取。
* 能否丢弃：关闭时，物品无法丢弃。
* 丢弃销毁：开启后，物品被丢失时会自动销毁。
* 互动距离：拾取物品的半径。
* 额外属性：物品在装配区时为持有者提供的额外属性。
* 属性加成（百分比）：物品在装配区时为持有者提供的属性加成，以百分比计算。
* 价值：物品出售给商店时获得的玩家属性。
* 技能：使用物品时会发动技能。
  + 物品如果未配置技能，则会被视为无法使用。
  + 如果界面上存在物品技能或选中物品技能的功能控件，这里配置的技能会显示到控件上
* 自定义属性

  

## 名称解释：物品槽位

角色或生物持有物品需要拥有物品槽位，物品槽位分类【装配区】和【储物区】，只有装配区的物品才能使用和激活属性加成，储物区仅用于保存物品，类似于仓库。

如果要配置具体对象的属性需前往【更多 - 高级功能 - 预设编辑 - 角色/生物】

选中任意角色或生物预设，在【基础 - 物品】分类内可看到【物品装配区数量】和【物品储物区数量】，这两个属性决定了角色或生物可携带的物品数量上限。
