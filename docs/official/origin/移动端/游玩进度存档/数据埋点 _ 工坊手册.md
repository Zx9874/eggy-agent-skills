# 数据埋点

数据埋点功能将帮助你收集游玩数据，观测玩家在游玩时的行动，从而调整地图内容。

【视频教学】[数据埋点的使用](https://egg-shell.fp.ps.netease.com/file/6901b6b097ddf9feb94a8d6aecEpKE6a06)

## 设置数据埋点

在【更多-规则设置-游玩进度】界面，可以找到数据埋点功能入口。

新建数据埋点，我们就可以在想要收集数据的环节进行“打点”了。

目前发送埋点数据有两种方式：

1. 通过触发埋点事件上报**1**次数据，目前还支持上报触发事件时的玩家属性（属性规则-玩家属性）
2. 使用蛋码<发送埋点数据变化>增减埋点数据

![埋点界面](https://u5-creator.s3.game.163.com/manual/assets/tracking_set.Ca1bJaKC.jpg)

埋点数据是实时上报到服务器的，不跟随对局结算，但是数据返回创作者平台需要经过一段时间处理，通常在次日可见。

### 使用案例1：监测异常数据

在游戏流程的每个环节设置埋点，可以观测到游玩时数据与理想不符的情况。

比如我们在解谜的每一个环节完成时触发一次打点，得到每个环节成功的次数。

* 如果某一个解谜环节上报次数大大低于前一环节，就可以考虑优化地图内容了，比如降低谜题难度，或者增加线索提示，改善玩家的游玩体验。
* 如果某个关卡的通关次数出现显著异常，也可以关注地图是否出现了bug————在之前我们一般通过地图评论区来获知玩家遇见bug的情况，而通过数据埋点，我们可以更快了解到bug对于游玩的影响。
* 对金币数量进行埋点也可以监测是否有金币获取漏洞导致游戏体验失衡的情况。

### 使用案例2：观察玩家行为

在游戏的分支处设置埋点，可以记录玩家的选择偏好，从而对你的受众们产生更深入的了解。

* 比如在剧情对话的每个选项上都进行埋点，就可以查看多少玩家选择了A选项，多少玩家选择了B选项。为什么更多的人会选择A选项？分析背后的原因可以帮助你更好面对这部分受众的兴趣制作地图内容。
* 还可以在商品购买上埋点来记录玩家的消费意愿，如果某种道具的销量显然高于其他道具，之后地图里你还可以沿用这个道具模版吸引玩家购买。

## 查看埋点数据

在【创作者平台-数据中心-地图数据】进入你设置了数据埋点的地图详情页，就可以在最下方的自定义数据标签部分，查看数据上报情况和玩家上报时的帧率情况了。

> 帧率可以帮助你理解发送事件时玩家的卡顿情况。

![数据中心](https://u5-creator.s3.game.163.com/manual/assets/tracking_map.BEvfsSP9.jpg)

数据支持筛选日期，以及直接统计平均值、最大值、最小值。

对游玩数据进行分析和应对，有利于维持更长期的地图运营哦~
