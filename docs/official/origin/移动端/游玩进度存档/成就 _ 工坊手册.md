# 成就

在电子游戏当中，成就是一种奖励机制，可以鼓励玩家达成特定目标或完成特定任务。成就系统可以增加游戏的挑战性和趣味性。

我们可以在更多-规则设置-成就界面中设置成就，然后通过蛋码写入成就的完成进度。

## 设置成就

在成就栏中点击【添加成就】增加一个成就条目。

点击未配置成就，可以在成就的高级设置界面设置成就的基础信息，比如成就的名称、图标、具体任务等。

| 属性名称 | 描述 |
| --- | --- |
| 成就名称 | 成就的名称，会显示在成就列表和完成条幅中。 |
| 成就描述 | 会在玩家完成成就时和成就名称一起弹出，可以在这里写一些有趣的成就描述。 |
| 成就品质 | 成就的品质，会显示给玩家成就品级。设定为隐藏时，成就的达成条件会显示为？？？。 |
| 达成条件说明 | 会在地图详情的成就列表里展示，提示玩家怎么获得该成就。 |
| 解锁所需计数 | 代表着成就进度到多少的时候，会显示玩家完成该成就，解锁次数也会在地图详情的成就列表里的成就详情展出，显示格式为（0/10）。 |
| 单局成就 | 开启后，该成就的进度不能进行存档，下次进入游戏会被重置。 |

## 增加成就进度

给自定义成就增加进度需要在蛋码里写入，蛋码可以直接设置玩家进度为具体的数字（可以使用这条重置进度），也可以在原有基础上增加（或减少）玩家的成就进度。

![设置成就积木集合](https://u5-creator.s3.game.163.com/manual/assets/achievement_api.JQcxNd9R.jpg)

> 注意事项：
>
> 成就完成后，设置和增加成就进度的动作积木会失效，成就进度不会超出解锁所需计数。

## 成就奖励

如果在玩家完成成就时给他一些奖励，玩家会感到更开心，也会更有收集成就的动力。

你可以在成就配置界面的奖励页给成就添加奖励，单个成就最多可添加六种奖励，可以设置成就的奖励是否自动领取。

> 若为否，玩家完成成就后需要点击地图左上角的成就功能按钮进入成就页面手动领取，避免奖励丢失。

* 奖励类型

| 类型 | 描述 |
| --- | --- |
| 角色属性 | 在规则设置-玩法规则-属性规则中配置的角色属性 |
| 物品 | 物品类型组件，发放给玩家时会直接掉落在角色脚边 |
| 技能 | 使用预设编辑-技能库制作的技能预设 |
| 效果 | 使用预设编辑-效果库制作的效果预设 |
| 玩家属性 | 在规则设置-玩法规则-属性规则中配置的玩家属性 |
| 自定义 | 完成成就时发送的事件，用于配置自定义的奖励，会给玩家发出物品获得横幅提示 |
| 游玩奖励 | 上架地图商城功能中的道具到商店后，可以将商品的获取方式修改为“游玩奖励”，之后该预设的商品可以作为成就奖励赠送给玩家 |

* 是否每局发放

开启后若玩家完成了该成就，下次再次进入地图可以重复领取奖励。

除了在成就配置界面直接配置，还可以使用蛋码中的<指定玩家成就完成>和<玩家领取成就奖励>事件给成就功能赋予更丰富的反馈。
