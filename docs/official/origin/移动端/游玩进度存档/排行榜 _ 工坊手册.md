# 排行榜

排行榜可以将玩家的游玩数据进行整合，通过竞争机制提高玩家的游玩积极性，也为玩家树立更明确的游戏目标。

## 局外排行榜

在规则设置-排行榜中可以设置地图的排行榜。

一个地图最多可以设置10个排行榜条目，但是只有3个排行榜可以展示在地图详情页（玩家游玩的入口界面），单个排行榜可以显示10~100位玩家。

不在详情页展示的排行榜除非在局内引用，没有任何渠道展示给玩家。

贡献榜

一个地图最多展示4个排行榜，为了保障赞助玩家的付费权益，贡献榜为固定显示，仅可调整显示排序。

局外排行榜内整合的是玩家单局游戏结算后上传的数据，排行榜会按照数据来源进行排序，你可以根据数据功能选择排序规则。

| 数据来源 | 描述 |
| --- | --- |
| 通关时间 | 玩家取得游戏胜利所花费的时间 |
| 投币数量 | 玩家给地图投入的乐园币数量 |
| 推荐次数 | 玩家将地图分享给他人，有效邀请到的玩家数量 |
| 存档预设 | 官方存档类型，仅支持整数和定点数类型的存档 |
| 成就达成日期 | 玩家完成某个成就的日期 |
| 自定义进度 | 官方存档类型，仅支持整数和定点数类型的存档 |
| 好友排名 | 开启了好友排名设置的自定义存档 |
| 粉丝排名 | 粉丝团等级排名展示 |

通关排行榜上传规则

默认情况下通关时间排行榜记录的是玩家通关的最佳成绩（最短时间）。

但是，如果地图存在自定义存档(包括游玩进度和成就)，那么地图上传的通关时间会叠加累计，而不是最后一次读档所使用的时间，最后进入排行榜的也会是多次游玩的累计时间。

多次游玩中被判定为胜利也不会自动重置通关时间。如果希望在有自定义存档的地图刷新通关时间记录，玩家需要先在我的乐园>记录>已存进度>进度管理里删除该地图的存档。

## 排行榜重置

1.更新地图时可以选择是否重置排行榜数据；

2.修改排行榜设定，系统会强制重置被修改的排行榜数据；

3.排行榜只会记录正式上线（发布/更新后）的数据，不会计入旧数据。

## 局内排行榜

局内排行榜是指游戏中展示的排行榜，使用的是游玩过程中的数据，可以作为局内竞争局势的参考。

局内排行榜的上限为乐园房间的人数上限，即16人。

【局内排行榜数据来源】

| 数据来源 | 描述 |
| --- | --- |
| 自定义分数 | 使用蛋码<设置排行榜分数>积木设置的数据 |
| 玩家属性 | 在更多-规则设置-玩法规则-等级规则中设置的玩家属性 |
| 自定义进度 | 在更多-规则设置-游玩进度界面设置的自定义存档 |
| 排行榜 | 引用更多-规则设置-排行榜里的排行榜数据 |
| 角色属性 | 在更多-规则设置-玩法规则-等级规则中设置的角色属性 |
| 好友排名 | 开启了好友排名设置的自定义存档 |
| 玩家积分 | 默认积分规则下的积分 |
| 贡献榜 | 引用地图贡献榜 |

### 排行榜控件

排行榜控件可以在更多-编辑界面-功能分类中找到，排行榜分类下的控件只有样式区别，没有功能差异。

排行榜控件能显示多少玩家取决于排行榜控件的长度。

### 场景排行榜

在组件库中搜索“排行榜”，可以找到能在场景中展示的排行榜组件，分为有框和无框两个版本，功能没有差异。

场景排行榜能显示多少玩家取决于排行榜内容缩放大小。

性能提示

展示的玩家数据越多，对场景造成的性能压力越大。
