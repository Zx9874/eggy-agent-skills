# 地图音乐与音效

在地图中使用音乐和音效可以提升地图的视听感染力。

## 地图音乐设置

在更多里进入网易云音乐，切换上方页签为【地图音乐设置】。

地图音乐可以设置为系统默认音乐或静音。

你可以在网易云音乐提供的授权曲库中选择地图配乐，点击【选取】并确认。

注意事项

如果选择的配乐是网易云VIP用户限定歌曲，那么没有在《蛋仔派对》游戏中登录网易云音乐VIP账号的玩家将无法正常播放作者选择的配乐，默认播放官方曲库配乐。

## 地图音乐切换

使用组件【音乐切换器】可以在游玩时切换音乐。

1. 点击【修改切换到的音乐】可以设置切换的音乐，播放规则和地图设置音乐一致。

   注意事项

   游玩过程中切换音乐的播放可能会受到玩家当前网络状况影响。
2. 指定音乐开始播放时间意味着音乐播放从歌曲的第几秒开始，可以根据地图情节播放合适的配乐片段。
3. 切换音乐必须要填入切换事件，如果事件是全局发送，则房间内所有玩家背景音乐改变；如果事件发出时附带了玩家参数，则只有该名玩家背景音乐改变。恢复默认音乐事件也会这样生效。
4. 音乐切换器还可以设置音乐切换的最短时间间隔，避免玩家频繁触发音乐切换影响游玩体验，设置范围为20~999(秒)。

剧情动画音乐冲突

播放剧情动画时，如果剧情动画存在网易云音乐轨道，则会中断当前播放的地图背景音乐。

## 音乐板组件

音乐板组件可以播放不同乐器的不同音阶，你可以使用音乐板创作乐曲片段。

音乐板播放的声音默认为3D音频效果，音量会根据玩家与音乐板之间的距离衰减，玩家离音乐板越远，能听到的声音越小。
