# 天空背景

天空背景能够有效地营造出游戏环境的氛围，并支持在地图运行过程中进行动态切换。系统在【更多-天空背景】中提供了多种可选的天空球，点击对应的天空球可以对【背景、光照、雾效】进行编辑。

![](https://u5-creator.s3.game.163.com/manual/assets/skybox_entry.DMTFHBiA.png)

| 属性类型 | 属性 | 详细信息 |
| --- | --- | --- |
| 背景图 | X方向背景偏转 | 天空背景图在 X 轴方向上面的偏转角度 |
| Y方向背景偏转 | 天空背景图在 Y 轴方向上面的偏转角度 |
| Z方向背景偏转 | 天空背景图在 Z 轴方向上面的偏转角度 |
| 扰动 | 开启扰动 | 扰动功能的总开关。 |
| 扰动强度 | 扰动强度越高，天空背景缩放的变化越强 |
| 扰动密集度 | 扰动密集度越高，天空背景扰动的频率越高 |
| 渐变设置 | 渐变轴向 | 少数天空球可以自定义渐变颜色，渐变轴向决定该天空球颜色的分布 |
| 渐变颜色 | 决定天空球的颜色 |
| 渐变轴心位置 | 决定天空颜色的渐变位置的偏移 |
| 渐变对比度 | 影响渐变颜色融合的距离 |

**光照属性**

| 属性类型 | 属性 | 详细信息 |
| --- | --- | --- |
| 太阳光 | 光照强度 | 太阳光是场景中有方向的直接光源，它能生成定向阴影的光线。太阳光的光照强度会影响该场景的亮度 |
| 光的颜色 | 光的颜色直接作用于物体表面的渲染颜色，在制作特定场景时，光的颜色需要适当调整，比如日落场景需要橙红色的太阳光 |
| 光照俯仰角 | 光线在竖直方向上旋转的角度 |
| 光照偏航角 | 光线在水平方向上旋转的角度 |
| 环境光 | 环境光强度 | 环境光为场景中漫反射的光，它是影响全局的光源。环境光强度直接作用于漫反射的亮度，天空盒不受该属性影响 |
| 环境光颜色 | 直接作用于全场景的光源颜色 |
| 泛光 | 泛光曝光系数 | 直接作用于整个场景的额外曝光度。泛光仅在高清模式下生效 |
| 泛光范围 | 泛光范围为亮度的筛选阈值，该数值越低，场景中会被视为泛光光源的地方越多 |
| 泛光强度 | 泛光区域的亮度 |
| 泛光扩散度 | 泛光区域的大小 |
| 阴影 | 阴影弱化 | 阴影的不透明度 |
| 高级 | 反射天空图 | 在玻璃、水面等高反射度的表面上所呈现的背景图片 |
| 颜色细节优化 | 也叫色调映射，会将高动态范围（HDR）的图像转为地动态范围（LDR）的呈现。具体表现为降低色彩的饱和度的同时呈现更多明暗细节，并且可以有效地避免过曝 |
| 环境光遮蔽 | 采样半径 | 产生阴影的范围大小，数值越大，阴影覆盖的区域越宽 |
| 深度偏移 | 减少阴影边缘噪点的程度，数值越大，边缘越干净平滑 |
| 遮蔽强度 | 控制阴影的深浅程度，数值越大，阴影颜色越深 |
| 淡出终点 | 环境光遮蔽将在此距离完全失去效果 |
| 淡出起点 | 环境光遮蔽开始淡出的位置 |

**雾效属性**

| 雾效属性分类 | 雾效属性 | 详细信息 |
| --- | --- | --- |
| 基础 | 开启雾效 | 雾效的总开关，当开启后可以调整雾效参数 |
| 大气雾颜色 | 大气雾是柱状或环状的雾，大气雾颜色是该雾的颜色，它将直接作用于场景渲染的一部分颜色 |
| 大气雾亮度 | 决定大气雾明度的参数，会乘算与大气雾颜色的明度值 |
| 大气雾浓度 | 该参数实际作用类似于雾的不透明度，雾效越浓，参与场景渲染计算的百分比越高 |
| 大气雾能见度 | 雾效开始生效的距离，可以为负数。该距离是从相机开始计算的，比如能见度为 50，那么雾效就是从相机 50 米外开始产生 |
| 雾衰减的起始距离 | 雾效开始衰减不再增长的距离，雾效在到达这个距离之前会持续变浓，到达这个距离后将不再变浓，会维持现有的雾效浓度 |
| 高度雾颜色 | 高度雾无限广阔但有高度限制的雾，高度雾颜色是该雾的颜色，它将直接作用于场景渲染的一部分颜色 |
| 高度雾浓度 | 该参数实际作用类似于雾的不透明度，雾效越浓，参与场景渲染计算的百分比越高 |
| 天空背景受雾效影响 | 该参数实际作用类似于是否将雾效渲染到天空背景之上 |
| 高度雾衰减起始高度 | 高度雾不再变浓的高度，比如当它设定 5 米时，5 米以下都会有完全的高度雾 |
| 高度雾消失高度 | 高度雾彻底衰减为 0 的高度，比如当他为 40 时，则 Y 轴坐标大于 40 的地方不会有高度雾 |
| 太阳光在高度雾中散射 | 散射光颜色 | 在有雾的情况下，太阳光会有个散射弥散效果，类似于泛光。可以修改太阳光在雾中看到的颜色 |
| 散射光收束度 | 散射收束度越高，该弥散效果越少 |
| 散射作用结束距离 | 距离相机此距离开始弥散效果不再增强 |
| 散射光高度 | 此弥散效果的亮度 |
| 散射受大气雾影响程度 | 此数值为 0 时，散射效果只受到高度雾影响，为 1 时，散射效果只受到大气雾影响 |

## 自定义天空球

为方便开发者个性化编辑场景氛围，PC编辑器现已支持上传更大尺寸的全景图文件作为天空背景。你可以将符合要求的全景图片导入【自定义图片】，并应用为天空背景，实现更丰富的视觉表现。

![](https://u5-creator.s3.game.163.com/manual/assets/skybox_OperationSteps.C7fbc6Ap.png)

## 天空背景相关的蛋码

你可以通过蛋码调整天空背景的参数，实现更复杂的天空背景切换效果。滤镜、暗角、描边、菲尼尔效果、蒙版等后处理特效，可作为视觉补充手段与天空背景搭配使用，以增强场景整体氛围。

![](https://u5-creator.s3.game.163.com/manual/assets/skybox_SwitcherEggyCode.DFM_7vEj.png)

通过蛋码可调整【大气雾】与【高度雾】的参数，实现雾效的变换效果。

![雾效蛋码](https://u5-creator.s3.game.163.com/manual/assets/skybox_FogEggyCode.CtuQSnoq.png)

天空光照参数支持通过蛋码进行配置，实现更复杂的光照效果。

![光照蛋码](https://u5-creator.s3.game.163.com/manual/assets/skybox_sunlightEggyCode.Bs8P9NRQ.png)

## 天空背景切换

【天空背景切换器】位于【机关】-【逻辑】分类中，该组件用于在游戏运行时动态替换当前天空背景图，配合事件触发区域或蛋码使用，可实现区域进入、任务推进等情景下的背景过渡效果。切换过程支持四种过渡动画。

![](https://u5-creator.s3.game.163.com/manual/assets/skybox_ComponentsPanel.BVKNtTWf.png)

| 属性 | 属性描述 |
| --- | --- |
| 使背景开始切换的事件 | 背景切换一旦开始，在结束前其他背景切换不会开始 |
| 使背景暂停切换的事件 | 使当前背景切换暂停在这一时刻，暂停的背景切换可以恢复开始，但无法被其他背景切换取代 |
| 背景切换时长 | 背景完全切换需要使用的时间 |
| 背景切换方式 | 目前可选【无过渡】、【淡出】、【电子故障】、【燃烧】四种 |

进入区域触发天空背景切换，通过组合使用【事件触发区域】与【天空背景切换器】，可实现玩家进入某区域后触发天空背景切换的效果。

![](https://u5-creator.s3.game.163.com/manual/assets/skybox_Examples.h9UTSywa.gif)

【雾效切换器】位于【机关】-【逻辑】分类中，该组件用于在游戏运行时动态切换场景雾效的浓度、颜色及衰减等参数，配合事件触发区域或蛋码使用，可实现不同区域或时段下的氛围变化。雾效切换仅影响场景雾效参数，不影响背景图本身。

【天空光照切换器】位于【机关】-【逻辑】分类中，该组件用于在游戏运行时动态替换天空光照的环境光与方向光参数，配合事件触发区域或蛋码使用，可模拟不同时段的光照氛围。光照切换仅影响光照方向与强度，不改变天空背景图与雾效。

## 光源

光源组件与对整张地图生效的天空光照、环境光不同，其仅照亮局部区域，且不产生阴影。光源组件可在【机关-功能机关】分类下找到。

## 光源类型

根据形态，光源组件可模拟现实中的各类照明设备：

| 组件类型 | 形态类比 | 组件特性 |
| --- | --- | --- |
| 点光源 | 灯泡 | 向所有方向均匀发散光线 |
| 线光源 | 长条灯 | 可制作渐变色光效 |
| 面光源 | 打光板 | 大面积、柔和、均匀的光照，提供五种光照皮肤，可模拟不同质感的光影 |

## 通用参数

在光源组件的高级设置中，可调整以下参数：

* 亮度：数值越高，光照效果越明显。
* 边缘锐利度：数值越低，光照边缘形状越平滑柔和。

## 光源相关蛋码

光源支持动态控制，可通过蛋码实现运行时调节。
