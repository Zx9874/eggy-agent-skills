# 色彩滤镜

色彩滤镜功能支持调整玩家的画面参数，能够单独对画面进行调色和后处理，在营造场景氛围的同时不会修改组件本身的材质颜色。

## 功能入口

在【更多】-【色彩滤镜】中找到丰富的滤镜效果，通过滤镜可营造不同的场景氛围。

![色彩滤镜入口](https://u5-creator.s3.game.163.com/manual/assets/colorfilter.CKaD0-k0.png)

## 预设滤镜列表

选中即可切换并预览对应的滤镜效果，再次点击即可详细调整滤镜参数。

![色彩滤镜](https://u5-creator.s3.game.163.com/manual/assets/colorfilter_list.C3k9zLRa.png)

## 调色

每个滤镜都有自己的属性参数，同时滤镜也有通用的调节属性和后处理属性。

| 属性类型 | 属性名 | 详细信息 |
| --- | --- | --- |
| 调节 | 开启调色 | 全局开关，控制是否启用所有颜色调整效果。 |
| 色相 | 调整色相，改变整体色调倾向（如红变橙、蓝变紫）。 |
| 明度 | 控制图像整体亮度，数值越高画面越亮，数值越低画面越暗。 |
| 饱和度 | 调整颜色鲜艳程度，数值越高色彩越浓烈，数值越低越接近黑白。 |
| 对比度 | 增强或减弱明暗区域差异，数值越高明暗对比越强烈，数值越低画面越灰暗。 |
| 色温 | 调节冷暖色调（冷色偏蓝，暖色偏黄），模拟不同光照环境的色彩倾向。 |
| 色调 | 控制整体颜色偏向（如偏绿、偏紫），常用于修正画面颜色或实现风格化。 |

## 动态切换滤镜

色彩滤镜支持通过蛋码在游戏运行时动态切换。

### 色彩切换器组件的使用

如果事件携带玩家参数（事件触发区域、UI发送事件）只对一个人生效，否则对所有人生效

![](https://u5-creator.s3.game.163.com/manual/assets/colorchange.DK1xWDcj.png)

### 通过蛋码实现切换

1. 从【组件】面板中拖入一个事件触发区域，摆放到地图中并调整触发范围。
2. 在【更多】-【色彩滤镜】中选择地图的初始滤镜。
3. 在【角色进入触发区域】事件下拼接【设置色彩滤镜】积木。

![案例蛋码示例](https://u5-creator.s3.game.163.com/manual/assets/danma.BqBycice.png)
