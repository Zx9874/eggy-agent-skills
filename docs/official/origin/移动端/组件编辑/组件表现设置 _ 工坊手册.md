# 组件表现设置

组件表现页可以设置组件的外观表现，主要包括如下内容：

* [组件材质和材质参数](https://u5-creator.s3.game.163.com/manual/mobile/unitedit/unit_appearance.html#组件材质和材质参数)包括更换皮肤与配色，调节材质质感；
* [自定义模型](https://u5-creator.s3.game.163.com/manual/mobile/unitedit/unit_appearance.html#自定义模型)使用程序化生成方式，通过调整参数修改自定义基础形状组件的形态;
* [阴影与镜面渲染规则](https://u5-creator.s3.game.163.com/manual/mobile/unitedit/unit_appearance.html#阴影与镜面渲染规则)控制组件是否投射阴影、接受阴影与镜面反射；
* [组件遮挡规则](https://u5-creator.s3.game.163.com/manual/mobile/unitedit/unit_appearance.html#组件遮挡规则)将设置组件遮挡玩家视野时的处理方式。

## 组件材质和材质参数

点击组件高级设置窗口左上角的组件图标，可以修改组件皮肤。

![皮肤](https://u5-creator.s3.game.163.com/manual/assets/unit_skin1.DE_0EVfv.png)

不同的皮肤具有不同的材质效果，比如玻璃材质可以呈现半透明效果，流沙材质会有明显的凹凸感。

你可以在材质的基础上更改配色和材质参数。

![材质参数](https://u5-creator.s3.game.163.com/manual/assets/unit_skin2.maDNmLar.png)

更改组件皮肤的蛋码

<设置组件皮肤>能够动态修改组件使用的材质。

### 组件配色

不同材质开放的染色区域数量不一，通常为1~4个染色区域。

染色区域的数量意味着组件最多可以使用多少配色。

更改组件配色时，对应染色区域会有一个高亮动画效果，用于提示选择的染色区域范围。

![染色区域](https://u5-creator.s3.game.163.com/manual/assets/unit_color_zone.BWy__iNa.gif)

更改配色的蛋码

蛋码<设置组件染色区域>可以动态修改组件的配色。

由于它不会根据当前指向的组件材质变化染色区域的枚举，当修改的组件没有对应染色区域时不会正常生效。

#### 自定义色板

使用色板将会按照顺序填入色板内颜色，官方提供了多种主题色板。

![材质参数](https://u5-creator.s3.game.163.com/manual/assets/unit_color1.C857LTLM.png)

在组件高级设置创建新色板，可以快速将当前组件配色保存为一个自定义色板。

![材质参数](https://u5-creator.s3.game.163.com/manual/assets/unit_color2.BLsMP6kn.png)

从更多-地图配色-色板编辑功能中也可以进入自定义色板界面:

![材质参数](https://u5-creator.s3.game.163.com/manual/assets/unit_color3.ByWnCYxP.png)

自定义色板支持逐个选择并设定颜色，也可以从右上角上传参考图片提取图片的色板使用。

通常来说组件使用的色板只会用到主色调的四个配色，辅色调的六个颜色则是会在地图一键配色功能中使用。

保存的自定义色板将会同步到云端，跟随账号使用。

#### 颜色选取

蛋仔工坊的拾色器使用的是HSB（色相、饱和度、亮度）色彩模式，由一个二维色板和一个亮度滑条组成。

在二维色板上，你可以通过左右移动取色器调整取色色相，上下移动调整组件的饱和度。

长按二维色板里的取色器可以调出精准取色面板，小幅度调整颜色参数。

上下移动右侧滑条可以改变色板的明暗度，滑块越接近底部色板越接近全黑。

![材质参数](https://u5-creator.s3.game.163.com/manual/assets/unit_color4.ZKkwoY6l.png)

除了使用调色板，你也可以在下面的输入框输入16进制颜色代码直接取色。

---

取色时，你可以点击保存将当前颜色保存到常用色色板中，方便反复调用；

在自定义色板里保存的颜色搭配也支持在这里复用；

调色面板还会自动保存最近选中使用过的四个颜色。

![材质参数](https://u5-creator.s3.game.163.com/manual/assets/unit_color5.ChwyiR-5.png)

配色面板左上角可以调节**所有染色区域**的色相\饱和度\明度。

颜色特征，通常为红橙黄绿蓝紫，可以改变配色的色系。

![色相](https://u5-creator.s3.game.163.com/manual/assets/unit_hue.aqELsR2x.gif)

### 材质参数

在组件高级设置的[表现]页>材质参数设置里可以设置材质参数。

点击材质参数设置前的齿轮符号，可以复制粘贴全部材质参数的配置。

![材质参数](https://u5-creator.s3.game.163.com/manual/assets/unit_material_copy.CcGPEmIF.png)

注意事项

部分参数在不同材质下的表现会有差异。

材质参数可以调节组件皮肤的表现，包括金属度、粗糙度、自发光和纹理变换等。

#### 纹理变换

部分材质使用了纹理贴图，纹理变换参数可以调整纹理贴图的表现。

关闭纹理自由缩放时，纹理只能进行整体缩放，参数越大，贴花重复度越高；

![纹理](https://u5-creator.s3.game.163.com/manual/assets/texture_scale1.CIX_d9pZ.gif)

开启纹理自由缩放后，可以对纹理进行单轴缩放。

![纹理](https://u5-creator.s3.game.163.com/manual/assets/texture_scale2.g6TyoPUx.gif)

#### 粗糙度

粗糙度越高，组件表面看起来越光滑，光的反射越清晰。

部分材质支持对不同染色区域进行局部调节。

粗糙度表现在节能画质下不生效。

（图中使用了白色金属皮肤，并将金属度参数调整到最高、更改了反射天空图，使粗糙度特性得到最显著的体现）

![粗糙度](https://u5-creator.s3.game.163.com/manual/assets/texture_rough.BYx9W0Ur.gif)

#### 金属度

金属度越高，组件反光表现越明显，组件也会更偏向冷色调。

部分材质支持对不同染色区域进行局部调节。

节能画质下不生效。

![金属度](https://u5-creator.s3.game.163.com/manual/assets/texture_metal.CTcTAjCs.gif)

#### 自发光

自发光表现会受到自发光颜色和强度影响。

自发光颜色明度越高，自发光表现越明显；自发光颜色为黑色时，无论自发光强度多高都不会有自发光效果（整体自发光使用自发光颜色，局部自发光使用染色区域颜色）。

自发光强度在颜色基础上生效，强度越高表现越明显。

自发光支持根据不同染色区域局部调节。

![自发光](https://u5-creator.s3.game.163.com/manual/assets/texture_emission.VmZ8HypY.gif)

自发光表现在节能画质下不生效。

#### 边缘光

又称菲尼尔效果，边缘光能够在组件边缘形成高光轮廓。边缘光颜色明度越高则实际亮度越高；边缘光范围和强度较大时，实际表现接近整体自发光效果。

![自发光](https://u5-creator.s3.game.163.com/manual/assets/texture_fresnel.BVc7uNt5.gif)

边缘光效果相关蛋码

菲尼尔效果能够使用蛋码动态修改。

<设置菲尼尔效果>可以设置指定玩家可见的组件菲尼尔效果； <设置菲尼尔渐变效果>可以制作组件过渡显现边缘光变化的效果； <关闭菲尼尔效果>可以关闭指定玩家视野的组件菲尼尔效果。

## 自定义模型

部分基础组件支持修改模型形状，可以通过修改边数、半径、角度、倒角阶数等参数生成全新模型。一张草稿里使用的自定义模型数量（一种设定为一个，同设定多个计为一个）不能超过75个。

自定义模型有简易物理和复杂物理两种物理碰撞版本，后者的物理效果更贴合模型，前者占用值更低。

## 阴影与镜面渲染规则

| 属性 | 描述 |
| --- | --- |
| 关闭投射阴影 | 开启后组件不会受天空光照影响投射阴影，该属性需试玩一次后生效。 |
| 是否接受阴影 | 关闭后组件将不会被场景里渲染的阴影覆盖，该属性需试玩一次后生效。 |
| 可被镜面反射 | 开启后组件不会在镜面组件中显示倒影，关闭非必须的组件反射可以降低镜面组件渲染造成的性能压力。 |

## 组件遮挡规则

组件遮挡玩家视野时会触发该效果。

| 遮挡规则类型 | 描述 |
| --- | --- |
| 不处理 | 默认为玩家不显示，组件会完全遮挡玩家视野。 |
| 玩家虚影 | 会显示玩家虚影，如果玩家在【游戏设置】里的【角色显示】勾选了不透视，则效果等同于不显示。 |
| 镜头前推 | 玩家的视野会变狭小。 |
| 组件半透明 | 组件会显示为半透明状态，避免影响玩家视野。 |
