# 组件预设

组件预设可以看做是组件的设计图，用来描述一个组件应该是什么样，默认的配置是什么。

我们从组件库里拖出来、在场景中生成的组件，则是根据预设创建出来的组件实体。

我们可以使用一个组件预设创建很多个组件实体，预设功能也能帮助我们更便捷地批量修改和管理场景内的组件。

## 预设编辑

进入更多-【预设编辑】界面即可编辑组件预设，组件高级设置界面左上角也可以跳转进入。

![](https://u5-creator.s3.game.163.com/manual/assets/unit_prefab.CWxfK88U.png)

预设支持修改大部分实体高级设置上的属性，包括组件皮肤、组件物理等。

并且部分属性只有预设上可以编辑，比如物品的外观和堆叠方式、组件的血条属性等。

更改预设后，可以使用预设编辑里的【应用到场景】将修改后的设定应用到之前创建出来的实体上，支持在列表中选择指定的属性进行覆盖。

如果想将组件实体上的属性反向覆盖到预设上，可以选择<同步到预设>将组件实体上的*所有*属性同步到预设的配置上，包括一些预设里不显示的属性。

组件实体所使用的预设不支持更换，只能修改其预设属性或者在实体上修改；如果想和原先的预设区分，可以将当前实体存为新的自定义预设。

## 自定义预设

在官方预设上的修改会直接影响到草稿使用的组件库，并且能对官方预设的修改存在一定限制。

<存为新预设>能够以指定预设或实体为模版创建新的预设，保存的预设会存储在预设编辑的【自定义】分类当中。

同一官方预设可以创造多个自定义预设，在之后创建的自定义预设上进行修改不会影响官方预设（或者作为创建模板的任何预设，存为自定义预设后它就是独立的）

性能提示

自定义预设的数量会影响地图文件大小，当地图文件大小超出上传范围时，可以尝试精简使用的自定义预设数量。

## 预设触发器

预设能够创建对象触发器，所谓对象触发器，就是对该预设下所有实体都生效的触发器。

对象触发器可以实现玩法中的类逻辑，比如，某类组件受到碰撞时会变色，某类生物蛋在敌人靠近时可以发动技能。

在预设编辑界面选中预设，点击右上角的<编辑蛋码>即可创建以该预设为对象的对象触发器。

预设触发器的销毁规则

当组件实体触发销毁时，它所使用的对象触发器也会被销毁，包括还没有生效的计时器。

例如使用事件积木<当前组件被销毁>时，想要组件被销毁后一秒发送一个提示，不可以在下面直接使用紫色计时器，因为计时器还没生效就会被销毁掉。可以改成被销毁时发送全局自定义事件，接收到事件后触发计时器。
