# 地形编辑器

地形组件支持使用笔刷工具绘制地势起伏、纹理材质以及观赏植被。

【视频教学】[地形编辑器](https://egg-shell.fp.ps.netease.com/file/6731d2d0620b73cc5709568c31BFQq7e05)

## 地形组件

地形组件可以在组件库中结构-基础形状分类中找到。

出于玩家设备性能考虑，单个地图场景内最多放置十个地形组件。绘制的地形越复杂精细，地形所占用的地图文件大小越多。

地形组件的原点不在中心，而在一个角上，暂时不支持旋转和镜像工具。

使用缩放工具或者修改高级设置中的地块长度和地块宽度可以修改地形大小。

地形组件的长宽上限为254\*254，这个大小意味着地形的面片数量，不等于地形的尺寸，地形在地图中的大小还会受到地形组件的细节精度影响。

* **整体缩放开关**

决定地形变化时当前地形内容是否进行等比例的拉伸缩放。

整体缩放开关为开时，地形组件上已经绘制的部分将会等比例放大或缩小；整体缩放模式开关为关时，缩放地形将会以原点为中心进行扩展或收缩。

![缩放差分图](https://u5-creator.s3.game.163.com/manual/assets/terrain_scale.CPC8RJLW.jpg)

* **细节精度**

可以修改当前地形组件的相邻顶点密度，顶点密度越高，地形的精细程度越高，整体越丝滑。地形精度提高后，地形大小会相对缩小。

* **精准采样**

精准采样用于场景内有多个相邻的地形组件时，开启精准采样能够让地形模块边缘的纹理旋转和地形高低差衔接得更自然。

## 高度笔刷

高度笔刷可以绘制地形的高低起伏，系统会根据绘制地形生成贴合的物理碰撞。

高度笔刷有多种样式，绘制出的形状不一样，可以根据需求选择。

![](https://u5-creator.s3.game.163.com/manual/assets/terrain_height.rkTqF598.gif)

笔刷大小会影响绘制的范围（这点所有笔刷都是通用的）

![](https://u5-creator.s3.game.163.com/manual/assets/terrain_height1.H3R0MQrs.png)

笔刷力度会影响画一次增加的高度，画多次高度也会叠加。

![](https://u5-creator.s3.game.163.com/manual/assets/terrain_height2.CE3-C0l2.png)

笔刷力度设置为负数的时候，会起到降低高度的作用，同样可以叠加。地形高度小于0时会呈凹陷状态。

![](https://u5-creator.s3.game.163.com/manual/assets/terrain_height3.B4KOjglD.png)

## 平滑笔刷

平滑笔刷可以在已绘制的地形上起到打磨棱角作用，让地形看起来更自然平滑，减小高度差。笔刷力度越大，效果越明显。 ![](https://u5-creator.s3.game.163.com/manual/assets/terrain_smooth.B_PMvsLn.gif)

## 整平笔刷

整平笔刷可以创造一片平坦的地形，原理是将笔刷绘制的区域高度都设置为最初点击位置的高度。 ![](https://u5-creator.s3.game.163.com/manual/assets/terrain_flatten.FV91lYvc.gif)

## 材质笔刷

材质笔刷可以更改地形的纹理，从而塑造不同风格的地形。

![](https://u5-creator.s3.game.163.com/manual/assets/terrain_texture.5DlXkirF.gif)

* **笔刷力度**

材质笔刷的笔刷力度决定了每次绘制时纹理的不透明度，透明度可叠加；透明度调整为负数时可以起到减去透明度的擦除作用。

> 注意事项：
>
> 如果地形上某个使用材质笔刷绘制的纹理透明度达到100，那么这个笔刷材质会完全替换掉那块地形的原生材质。此时不再可以通过负数力度笔刷降低该材质的透明度，只能使用想要替换的材质笔刷进行覆盖。

* **羽化范围**

羽化指笔刷绘制形状的模糊边缘。羽化范围越小，绘制形状越清晰；羽化范围越大，绘制形状边缘透明度渐变越明显。

* **材质样式**

同一个地形上只能同时存在四种材质，因此材质笔刷使用的样式只能在地形高级设置里设置的材质中选择。

![地形高级设置选择材质](https://u5-creator.s3.game.163.com/manual/assets/terrain_texturesetting.fjtjO_Xr.jpg)

在高级设置界面的【表现】栏可以更换使用的材质以及调整单个材质的材质参数。

| 属性名称 | 描述 |
| --- | --- |
| 自定义颜色 | 开启后能够对材质进行调色 |
| 移动轨迹 | 开启后玩家在该材质的地形上行走会出现脚印 |
| 金属度 | 金属度越大，该部分材质的金属反光表现越明显 |
| 自发光强度 | 自发光强度越大，材质的发光表现越明显 |
| 贴花重复度 | 贴花重复度越大，纹理密度越大 |
| 粗糙度范围 | 粗糙度会影响到材质的表面光滑程度和反光表现，下限越低反光越明显，上限越高表面越粗糙 |
| 纹理旋转 | 影响纹理方向 |

## 染色笔刷

染色笔刷可以在地形材质上叠加局部染色。

![染色笔刷](https://u5-creator.s3.game.163.com/manual/assets/terrain_dyetool.CL5m3ygj.gif)

* **混合模式**

混合模式下可以使用染色笔刷直接对材质进行局部染色，不会改变材质的纹理表现。

更换颜色后继续绘制，染色边缘会与之前的染色部分混合。（主要还是覆盖效果，只是在羽化范围较大时颜色交接处比较柔和，不会有明显的色相改变）

* **擦除模式**

起到橡皮擦的作用，可以还原材质原本的颜色。

## 装饰笔刷

装饰笔刷可以在地形上绘制出实体组件，能够快速添加批量的装饰物。

【视频教学】[地形装饰笔刷](https://egg-shell.fp.ps.netease.com/file/6808832401975819025fb8e7Qb4fvLIt06)

* **笔刷模式**

![装饰笔刷](https://u5-creator.s3.game.163.com/manual/assets/terrain_decotool.BaztGV5Q.gif)

| 模式 | 描述 |
| --- | --- |
| 添加 | 在绘制区域放置组件或组件组，可以无限叠加 |
| 移除 | 删除绘制区域内的组件，组件的原点在绘制范围内才会被删除 |
| 替换 | 重新绘制区域内的组件，可以更换装饰方案，也可以在同个装饰方案的基础上随机新的表现 |

* **装饰方案**

装饰方案可以添加一个或多个组件作为笔刷，可以用它快速绘制形态各异的植被或其他装饰。

除了官方提供的植被装饰方案，你也可以按照如下步骤，选择想要的组件预设并更改其配色和物理来制作自定义装饰方案作为笔刷使用。

![装饰笔刷自定义](https://u5-creator.s3.game.163.com/manual/assets/terrain_decoplan.FaLaCkzb.jpg)

装饰笔刷绘制的组件经过特殊处理，相比从组件库中拖出来的组件性能消耗更低，但也舍弃了大部分组件上的高级属性，便于为场景搭建服务。

出于设备性能考虑，装饰组件离玩家较远时不会显示。

使用装饰笔刷绘制的组件在沙盒模式试玩时默认无物理碰撞，普通试玩和发布后的物理是正常的。

> 图标上标记了风场的组件无法开启物理碰撞，无法关闭风场效果

* **装饰密度**

可以改变绘制时一笔的装饰密度，密度越大，装饰越密集。

* **装饰设置**

![装饰笔刷设置](https://u5-creator.s3.game.163.com/manual/assets/terrain_decosetting.BqtcDIvv.jpg)

| 属性 | 描述 |
| --- | --- |
| 绘制类型 | 可选择一笔是放置一个组件还是多个组件 |
| 装饰列表 | 选择使用的组件装饰方案 |
| 仅对当前方案植被进行操作 | 笔刷为擦除模式时开启该开关只会擦除这个方案的装饰 |
| 随机缩放 | 关闭时绘制的组件将使用统一的缩放；开启后可以设置随机缩放的大小范围 |
| 随机角度 | 关闭时绘制的组件将使用统一的旋转角度；开启后可以设置随机旋转的角度范围 |
| 与地表垂直 | 开启后会根据绘制区域的角度，使装饰组件垂直于地表 |
| 避免重叠 | 开启后多次绘制的装饰组件也不会重叠（原点而非边缘不重叠） |
| 使用地表颜色 | 开启后装饰方案里的组件在实际绘制时会自动变成地表的颜色 |

## 植被风场

植被风场功能可以给地形植被加入自然的风力效果以及踩踏表现。

但风场实质上只是给植被模型赋予了风动的表现，并没有类似【风场组件】的物理效果。

![植被风场效果](https://u5-creator.s3.game.163.com/manual/assets/terrain_windforce.H4GSlIFj.gif)

### 全局风场

全局风场将会对地图内所有预设上有风场标志的地形植被生效。

在地形左上角工具里进入植被风场界面，打开【全局风场】开关。

![装饰笔刷设置](https://u5-creator.s3.game.163.com/manual/assets/terrain_wind.DrwYwhq9.jpg)

| 属性 | 描述 |
| --- | --- |
| X方向力 | 植被风在x方向上的风向，可以理解为东西风 |
| Y方向力 | 植被风在y方向上的风向，可以理解为南北风 |
| 风场频率 | 频率越高风动效果越频繁 |

> 以上参数可以在蛋码中使用相关积木动态修改。

**植被风场管理**

可以控制风场是否对该类植被生效。

### 固定风场

固定风场只会在区域范围内生效，如果地图里存在全局风场，那么风力效果会叠加。

可以在组件库中【机关】-【逻辑】分类中找到固定大小风场组件，也可以使用蛋码里的<创建固定风场>积木动态生成。

![装饰笔刷设置](https://u5-creator.s3.game.163.com/manual/assets/terrain_fixedwind.DcHLnnbh.jpg)

### 踩踏效果

植被风场功能还可以模拟角色在植被上的踩踏效果。

在植被风场功能界面打开【踩踏效果】开关，角色行走在受风场影响的植被中可以看到明显的植被变形表现。

| 属性 | 描述 |
| --- | --- |
| 踩踏范围 | 数值越高，受踩踏影响的植被范围越大 |
| 踩踏强度 | 数值越高，踩踏对植被造成的影响越明显 |

## 流体笔刷

流体笔刷可以在地形组件上绘制流水景观，它独立于地形笔刷，用来单独塑造流体的高度、形状和表现。

### 流体笔刷的使用

流体笔刷需要先绘制流体材质，再使用流体材质单独的高度、平滑和整平笔刷塑造流体的形状。

流体材质笔刷分为【绘制】和【擦除】模式，用于更改水体区域范围。

![流体笔刷羽化范围](https://u5-creator.s3.game.163.com/manual/assets/terrain_fluid.1VYciAq5.jpg)

流体笔刷的羽化范围会影响到绘制水体的锯齿程度，羽化范围越高，流体边缘越圆润。

绘制的流体区域在试玩时没有物理碰撞。

### 流体材质表现

在流体笔刷的高级设置里可以设置流体的材质表现，官方提供了多种风格的模版，你也通过调节各项参数打造独特的流体表现。

流体材质支持自定义调色，更改水体表现、岸边冲击表现和波光、涟漪、浮沫、波纹等水体装饰效果。

## 高度组件

高度组件也叫做局部高度图，是官方提供的成品地形素材，可以帮助你快速搭建地形。

【视频教学】[局部高度图](https://egg-shell.fp.ps.netease.com/file/6808834334a6d292ceb7c68f84AJr0Fi06)

将高度组件放置在地形组件上后，可以使用缩放工具对它进行长宽拉伸。

在高级设置中更改【高度系数】可以调整高度组件在y轴上的表现；调整【平滑程度】可以一键调整高度组件的崎岖程度，范围为0~5。

### 自定义高度组件

除了使用官方提供的高度组件，现在还支持将自定义图片转化为高度组件使用。

图片的灰度值将转化为高度分布，颜色偏向黑色的部分将会向下凹陷，偏向白色的部分会向上升起。
