# 表现器

表现器可以给组件添加丰富的表现效果，不同的表现器有不同作用。

* 皮肤表现器能够在游戏运行时动态更换组件的配色、皮肤和材质；
* 特效表现器能在组件位置或组件挂点上播放特效，特效将会跟随组件；
* 音效表现器能够在组件位置播放音效；
* 场景界面表现器可以在组件位置创建场景界面，界面将会跟随组件位置。

## 创建表现器

1. 选中场景内组件，打开组件的【高级设置】界面切换到【表现】页签。
2. 在表现页底部找到【表现器列表】，这里用来添加和管理组件实体上的表现器。

![表现器](https://u5-creator.s3.game.163.com/manual/assets/Unit.CIg3A4Zy.png)

3. 点击添加表现器后，在表现器列表中选中新建的表现器，点最右侧的小箭头跳转到表现器设置界面。在这里可以设置表现器的类型、表现效果和表现触发方式等参数。

![表现器](https://u5-creator.s3.game.163.com/manual/assets/setting.CpSJRydA.png)

4. 添加表现器后，右下角会出现【表现测试选择】按钮，这里能够预览组件上所有或指定的表现器效果。

![表现器](https://u5-creator.s3.game.163.com/manual/assets/PerformancetestUnit.RplhEKFC.png)

单个组件上可以添加多个表现器，上限为50个。

组件上的表现器支持复制粘贴指定表现器和组件上的全部表现器，但是皮肤表现器可能会因为粘贴的组件缺少对应染色区域和皮肤材质失效。

复制组件时，会复制组件的所有表现器。表现器可以通过【同步到预设】将表现器存到到组件预设上；组件预设支持编辑表现器列表。

![表现器](https://u5-creator.s3.game.163.com/manual/assets/entry.r5FIOVKg.png)

表现器性能

表现器不会影响地图组件占用值，但是会占用地图文件大小，遇到地图文件大小过大导致无法上传的情况可以尝试删除部分表现器。

同屏组件使用的表现器过多会对玩家设备造成性能压力，因此建议尽量减少表现器的集中规模使用。

## 皮肤表现器

选择表现器类型为皮肤即可创建一个组件外观表现器。

外观表现器通常用于制作组件变色或切换皮肤材质的效果，触发表现器后组件会变化为所选皮肤和配色。

| 功能 | 描述 |
| --- | --- |
| 切换方式 | 切换方式目前仅开放【渐变过渡】（不改变皮肤外观，仅更换颜色），可以选择变化时长，时长越长则变化越自然 |
| 游戏开始时触发 | 如果选项设置为<开>，在游戏开始时会立刻触发一次此表现 |
| 触发表现/关闭表现的事件 | 同运动器一致，填入设定的事件名称即可作为表现器本身的开关 |
| 初始延迟时间 | 当表现器被触发后，表现器效果需要等待所填的秒数后才会生效 |
| 周期触发时间 | 表现器效果每次被触发后，经过设置的时间后会再次被触发。数值越小，同样时间内可以观察到的触发效果越频繁。数值设置为0的时候，系统会默认关闭周期性触发 |
| 触发冷却时间 | 设置表现器在一定时间内只触发一次，冷却时间内无法再次触发，间隔大于冷却时间后触发才有效。数值越大，等待时间越长 |

**案例1：变色效果**

以组件【中式纸伞】为例，制作跑酷图中一步一换色的触发效果,需要使用三个【表现器】和【事件触发区域】。

![表现器](https://u5-creator.s3.game.163.com/manual/assets/example.Bm0KoB6b.gif)

1. 设置三个【小地板】，并分别在上方位置设置【事件触发区域】
2. 设置【中式纸伞-表现器1】的【触发表现的事件】为01，【关闭表现的事件】暂不填写。【周期触发时间】和【触发冷却时间】均为0。
3. 设置事件触发区域【进入区域触发事件】为01，蛋仔每次进入该区域，【中式纸伞】就会切换为【表现器1】的颜色。

**案例2：切换材质**

使用表现器能做出更真实的物体状态变化，给玩家的互动动作提供更强烈的反馈。

例如设置组件皮肤变化为【自发光】，通过开关触发。玩家点击按钮后，灯将被点亮。

![表现器](https://u5-creator.s3.game.163.com/manual/assets/example3.DEsC41IM.gif)

提示

如果出现了试玩时组件变白的问题，建议先检查一下该组件是否添加了表现器。

默认的表现器配置是游戏开始时组件变为白色。

## 特效表现器

选择表现器类型为特效即可创建一个组件特效表现器。

特效表现器通常用于给组件添加特效表现，也可以让无法直接移动的场景特效资源借助组件为载体拥有运动效果。

在精准编辑界面，你可以预览特效的挂接表现，通过调整参数改变特效的位置、缩放和旋转信息。

![表现器](https://u5-creator.s3.game.163.com/manual/assets/sfxedit.CjojscIZ.png)

| 特效精准编辑 | 参数描述 |
| --- | --- |
| 特效是否挂接 | 可参考工坊组件的【绑定】关系，挂接后，特效的大小和朝向会与组件绑定，随组件一起运动。选择挂接后可以在【跟随组件变化的属性】中调整选项 |
| 挂接的挂点 | 表示特效播放的位置。挂点暂不支持自定义，但可以通过【特效位置偏移】调整特效位置。当挂点为<空>时，特效会在组件的默认点位播放且缩放倍数设置不会生效 |
| 特效位置偏移 | 可以通过精确编辑数值，在以组件坐标为原点的坐标系中移动特效位置 |
| 特效缩放倍数 | 可以通过精确编辑数值，在不同轴上放大或缩小特效 |
| 特效旋转 | 可以通过精确编辑数值，以特效底面中心点为原点的方向轴上旋转特效 |

特效表现器还支持调整以下参数：

| 功能 | 描述 |
| --- | --- |
| 特效持续时间 | 特效从开始播放到消失的时间。设置持续时间小于0则为永久播放，直到特效被销毁 |
| 播放特效中声音 | 部分特效资源会携带音效，如果不希望自带音效，可以关闭此开关 |
| 跟随组件显示 | 关闭时，此表现器特效始终显示；打开时，此表现器播放的特效将跟随组件的显隐而出现（例如蛋码里的设置组件模型显隐积木） |
| 游戏开始时触发 | 如果设置为<开>，游戏开始时会立刻触发一次该特效。如果想要特效只在触发时出现，需要关闭此项 |
| 触发表现/关闭表现的事件 | 填入设定自定义的事件名称可作为表现器触发/关闭的开关 |
| 初始延迟时间 | 表现器效果被触发后，需要等待设定时间后才被执行 |
| 周期触发时间 | 表现器效果每次被触发后，经过设置的时间后会再次被触发。数值越小，同样时间内可以观察到的触发效果越频繁。数值设置为0的时候，系统会默认关闭周期性触发 |
| 触发冷却时间 | 设置表现器在一定时间内只触发一次，冷却时间内无法再次触发，间隔大于冷却时间后触发才有效 |

**案例1：火焰燃烧特效（附加特效）**

使用表现器给组件添加特效，无需添加特效组件且节省地图容量。特效库中的【岩浆球】特效比分类中的火焰更具真实感。

![表现器](https://u5-creator.s3.game.163.com/manual/assets/example4.DDoRNb2s.gif)

1. 需要火焰能一直在火盆上燃烧，将特效持续时间设置为-1，并打开【游戏开始时触发】。
2. 系统提供的挂点位置较低，增加y轴的偏移值，通过表现测试确定特效是否在理想的位置播放。

**案例2：踩水花特效（事件触发）**

如需手动触发特效，可使用【触发表现的事件】控制。以踩水花为例，当蛋仔踩到石板上时会触发，并且特效不会重复播放。

![表现器](https://u5-creator.s3.game.163.com/manual/assets/example5.BkgCg9Jg.gif)

1. 设置【触发表现的事件】为对应的事件触发区域01，通过复制表现器到其他地板，依次修改【触发表现的事件】为对应的事件触发区域02、03。
2. 当【触发冷却时间】设置为0时，蛋仔进入区域后会多次触发水花效果，可以根据需求调整表现器。

## 音效表现器

选择表现器类型为音效即可创建一个音效表现器。

音效表现器被触发后会播放指定音效，不仅能够替代音效播放器的功能，还能以组件为载体播放3D空间感音效，让游戏中的音效表现更真实。

| 功能 | 描述 |
| --- | --- |
| 音量 | 支持单独设置不同音效表现器的音量区别，但最终的声音大小会受到总音量影响 |
| 音效持续时间 | 音效从开始播放到消失的时间。当设置持续时间小于音效本身时间，该表现器会播放音效的前一部分； 当音效持续时间大于音效本身时间时，只播放一遍完整的音效；当音效持续时间设定为0时，系统默认为音效本身的播放时长 |
| 播放变速 | 设置音效的播放速率，会导致频率（音调）发生改变。设置为0时音效按原速率播放，设置为60时音效按2倍原速率播放，设置为-60时按0.5倍原速率播放,可据此调整 |
| 3D空间效果 | 打开时，音效的播放效果会以组件为中心产生播放距离衰减，远离音源时音量会变小，并且会有左右声道播放效果。关闭时，音效为单声道播放，不会因远离音源而音量减弱。 |
| 音效传播距离 | 打开3D空间效果时，可以用此设置调整音效的整体传播距离，点击<显示范围>可以在场景中查看呈现为红色球体的可视化传播范围 |
| 音效衰减方式 | 设置随着远离音源时，音量以何种方式减小。系统提供【由慢到快、由快到慢、均匀衰减、慢-快-慢】四种方式 |
| 游戏开始时触发 | 如果设置为<开>，游戏开始时会触发该音效。如果想要音效只在触发时出现，需要关闭此项 |
| 触发表现/关闭表现的事件 | 填入设定自定义的事件名称可作为表现器触发/关闭的开关 |
| 初始延迟时间 | 表现器效果被触发后，需要等待设定时间后才被执行 |
| 周期触发时间 | 表现器效果每次被触发后，经过设置的时间后会再次被触发。数值越小，同样时间内可以观察到的触发效果越频繁。数值设置为0的时候，系统会默认关闭周期性触发 |
| 触发冷却时间 | 设置表现器在一定时间内只触发一次，冷却时间内无法再次触发，间隔大于冷却时间后触发才有效 |

## 场景界面表现器

选择表现器类型为场景界面即可创建一个场景界面表现器。

创建场景界面表现器之前，你首先需要在更多-编辑界面-上方切换画布为场景界面画布，点击上方工具栏里的<管理>新建自定义场景界面预设并进行界面内容编辑。

>>> [场景界面详情](https://u5-creator.s3.game.163.com/manual/mobile/UIeditor/ui_3d.html)

场景界面能以组件为载体展示界面ui

| 功能 | 描述 |
| --- | --- |
| 场景界面预设 | 可以在编辑界面中创建或编辑场景界面。官方也提供了一些预设界面 |
| 持续时间 | 设置场景界面显示的持续时间，设置为<-1>表示场景界面会一直存在 |
| 跟随组件显示 | 设置为<关闭>，由此表现器创建的场景界面会始终处于显示状态；设置为<打开>，由此表现器创建的场景界面的显示/隐藏状态会与表现器所在的组件保持一致 |
| 事件指向绑定者 | 设置为<开>，点击场景界面发送的事件会同时发送给该表现器所属的对象，可以同时触发蛋码事件【接收自定义事件（当前对象）】 |
| 游戏开始时触发 | 如果设置为<开>，游戏开始时会触发此表现。如果想要场景界面只在触发时出现，需要关闭此项 |
| 触发表现/关闭表现的事件 | 填入设定自定义的事件名称可作为表现器触发/关闭的开关 |
| 初始延迟时间 | 表现器效果被触发后，需要等待设定时间后才被执行 |
| 周期触发时间 | 表现器效果每次被触发后，经过设置的时间后会再次被触发。数值越小，同样时间内可以观察到的触发效果越频繁。数值设置为0的时候，系统会默认关闭周期性触发 |
| 触发冷却时间 | 设置表现器在一定时间内只触发一次，冷却时间内无法再次触发，间隔大于冷却时间后触发才有效 |

**案例：显示获得金币（事件触发）**

以金币飘字效果为例，需要使用【表现器-场景界面】和【事件触发区域】。

![](https://u5-creator.s3.game.163.com/manual/assets/example6.DjYqAFQr.gif)

1. 【组件-添加表现器-表现器类型】界面中选择【场景界面】，设置场景界面预设为【金币飘字】，关闭【游戏开始时触发】。
2. 设置【表现器1】的【触发表现的事件】为002，【关闭表现的事件】暂不填写。【周期触发时间】和【触发冷却时间】均为0。
3. 设置事件触发区域【进入区域触发事件】为002,即可实现蛋仔进入区域后触发+999金币飘字反馈的效果。

## 表现器的关联使用

### 组件互动功能关联

在组件高级设置的物理页下找到互动列表，此功能可以给组件添加按钮交互功能，玩家靠近组件出现交互按钮，点击按钮后触发组件互动表现。

开启组件的互动功能后，添加互动类型为表现器的互动。

点击【关联表现器】选择指定表现器，一个互动项只能配置一个表现器，并且一个表现器不可重复用于多个互动项中。关联表现器只能够关联已经创建的表现器。

![](https://u5-creator.s3.game.163.com/manual/assets/interact.BmLWySYj.png)

### 组件被破坏表现关联

表现器还支持被引用为组件的被破坏表现，可被破坏的组件健康值降为0时会触发被破坏表现。

1. 【预设编辑】中选择目标组件预设，表现-健康属性-开启可破坏设置为开；
2. 设置组件的健康值不为0；
3. 进入被破坏表现的配置页，关联已经创建的表现器；
4. 在预设编辑中设置血条显示模式为常驻显示，并应用到场景中（或者在场景中使用该预设创建一个实体）；使用蛋码动作积木<造成伤害>选择指定组件或者打开物品规则使用物品枪械攻击组件，组件健康值归零后会触发被破坏表现。

![](https://u5-creator.s3.game.163.com/manual/assets/Destruction1.DEKFHzmQ.png)

想要顺利预览被破坏表现需要修改表现持续时间，若为0则无法播放；打开淡出时间会导致组件切换到被破坏表现时模型会逐渐降低不透明度。

## 表现器相关的蛋码

* 激活表现器

激活表现器积木可以直接触发一次指定表现器效果。

需要指定具体的组件实体和输入对应表现器的名称（如表现器1），运行这条蛋码时会强行触发表现器效果。

![蛋码示例](https://u5-creator.s3.game.163.com/manual/assets/Activate.Cl9aQ0m9.png)

* 禁用表现器

禁用表现器积木可以解除一次指定的表现器效果。

需要指定具体的组件实体和输入对应表现器的名称（如表现器1），运行这条蛋码时会强行撤销该表现器效果。

![蛋码示例](https://u5-creator.s3.game.163.com/manual/assets/Deactivate.BNBDTVMp.png)

提示

和运动器的蛋码使用运动器的默认序号不同，表现器蛋码中指定表现器的方式为输入表现器名称。
