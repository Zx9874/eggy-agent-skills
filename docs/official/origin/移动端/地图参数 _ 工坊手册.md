# 地图参数

蛋仔地图中除了常规的地图设置和地图搭建的数据以外，还有大量的地图参数可以调整

## 地图规则设置

地图规则有两个入口：

1. 点击设置 - 地图设置 - 规则设置 - 编辑 即可跳转到规则设置界面
2. 点击更多 - 高级功能 - 规则设置 也可以跳转到规则设置界面

### 玩法规则

玩法规则可以决定一张地图在发布时会遵循哪些规则。并且在界面上方也提供了一些规则模板可以参考使用。

| 规则大类 | 细分规则 | 详细描述 |
| --- | --- | --- |
| 基础规则 | 信息展示 | 不显示：游玩时隐藏右上角的通关或剩余玩家数。 通关玩家数：显示已通关玩家的数量。 剩余玩家数：显示未通关玩家的数量。 |
| 胜利退场 | 可选呦呦退场，当玩家胜利后，可以搭载 yoyo 起飞退场。 |
| 掉落场地 | 复位：当玩家掉落到地图之外时，会触发复位行为，并不会扣除命数。 死亡：当玩家掉落到底图之外时，会触发死亡事件，会扣除命数。 |
| 胜利观战 | 改属性开启后，当玩家胜利后即可观战其他玩家，否则会原地挂机。 |
| 蛋仔！冲！ | 当该规则开启后，在刚开始一局时会显示“蛋仔！冲！”的控件。 |
| 淘汰观战 | 当该规则开启后，玩家淘汰且无法复活时可以进入观战状态。 |
| 入场形式 | 可选呦呦入场，当玩家初次出生时，可以搭载 yoyo 缓慢入场，类似于疯狂乱斗。 |
| 复活形式 | 可选呦呦入场，当玩家复活时，可以搭载 yoyo 缓慢入场，类似于疯狂乱斗。 |
| 计时规则 | 开启规则 | 开启规则后该地图将会有最长游戏时间，如果在最长游戏时间内没有达成胜利或失败条件，将触发时间终止规则。 关闭规则后单人（非开房间）游玩本地图将会不限制时长。 |
| 游戏时长 | 本地图的最长游戏时间，最大 3000 秒（50 分钟）。如需修改地图时间，请修改当前属性。 |
| 游戏模式 | 时间结束胜利：当触达最大时间后，剩余存活玩家胜利。 时间结束失败：当触达最大时间后，剩余存活玩家失败。 高分团队胜利：当触达最大时间后，剩余存活玩家中阵营分数更高的一方胜利，其余玩家失败。 |
| 积分规则 | 开启规则 | 开启规则后改地图将根据获得的积分判定玩家是否胜利。 |
| 目标积分 | 达到目标积分的玩家或阵营将胜利。 |
| 团队模式 | 开启团队模式后，积分的获取与判断将以阵营为准。 |
| 击败积分 | 当击败非同阵营玩家后，将获得的积分数量。 |
| 获胜后结束游戏 | 当有玩家获胜后，立刻终止游戏。 |
| 积分界面显示 | 是否显示得分界面。 |
| 死亡规则 | 开启规则 | 开启规则后，蛋仔可以有命数和健康值等属性。 关闭规则后，蛋仔掉落或死亡将会自动复位。 |
| 最大命数 | 当前地图中玩家的最大可复活命数。 |
| 复活时间 | 蛋仔死亡后复活的冷却时间。 |
| 自动复活 | 默认开启，如果关闭那么蛋仔复活将需要用蛋码复活。 |
| 最后存活获胜 | 当只剩下一个玩家时，判定该玩家获胜。 |
| 健康值 | 开启后蛋仔将开启健康值计算，如果健康值小于等于 0 则进入死亡状态。 |
| 质量 | 开启后将打开质量相关功能，类似于巅峰派对决战关。 |
| 复位 | 开启后在游戏中也支持复位功能，否则复位功能不可用。 |
| 倒计时 | 开启后玩家在等待复活时可以看到复活倒计时。 |
| 死亡规则 | 击败播报 | 开启后玩家可以看到淘汰信息。 |

### 相机参数

相机参数调整是制作玩法的重要内容之一；想要制作横版过关地图？亦或者制作第一人称恐怖地图？适当的调整相机参数才能够完美的实现你的构想。

首先让我们找到左上角的设置 - 地图设置 - 相机参数设置，点击调整参数后即可进入相机参数面板

![](https://u5-creator.s3.game.163.com/manual/assets/2_1_camera.dQ2uqzLA.png)

在模板中可以选取官方提供的预设，并且在左侧场景中预览相机效果，如果对官方效果不太满意的话，也可以点进调节面板详细设置每个参数。

![](https://u5-creator.s3.game.163.com/manual/assets/2_2_camtemp.CQvjQ1qE.png)![](https://u5-creator.s3.game.163.com/manual/assets/2_3_campara.CXT7BAyD.png)

| 参数设置 | 详细描述 |
| --- | --- |
| 正交相机模式 | 该属性开启后相机切换成正交相机模式，该模式下相机没有近大远小。 |
| 正交相机视域 | 该属性为正交相机的视场大小，数值越大，相机所包含的视域越大。 |
| 相机与角色的距离 | 该属性实际为焦距的长短，即该属性实则焦点到相机的距离，在默认情况下焦点在蛋仔脚下。如果调整了相机高度或水平偏移，则实际上改变了焦点位置 |
| 相机视场角 | 视场角越大，能够看到的范围越广。 |
| 锁定相机角度 | 该属性开启后，则摄像机锁定旋转，无法通过滑动屏幕等方式改变相机角度。 |
| 默认相机俯仰角 | 默认的相机在竖直方向旋转的角度。 |
| 最小相机俯仰角 | 相机在竖直方向可以旋转到的最小角度。 |
| 最大相机俯仰角 | 相机在竖直方向可以旋转到的最大角度。 |
| 相机高度 | 相机焦点位置的竖直方向的偏移。 |
| 水平偏移 | 相机焦点位置的水平方向的偏移。 |
| 隐藏本地角色 | 开启后相机将隐藏玩家控制的角色，多人游玩时依旧可以看到对方角色，常用语第一人称。 |
| 关闭相机缓动 | 开启后游玩时关闭相机移动的延迟效果会让相机完全绑定与角色的移动，常用于第一人称。 |
| 锁定面向到相机 | 开启后旋转镜头将影响角色朝向，并且角色移动将和朝向解绑。 |

  
  
  

## 给地图添加音乐

一张好的地图往往需要一个适合的背景音乐。那么蛋仔工坊联动了网易云音乐为大家的地图提供了背景音乐。

更多 - 网易云音乐 - 地图音乐设置 中，登录网易云账号并选择适宜的歌曲即可为所有游玩的玩家推荐背景音乐。

![](https://u5-creator.s3.game.163.com/manual/assets/2_4_music.BdxDPwqP.png)

同时，切换背景音乐也许也是很多玩家所需要的重要功能，在蛋仔工坊中，我们提供音乐切换器组件，你可以在机关 - 逻辑里面找到它。

音乐切换器通过特定的事件触发，将音乐切换至所选的目标音乐。

![](https://u5-creator.s3.game.163.com/manual/assets/2_5_musicswitch.DEcQ63B_.png)

  
  
  

## 天空、光照、雾效、滤镜

在虚拟引擎中设置合适的光照、雾效会极度影响场景的美观程度。根据不同的场景设置不同的天空球会非常有用。

### 怎么设置天空球

更多 - 天空背景 中有大量的天空球，点击对应的天空球就会立刻修改。

![](https://u5-creator.s3.game.163.com/manual/assets/2_6_skybox.CGV29g3b.png)

再次点击当前天空球就可以进入详细设置，其中包含了光照调节和雾效调节。

| 属性类型 | 属性 | 详细信息 |
| --- | --- | --- |
| 背景图 | X方向背景偏转 | 天空背景图在 X 轴方向上面的偏转角度。 |
| Y方向背景偏转 | 天空背景图在 Y 轴方向上面的偏转角度。 |
| Z方向背景偏转 | 天空背景图在 Z 轴方向上面的偏转角度。 |
| 扰动 | 开启扰动 | 扰动功能的总开关。 |
| 扰动强度 | 扰动强度越高，天空背景缩放的变化越强。 |
| 扰动密集度 | 扰动密集度越高，天空背景扰动的频率越高。 |
| 渐变设置 | 渐变轴向 | 少数天空球可以自定义渐变颜色，渐变轴向决定该天空球颜色的分布。 |
| 渐变颜色 | 决定天空球的颜色 |
| 渐变轴心位置 | 决定天空颜色的渐变位置的偏移 |
| 渐变对比度 | 影响渐变颜色融合的距离 |

  
  
  

光照属性

| 属性类型 | 属性 | 详细信息 |
| --- | --- | --- |
| 太阳光 | 光照强度 | 太阳光是场景中有方向的直接光源，它能生成定向阴影的光线。太阳光的光照强度会影响该场景的亮度。 |
| 光的颜色 | 光的颜色直接作用于物体表面的渲染颜色，在制作特定场景时，光的颜色需要适当调整，比如日落场景需要橙红色的太阳光。 |
| 光照俯仰角 | 光线在竖直方向上旋转的角度。 |
| 光照偏航角 | 光线在水平方向上旋转的角度。 |
| 环境光 | 环境光强度 | 环境光为场景中漫反射的光，它是影响全局的光源。环境光强度直接作用于漫反射的亮度，天空盒不受该属性影响。 |
| 环境光颜色 | 直接作用于全场景的光源颜色。 |
| 泛光 | 泛光曝光系数 | 直接作用于整个场景的额外曝光度。泛光仅在高清模式下生效。 |
| 泛光范围 | 泛光范围为亮度的筛选阈值，该数值越低，场景中会被视为泛光光源的地方越多。 |
| 泛光强度 | 泛光区域的亮度 |
| 泛光扩散度 | 泛光区域的大小 |
| 阴影 | 阴影弱化 | 阴影的不透明度 |
| 高级 | 反射天空图 | 在玻璃、水面等高反射度的表面上所呈现的背景图片。 |
| 颜色细节优化 | 也叫色调映射，会将高动态范围（HDR）的图像转为地动态范围（LDR）的呈现。具体表现为降低色彩的饱和度的同时呈现更多明暗细节，并且可以有效地避免过曝。 |

  
  
  

雾效属性

| 雾效属性分类 | 雾效属性 | 详细信息 |
| --- | --- | --- |
| 基础 | 开启雾效 | 雾效的总开关，当开启后可以调整雾效参数。 |
| 大气雾颜色 | 大气雾是柱状或环状的雾，大气雾颜色是该雾的颜色，它将直接作用于场景渲染的一部分颜色。 |
| 大气雾亮度 | 决定大气雾明度的参数，会乘算与大气雾颜色的明度值。 |
| 大气雾浓度 | 该参数实际作用类似于雾的不透明度，雾效越浓，参与场景渲染计算的百分比越高。 |
| 大气雾能见度 | 雾效开始生效的距离，可以为负数。该距离是从相机开始计算的，比如能见度为 50，那么雾效就是从相机 50 米外开始产生。 |
| 雾衰减的起始距离 | 雾效开始衰减不再增长的距离，雾效在到达这个距离之前会持续变浓，到达这个距离后将不再变浓，会维持现有的雾效浓度。 |
| 高度雾颜色 | 高度雾无限广阔但有高度限制的雾，高度雾颜色是该雾的颜色，它将直接作用于场景渲染的一部分颜色。 |
| 高度雾浓度 | 该参数实际作用类似于雾的不透明度，雾效越浓，参与场景渲染计算的百分比越高。 |
| 天空背景受雾效影响 | 该参数实际作用类似于是否将雾效渲染到天空背景之上。 |
| 高度雾衰减起始高度 | 高度雾不再变浓的高度，比如当它设定 5 米时，5 米以下都会有完全的高度雾。 |
| 高度雾消失高度 | 高度雾彻底衰减为 0 的高度，比如当他为 40 时，则 Y 轴坐标大于 40 的地方不会有高度雾。 |
| 太阳光在高度雾中散射 | 散射光颜色 | 在有雾的情况下，太阳光会有个散射弥散效果，类似于泛光。可以修改太阳光在雾中看到的颜色。 |
| 散射光收束度 | 散射收束度越高，该弥散效果越少。 |
| 散射作用结束距离 | 距离相机此距离开始弥散效果不再增强。 |
| 散射光高度 | 此弥散效果的亮度。 |
| 散射受大气雾影响程度 | 此数值为 0 时，散射效果只受到高度雾影响，为 1 时，散射效果只受到大气雾影响。 |

  
  
  

### 怎么设置色彩滤镜

更多 - 色彩滤镜 中有很多滤镜效果，适当的使用这些滤镜效果可以让地图的氛围感更上一层楼。

![](https://u5-creator.s3.game.163.com/manual/assets/2_7_filter.Cesk_--i.png)

选中即可切换并预览到对应的滤镜效果，再次点击即可详细调整滤镜参数

每个滤镜都有自己的属性参数，但滤镜也有通用的调节属性和后处理属性

| 属性类型 | 后处理属性 | 详细信息 |
| --- | --- | --- |
| 调节 | 开启调色 | 全局开关，控制是否启用所有颜色调整效果。 |
| 色相 | 调整颜色的基本属性（如红变橙、蓝变紫），改变整体色调倾向。 |
| 明度 | 控制图像整体亮度，数值越高画面越亮，反之越暗。 |
| 饱和度 | 调整颜色鲜艳程度，数值越高色彩越浓烈，越低越接近黑白。 |
| 对比度 | 增强或减弱明暗区域差异，数值高时光暗对比强烈，数值低时画面灰暗。 |
| 色温 | 调节冷暖色调（冷色偏蓝，暖色偏黄），模拟不同光照环境的色彩倾向。 |
| 色调 | 控制整体颜色偏向（如偏绿、偏紫），常用于修正或风格化画面。 |
| 调色 | 整体偏色程度 | 设置全局颜色偏移的强度，数值越高颜色偏离原始效果越明显。 |
| 中灰偏色 | 针对中间灰度区域（如物体表面）施加特定颜色偏移，影响画面主体色调。 |
| 中灰偏色程度 | 控制中间灰度区域颜色偏移的强度，数值越高中间调颜色变化越大。 |
| 暗部偏色 | 针对阴影区域（如深色物体）施加特定颜色偏移，增强暗部氛围感。 |
| 暗部偏色程度 | 调节阴影区域颜色偏移的强度，数值越高暗部颜色变化越明显。 |
| 亮部偏色 | 针对高光区域（如光源、反光）施加特定颜色偏移，改变亮部视觉风格。 |
| 亮部偏色程度 | 控制高光区域颜色偏移的强度，数值越高亮部颜色变化越显著。 |
| 暗角 | 开启暗角 | 启用画面边缘渐暗效果，模拟镜头暗角或聚焦视线。 |
| 暗角强度 | 调节暗角效果的深浅程度，数值越高边缘越暗，中心区域对比越突出。 |
| 暗角颜色 | 设置暗角区域的颜色（默认黑色，可改为深蓝/棕等），影响画面氛围。 |
| 像素化 | 开启像素化 | 启用图像分块马赛克效果，模拟复古游戏或低分辨率风格。 |
| 像素化数量规模 | 控制像素块的大小，数值越高块状越明显，画面细节丢失越多。 |
| 景深 | 开启景深效果 | 启用虚实分层效果，模拟镜头对焦，使主体清晰而背景模糊。 |
| 焦距远近 | 设置镜头的焦点位置（如近处或远处物体清晰），决定画面中清晰区域的范围。 |
| 景深深浅 | 控制背景虚化的强度，数值越高模糊程度越大，主体与背景分离感越强。 |
