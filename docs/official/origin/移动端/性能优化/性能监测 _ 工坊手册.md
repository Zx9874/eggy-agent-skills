# 性能监测

## 入口

在“工坊设置”——“高级设置”中打开“性能监测”的开关，即可在试玩时实时预览当前帧率和场景内组件的性能消耗

## 具体功能

试玩时将在右上角画面右上角显示当前帧率，展开后将进一步镜头内和地图内统计到的相关性能数据

![](https://u5-creator.s3.game.163.com/manual/assets/rt_performance_1.BCVHDgcB.png)![](https://u5-creator.s3.game.163.com/manual/assets/rt_performance_2.CZOOTSYO.png)

点击“性能分析”按钮，将跳出性能分析窗口，窗口中将展示镜头内和地图内模型/物理消耗最高的前三个组件/组合，并支持“隐藏”、“标记”和“撤销/还原”操作

![](https://u5-creator.s3.game.163.com/manual/assets/rt_performance_3.B3YKS-2C.png)

1、隐藏——可在试玩时快速隐藏选中的组件/组合

2、标记——标记该组件/组合，退出试玩后可在场景管理器中快速找到刚刚标记的组件以进行编辑操作

![](https://u5-creator.s3.game.163.com/manual/assets/rt_performance_4.D2XfjSdz.png)
