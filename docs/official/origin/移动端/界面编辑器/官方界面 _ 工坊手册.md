# 官方界面

本部分将整理官方提供的各种界面功能。

## 原生界面

使用蛋码<显示\隐藏原生界面>可以控制大部分官方界面的显隐。在开启对应原生界面的显示后，可以使用<显示\隐藏原生控件>单独控制该界面上原生控件的显隐，通过<设置原生界面文本内容>给原生界面填充自定义内容。

大部分原生界面都可以在编辑界面左上角设置>预览管理中启用预览，用于观察它们在画布上的位置，避免ui位置冲突。

## 规则界面

| 界面 | 功能描述 |
| --- | --- |
| 团队竞速积分\个人竞速积分 | 配合积分规则使用的顶部积分显示，适用于到达目标即结算的竞速积分规则。 |
| 个人排名积分\团队阵营积分 | 配合积分规则使用的右上角\顶部积分显示，适用于个人\阵营比拼最后结算分数的积分规则。 |
| 通关人数 | 通关人数可以在更多>规则设置>基础规则>界面相关中修改信息显示选项。 |
| 小队分数 | 显示团队当前的竞速总分 |
| 战斗结束\游戏结束界面 | 战斗结束界面会在画面中显示“游戏结束”动画字；游戏结束页面会在屏幕上显示烟花效果。 |
| 角色属性面板 | 配合更多>规则设置>击败规则里启用角色健康值；等级规则里启用角色等级使用。 |
| 计时界面\倒计时 | 在更多>规则设置>计时规则里可以修改倒计时时间，关闭计时规则后地图将转化为没有时间限制的无规则地图。 |
| 蛋仔冲 | 在更多>规则设置>基础规则>界面相关中也可以开关该动画的开关 |
| 塔防界面 | 塔防玩法会用到的波次显示等信息 |

## 决战技界面

更多>规则设置>附加规则中开启<是否启用决战技>能够在开场时调起所有玩家的决战技选择界面。

乐园决战技列表不支持作者单独配置选项。

使用蛋码<玩家选择决战技界面>可以动态调起指定玩家的决战技选择界面。

## 任务界面

在更多>任务里使用任务编辑器创建任务后，试玩时会出现任务接取面板。

使用<显示\隐藏原生界面>可以调整任务面板的显隐。

更多>规则设置>基础规则>界面相关中也可以开启<自动隐藏任务跟踪面板>，当玩家没有可从任务面板接取、进行、提交的任务时会自动隐藏任务面板。

## 商店界面

使用更多>物品系统商店功能制作的局内商店，可以将商店界面挂载在组件互动上，也可以使用蛋码<设置玩家商店显示>来开关显示。

一个玩家的界面同时只能显示一个商店，打开新的商店会关闭之前打开的商店。

## 背包界面

你可以使用编辑界面中名为“打开背包”的控件，它自带打开背包的逻辑。

也可以使用蛋码<设置玩家背包界面显隐>来打开\关闭角色背包。

## 商城界面

只要作者设置了付费商品，左上角就会显示地图商城的入口。

你也可以使用以下积木，在游玩过程中打开对应的商店\道具购买窗口，便于玩家消费。

| 蛋码 | 描述 |
| --- | --- |
| 设置付费道具商店是否可见 | 可以直接打开\关闭商城界面 |
| 对玩家显示商品详情弹窗 | 会显示单个商品的购买弹窗，附带商品详情 |
| 玩家显示商品限时购买提示 | 打开后会在右上角显示一个商品购买弹窗，弹窗的关闭键会在限时购买结束后关闭 |
| 前往礼包码兑换界面 | 使用后会让玩家直接跳转到礼包码兑换界面 |
| 打开粉丝团权益界面 | 使用后会让玩家直接跳转到粉丝团权益界面 |
| 显示乐园会员界面 | 使用后会让玩家直接跳转到乐园会员权益界面 |

## 结算界面

<设置玩家游戏胜利\失败>里可以设定展示成功\失败结算界面。

## 观战界面

更多>规则设置>基础规则中可以开启胜利观战和淘汰观战功能，玩家结算后将自动进入观战。

使用蛋码<玩家进入观战\玩家退出观战>可以强制指定玩家进入观战状态，条件积木<玩家是否处于观战模式>可以判断这一状态。

作者可以在更多>规则设置>附加规则中开关地图的局内观战功能，关闭后左上角不会显示观战按钮。

游玩时是否支持观战会受到房间观战设置的影响。

## 分享与点赞界面

蛋码<打开指定玩家的分享界面>可以让游玩玩家在局内打开分享地图的界面进行分享。

<玩家显示点赞界面>能够展开左上角的点赞窗口，组件<赞气收集板>也有同样功能，点赞显示只能触发一次。

## 分屏界面

分屏界面可以实时观察到另一个视角的镜头，类似派对玩法中玩家放的道具被其他玩家触发时会显示的场景小窗口。

性能提示

分屏界面性能占用巨大，极有可能造成玩家卡顿，需要谨慎使用。

分屏界面的位置支持在编辑界面中调整（在预览管理里打开后就可以在画布里调整位置了）。

分屏界面的使用：

1. 使用<显示\隐藏原生界面>打开分屏界面的显示；
2. 如果想要分屏相机跟随某个角色，可以使用<设置分屏画面相机目标角色>；如果想要相机固定观察某个位置，可以使用<设置分屏画面相机的位置>
3. 使用<设置分屏画面相机的属性>调整分屏画面的角度、高度、距离等
