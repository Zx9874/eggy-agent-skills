# 移动端主界面介绍

本页面将带你了解蛋仔派对编辑器中最常用的工具界面以及可以调整编辑手感的设置。

## 工坊编辑界面

打开工坊，从右侧组件库中拖出一个组件到场景中,点击场景中的组件，下方将会出现编辑工具栏。

这就是作图过程中最常见的场景编辑界面，我们来快速了解这个画面里你会经常用到的功能。

## 坐标系与坐标轴

### 坐标系

坐标系是游戏引擎中定位物体的基本框架。类似于经纬度和海拔一样的存在，可以用来定位组件在世界中的位置。

坐标系分为世界坐标系和局部坐标系。

**世界坐标系**就是引擎首先构建了一个世界，以（0,0,0）为原点，所有物体基于这个世界来标记各自的位置、旋转、缩放。我们点击组件的高级设置，其中的精准编辑就是组件基于世界坐标系中的实际坐标。

**局部坐标系**为基于当前组件的坐标系。如果把当前选中的组件视为该坐标系的原点，并重新展开一个的坐标系。

### 坐标轴

在蛋仔编辑器中，X 轴为红色，Y 轴为绿色，Z 轴为蓝色。对应的精准编辑也是相同的颜色帮助区分。

当点击并拖动对应的轴时，会根据目前的编辑状态进行对应的修改。拖动轴可以快速修改组件对应的位置、旋转或缩放。也可以关闭轴直接拖动组件来快速调整组件位置。

## 编辑设置

在地图编辑过程中，合理的运用编辑设置可以进一步提高作图的效率。

点击左上角的设置按钮，进入工坊设置界面，在高级设置中有大量的属性可以调节

| 选项名称 | 说明 |
| --- | --- |
| 画质 | 调整全局画质的选项。在不同画质下，组件的表现和切换 lod 距离会有不同。镜面、泛光等非常耗费手机性能的功能只在高清模式下生效。 |
| 视野 | 调整全局视野的选项。在不同视野下，组件的裁切距离也会有所变化。裁切距离和组件本身的大小、在视野中的大小、实际距离都有关系。 |
| 编辑模式 | 编辑模式分为沙盒模式和高级模式。  沙盒模式（超链接）为运行时编辑的模式。  高级模式为静态世界，不运行实际的物理，且该模式下可以编辑的功能更多，提供预设编辑、蛋码编辑等更多功能。 |
| 试玩模式 | 试玩模式分为沙盒模式和普通模式。  沙盒模式（超链接）为运行时编辑的模式。  普通模式为和乐园、主城等一样的战场模式，该世界运行正常的物理，且不可进行编辑。 |
| 编辑视角 | 编辑视角分为上帝视角和游戏视角。  上帝视角：一种类似 RTS 游戏的相机操控方式，在界面上拖动可以移动摄像机，双指操作可以旋转摄像机，双指缩放可以拉进或拉远摄像机。该模式下摄像机无法向上看。 游戏视角：一种类似第三人称的相机操控方式，在左下角的"显示蛋仔"处可以切换蛋仔模型的显隐状态。该模式下左侧配有移动轮盘，在屏幕上滑动可以旋转摄像机。 |
| 镜头速度 | 高级编辑模式下两种视角的移动速度。 |
| 网格显示 | 开关或切换网格颗粒度的选项。网格分为 0.5 米网格、1 米网格、2 米网格和自适应网格。在自适应网格的情况下，网格会根据摄像机距离焦点的距离动态调整网格的颗粒度。 |
| 网格不透明度 | 该数值越高，网格越明显，该数值越低，网格越透明。 |
| 自动上传间隔 | 为了防止地图进度丢失，每隔一段时间就会自动保存地图并上传。可自由指定保存并上传时间间隔。建议设置自动保存时间。 |
| 操作辅助 | 操作辅助分为叠放辅助、网格吸附、和组件跟随地形高度三个模块。操作辅助可以设置为简易、自由和自定义三个模式，切换到自定义后，上述三个模块可以根据需求自行制定。 |
| 叠放辅助 | 当模型叠放开启时，放置组件时会优先吸附到手指所在的组件上方。 |
| 网格吸附 | 当网格吸附开启时，放置组件和移动组件时会优先吸附到贴合网格的状态。移动操作会将组件包围盒贴合至网格。 |
| 组件跟随地形高度 | 当组件跟随地形高度开启时，地编模式下调整地形高度时，会将地形模块上面的其他组件一同移动，使其他组件依旧贴合地形模块。 |
| 网格跟随 | 当网格跟随开启时，聚焦组件的同时会将网格拉至同一平面。正交视角时也生效。 |
| 精准编辑 | 当精准编辑开启时，移动、缩放、旋转组件时会在底部增加快捷精准编辑面板。可以精细调整组件的精准编辑属性。在一些移动和旋转时还可以快捷切换世界空间和局部空间的变换。 |
| 长按穿透 | 当长按穿透开启时，长按场景中可以将按压出的所有组件以列表的形式列出，上下滑动即可精确选中所需要的组件。 |
| 蛋码菜单 | 蛋码菜单可以选择点击模式或长按模式；  点击模式：点击积木即可呼出蛋码菜单。  长按模式：长按积木呼出蛋码菜单。 |
| 性能监测 | 当性能监测开启时，试玩的时候会有一个性能分析菜单，用来检查当前地图是否符合大众游玩。 |
| 震动模式 | 当震动模式开启时，移动、旋转、缩放组件会有轻微震动。是否震动也和机型是否支持震动有关。 |
