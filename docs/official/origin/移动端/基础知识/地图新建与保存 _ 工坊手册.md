# 地图新建与保存

从新建草稿开始你的地图制作之旅吧！

本节将介绍地图草稿的创建流程和模版图类型，以及创建草稿后发布地图前必经的试玩和保存流程。

## 新建草稿

1. 在主界面进入蛋仔乐园，点击左下角`乐园工坊`进入工坊界面，点击右上角新建草稿；

![移动端](https://u5-creator.s3.game.163.com/manual/assets/newmap_mobile.CFfaiZn8.png)

2. 选择一张模版图，点击右下角`开始创作`即可创建草稿，创建后会自动进入草稿编辑。

![移动端](https://u5-creator.s3.game.163.com/manual/assets/newmap_mobile1.CLfeClVX.png)

---

每个工匠蛋能创建的草稿数量有限，工匠点越高，草稿数量上限也会增加；

加入激励计划、成为签约作者还可享受更高草稿上限。

| 工匠点等级 | 草稿数量上限 |
| --- | --- |
| lv.1 | 30 |
| lv.2 | 100 |
| lv.3及以上 | 200 |
| 加入激励计划 | 300 |

### 草稿复制

在工坊界面选中草稿可以复制草稿，选择复制后会自动在原地生成一个副本。

复制的草稿会继承原草稿的绝大多数数据，但以下内容会被重置。

* 共建者信息（包括参与过实时共建的玩家和原草稿权限人）
* 草稿创建和保存时间
* 绑定的已发布地图，不可以用复制草稿更新已发布的地图
* 谢礼数据
* 商品数据

### 草稿删除

草稿删除后，为避免误操作可能，会先进入回收站作为缓冲，期间作者可自行决定彻底销毁或恢复该草稿。

![回收站](https://u5-creator.s3.game.163.com/manual/assets/map_recycle.DJwsk9mD.png)

## 模版图类型介绍

**根据功能差异，模版图主要分为以下大类，请根据实际需求选择对应的类型：**

| 类型 | 说明 |
| --- | --- |
| 乐园地图 | 包括竞速、积分、生存等各种规则的地图，这类地图的共同点是有一个具体的通关目标； 也包括没有时间限制和胜利规则的无规则地图； 最多可容纳16个出生点，支持房间玩法，房间不支持随进随出，时间上限为一小时。 |
| Lua地图 | 支持编写Lua逻辑的地图模版，规则与普通乐园地图一致，仅pc端可创建。 |
| 步行街 | 发布的地图将允许其他玩家在步行街系统中使用和运营，支持玩家中途加入和离开； 不支持编写蛋码逻辑及剧情动画、物品系统等功能； 支持<菜单>功能，用于辅助步行街玩家进行角色扮演和出售服务； 最多可容纳32个出生点。 |
| 乐园岛 | 玩家可中途加入和离开地图房间，可理解为一个自定义的蛋仔岛屿； 不支持编写蛋码逻辑及剧情动画、物品系统等功能； 最多可容纳32个出生点。 |

## 地图试玩

试玩可以让我们随时体验到地图，并且可以通过试玩找到当前地图的问题；所以灵活运用试玩是极为必要的。

![](https://u5-creator.s3.game.163.com/manual/assets/1_11_playtest.DBYYiH90.png)![](https://u5-creator.s3.game.163.com/manual/assets/1_12_playtestsetting.CJhSGO-X.png)

点击试玩即可进入试玩模式，点击齿轮可以调整试玩参数，比如试玩方式、预设阵营、试玩存档和试玩权益

| 设置项 | 说明 |
| --- | --- |
| 试玩方式 | 可以切换为普通试玩和沙盒模式 |
| 预设阵营 | 可以调整试玩的阵营类型并且填充机器人用于测试 |
| 试玩存档 | 可以调整存档数据和成就计数等数据，用于存档相关功能的测试 |
| 试玩权益 | 可以开关乐园会员等功能，用于测试乐园权益 |

### 沙盒模式

切换到沙盒模式试玩，可以一边试玩地图一边编辑场景。

注意事项

沙盒模式下的物理较为特殊，暂时不支持组件攀爬、载具等功能。

发布后的实际效果依然以普通试玩为准。

沙盒模式分为运行模式和暂停模式：

* 运行模式

运行模式和普通的试玩一样。点击屏幕上方的运行模式即可切换到暂停模式。

* 暂停模式

在暂停模式下即可进行组件级别的编辑。下面是该模式的界面简介

![](https://u5-creator.s3.game.163.com/manual/assets/1_13_sandbox.xw9tEHY0.png)

| 功能 | 描述 |
| --- | --- |
| 菜单栏 | 提供和工坊菜单栏近似的功能，提供调整编辑设置、复位、开关真视模式等 |
| 切换菜单栏 | 在这里可以切换运行模式和暂停模式。并且左边的刷新按钮可以重新加载 |
| 占用值 | 在这里显示当前地图的占用值状态 |
| 快捷工具栏 | 从左到右分别可以调整网格显隐、贴合模式、视野 |
| 准星功能 | 点击可以开启或关闭准心功能，同时会切换预选中组件模式。当预选中组件后即可更高级的编辑组件。 |
| 创建面板 | 通过点击组件可以进入创建模式，点击组件栏可以调整常用组件。删除的组件会进入回收站。 |
| 飞行模式切换 | 点击后即可进入飞行模式，蛋仔不受重力制约，可使用喷气背包自由移动位置 |

## 存档与读档

蛋仔乐园工坊提供保存时自动上传云端的功能，在工坊设置里可以调整：

![存档读档](https://u5-creator.s3.game.163.com/manual/assets/map_autosave.REjvZOaC.png)

不过，在一些极端情况下还是有丢进度的可能。善用存档和读档功能可以更好的帮助我们确保地图进度安全。

![存档读档](https://u5-creator.s3.game.163.com/manual/assets/1_15_slsys.1FAD0jxN.png)

每张地图拥有三个跨设备的云端存档和三个不跨设备的本地存档。

![存档读档](https://u5-creator.s3.game.163.com/manual/assets/1_16_save.CkZxkqRc.png)

选择读档时可以看到地图中自动或手动存档，其中标有存档日期和存档名称等信息。

![存档读档](https://u5-creator.s3.game.163.com/manual/assets/1_17_load.B3Mh23pr.png)
