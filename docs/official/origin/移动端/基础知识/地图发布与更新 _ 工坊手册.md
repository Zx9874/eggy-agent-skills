# 地图发布与更新

发布地图可以将自己所制作的地图上传到蛋仔乐园中，让其他玩家能够游玩你的地图。

作者能够更新已发布的地图或下架地图。

## 发布地图的主要流程

发布地图所需要的流程如下：

1. 想要发布一张地图，首先需要点击菜单栏的设置按钮。
2. 然后在新打开的界面右下角可以看到发布地图的按钮。
3. 点击后根据情况可能需要游玩当前地图，到达终点即可触发发布页面。
4. 在发布页面填写发布信息后，可以选择定时发布或立即发布，确认后即可发布地图。

### 发布地图的补充条件

根据地图的规则，发布流程可能会有细微的不同。

不同规则所需要的条件不同,只有竞速规则和个人积分规则需要作者在发布前达成过关条件才能发图。

![](https://u5-creator.s3.game.163.com/manual/assets/1_9_ocupy.CY8VCmLL.png)![](https://u5-creator.s3.game.163.com/manual/assets/1_10_mappercent.BIRvY3lU.png)

另外影响到是否可以发布地图的因素是占用值或地图文件大小，它会显示在编辑界面的右上角。

当超过地图占用值上限或地图文件大小时，该地图无法发布上传。

## 地图可见范围修改

发布地图时可以设置地图的可见范围，设置地图可见范围将会限制其他玩家对地图详情页的查看合地图游玩权限，便于作者进行小范围测试或传播。

注意事项

设置了可见范围的地图，在作者个人主页仍然可见，，只有乐园搜索和详情页分享会受到限制 可见范围能够通过不下架更新进行修改。

![](https://u5-creator.s3.game.163.com/manual/assets/maprelease_visibility1.CmXkBH_p.png)![](https://u5-creator.s3.game.163.com/manual/assets/maprelease_visibility2.D5KvMr5T.png)

| 类型 | 说明 |
| --- | --- |
| 地图公开可见 | 地图能在蛋仔乐园中被所有玩家发现 |
| 地图好友可见 | 仅作者好友能够看到地图详情页和游玩 |
| 地图指定玩家可见 | 仅作者设置的指定好友能查看地图详情页和游玩 |
| 地图分享地图码可见 | 地图只能通过搜索地图码被找到 |
| 地图仅自己可见 | 地图仅作者自己可查看详情页和游玩 |

## 地图不下架更新

地图发布后也可以继续编辑内容并更新，其流程与发布地图一致。

1. 打开已发布地图对应的地图草稿，如果删除了原来的草稿，可以在已发布中下载地图草稿。

   ![更新](https://u5-creator.s3.game.163.com/manual/assets/map_update1.D7hSrwA6.png)
2. 修改草稿内容后，按照地图再发布流程更新地图，更新地图的时间间隔不能少于10分钟。

![更新](https://u5-creator.s3.game.163.com/manual/assets/map_update2.D70u5o9W.png)

3. 更新地图后，内容经过审核会快速更新到乐园中，但是当前游玩的玩家不会被影响，只有再次游玩时才能更新到新的内容。

   更新地图后会重新审核的内容：

   * 地图封面
   * 地图商城商品
   * 地图盲盒

地图信息更新

支持不下架更新的地图信息：

* 地图描述
* 地图封面
* 地图背景音乐

不支持不下架更新修改的信息：

* 地图名称
* 地图话题
* 活动参与信息
