# 手册

手册是游戏商业化的一种常见形式，玩家通过完成日常任务获得手册经验，提升手册等级获取对应等级奖励，购买高级手册还可以获得更豪华的奖励。

由于手册只支持使用金豆子定价，目前**仅向加入了激励计划的作者开放**。符合条件的作者可以在更多-地图商城中制作类似游戏当中赛季手册的手册商品。

## 创建手册

在更多-地图商城-手册管理点击左下角可以新建手册商品，单张地图最多制作20个手册商品。

![手册创建](https://u5-creator.s3.game.163.com/manual/assets/pass_create.BCBziDAz.png)

不建议一次发布多个手册商品！

手册并非单纯使用货币换取奖励的商品，而是让玩家通过持续游玩游戏逐步获得奖励的成长型系统。

因此，通过更新地图逐步推出适合不同游玩阶段的手册更加合适。

如果你一次性投放大量的手册商品，玩家完成一个任务可能会触发大量的红点，频繁地点击领取会让人感到疲劳，并且获得感也会随之降低；同时存在多个手册商品也容易让玩家丢失明确的奋斗目标。

在手册管理界面选中手册，点击打开进入对应手册的编辑界面。

地图手册不会出现在地图商城中。如果想在游玩时打开手册界面，需要在【编辑界面】功能里找到手册控件（功能-商业化分类下），选中该控件在高级设置中设置对应手册。在当前手册被启用的情况下，游玩时会显示该手册的入口；或者让玩家触发手册的显示事件打开手册界面显示。

## 手册基础配置

手册通常由【基础版】和【高级版】两个奖励模块组成，即使玩家没有付费购买高级手册，依然可以完成任务提升等级，获取该等级的基础版奖励。手册不仅是付费商品，也是对普通玩家游戏投入的奖励。

因此，手册不仅仅可以给你的地图带来金豆子收益，也可以提升所有玩家的游戏动力。

![手册配置界面](https://u5-creator.s3.game.163.com/manual/assets/pass_edit.B7se4vut.png)

手册基础页可以简要设置手册的图标、名称、最大等级，显示事件和高级手册价格，以及确认是否启用该手册。

> 关闭手册启用可以让地图中所有打开该界面的逻辑失效，适用于处理一些紧急状况！

高级手册价格设定范围为100~999。大部分游戏包括《蛋仔派对》都会在手册中投放远超手册售价的奖励，“超值”是手册类型商品最重要的卖点之一。

是否限时可以用于制作限时手册，手册持续时间结束后，玩家无法再调取手册界面购买和领取奖励。

终极奖励可以设置专属展示位，用于展示手册当中最具有吸引力的奖励。

点击右下角【效果预览】可以查看手册界面预览。

## 等级、任务与奖励

手册由奖励、等级、任务三大核心模块组成，玩家通过完成手册任务获得经验，通过积累经验提升手册等级，根据手册等级发放奖励。

在手册的基础配置页可以设定手册的等级上限，【经验列表】中可以设定升到每级需要的经验值。默认每一级升级需要100经验，你也可以设置重点奖励等级（比如5级、10级）需要更多经验值。

手册经验以任务的形式投放给玩家，切换到【任务】页可以配置每日任务、每周任务和永久任务，任务上限均为11个。

## 任务设计

在手册的【任务】页可以添加每日/每周/永久任务。

任务类型只有刷新次数的区分，配置信息基本一致。

![任务设置](https://u5-creator.s3.game.163.com/manual/assets/pass_quest.CAUB5SSu.png)

| 属性 | 描述 |
| --- | --- |
| 名称 | 任务的名称，会显示在手册任务面板上 |
| 描述 | 任务的描述，会显示在手册任务面板上 |
| 经验奖励 | 完成该任务玩家会获得的手册经验值，可以用于提升手册等级 |
| 进度增加事件 | 发送附带玩家信息（界面触发事件、事件触发区域、<发送事件给指定玩家>动作积木等）的事件会增加玩家的任务进度一次 |
| 完成所需进度 | 累计进度达到该计数目标才算作完成任务 |

### 每日任务的设计

每日任务以自然天作为有效范围，零点刷新可完成次数，通常配置一些简单容易完成的任务。

以蛋仔的赛季手册的每日任务为例：

![赛季手册任务举例](https://u5-creator.s3.game.163.com/manual/assets/pass_daily.hfSc0zRz.png)

1. 大部分基础任务进度通常只有1~2次，比如登录游戏；参与一局游戏；抽取一次盲盒等，只需要非常简单的步骤就可以完成，并且没有门槛限制。
2. 任务覆盖了游戏的主要流程，给玩家提供了游戏目标。比如玩家打开游戏/进入地图时并没有什么明确的目的，跟随任务要求玩家会主动参与派对、游玩乐园等，感受玩法的乐趣。
3. 在普通任务之外，也会有一些进阶任务，比如每日进行3次游戏和每日进行5场游戏是每日进行1场游戏的进阶版本，这样的设计会让每日任务更有层次感。

### 每周任务的设计

每周任务以自然周作为有效范围，每周一刷新可完成次数，通常配置需要累计进度的基础任务，以及高级任务。

依然以赛季手册为例：

![赛季手册周常任务举例](https://u5-creator.s3.game.163.com/manual/assets/pass_weekly.bjXMfuXE.png)

1. 每周任务通常会有需要多次完成的任务，用于奖励累计进度。比如获得100潮流纤维，参加3场生存赛等。
2. 每周任务会增加一些有硬性时间要求的任务，比如参加三天钓鱼。
3. 每周任务相对简单的每日任务来说，会增加一些高级的拓展任务，比如蛋仔赛季手册的周任务会鼓励玩家参加艾比和农场玩法，引导玩家更换一次脸型。你可以借助周任务引入一些地图中主玩法以外的内容让玩家尝试。

手册任务与玩法循环

每日任务和每周任务根据时间刷新，往往需要玩家重复完成一样的任务，也就是说，它们的效果其实建立在玩法循环上。

如果你的地图玩法流程并没有那么长，日任务和周任务的设计会显得相对多余。

日任务和周任务并非一个手册的必需设计，你可以根据地图实际玩法重新分配投放经验的任务类型。

### 永久任务的设计

永久任务是一次性的任务，不会根据时间刷新，通常配置一些难度较高的任务。

手册的永久任务跟成就奖励，以及新手\主线任务是有区别的，主要是作为手册经验投放的补充，不需要和整个游戏流程强关联。

当然，你也可以根据你的手册设计目的，只使用永久任务的形式投放经验，不需要玩家每天或者每周刷任务进度。采取这样的做法需要认真规划经验的投放，确保所有任务提供的经验值大于等于手册满级所需的经验值。

## 等级与经验

等级是手册的核心模块，任务经验的投放量最终是根据手册的等级体系来分配的。

创建手册时，你需要认真考虑这个手册对于玩家的时效有多长，即玩家需要投入多久时间可以拿完所有奖励。然后再根据这个目标，规划玩家第一天第二天甚至第二周第三周能完成多少手册进度，倒推出来手册任务应该提供多少经验值。

你可以根据具体的地图内容量来设计手册的时效，借助手册的等级体系提高玩家的长期留存。

如何设计手册经验的投放

如果我们想制作一个双周时效的地图手册，可以按照如下步骤来分配经验的投放：

1. 为了给玩家留有余裕，即不需要完成所有任务也可以达到满级拿完手册奖励，我们要投放的经验可以定到满级所需经验的1.5倍左右。倍率越大对玩家来说达到满级越容易。
2. 在1.5倍经验总量的前提下可以开始分配不同类型任务承担的经验比例，可以参考下表的比例分配。

| 任务类型 | 比例参考 | 描述 |
| --- | --- | --- |
| 每日任务 | 20% | 每日经验通常用来提供稳定的经验来源，活跃玩家可以通过完成每日任务更快提升等级 |
| 每周任务 | 45% | 每周任务提供大量经验，对于只能周末上线的玩家群体来说更友好 |
| 永久任务 | 35% | 永久任务可以快速提供大量经验，对日常周常任务没刷满的玩家起到经验补充作用 |

3. 如果希望玩家长期活跃在地图玩法中，建议计算一下玩家第一天、前三天、第一周能获取到的经验上限，确保玩家不会因为太早达到满级丢失目标。

## 奖励投放

手册奖励分为基础和高级两个部分。

目前支持作为手册奖励投放的奖品只有物品和游玩奖励。

物品需要打开物品规则使用；游玩奖励需要上架地图商城中的付费道具到商店后，将商品获取方式改为【游玩奖励】即可作为手册奖励发放给玩家。

一个奖品栏只能投放一种奖励，可以自定义投放数量。

![奖励设置](https://u5-creator.s3.game.163.com/manual/assets/pass_reward.DGuzdc5v.png)

> 如果想在一个档位投放包含多个类型道具的奖励，可以在商店里将道具包装为礼包，再将商品获得方式更改为【游玩奖励】，就可以在手册奖励中投放组合奖励。

### 基础奖励

基础奖励面向所有玩家，用于奖励玩家持续在游戏中投入时间和精力。

无门槛的奖励能让玩家注意到手册的存在，并且随着手册等级提升，附加的高级奖励对玩家的吸引力也会更强。

基础奖励栏位通常会给予玩家各种基础道具，在重点等级节点会提供更丰厚的奖励，比如增加道具奖励的数量或者投放一些特殊奖励。

基础奖励可以投放的奖励类型：

1. 游戏内货币
2. 游戏内属性
3. 地图商城里售卖的基础道具
4. 简易的服装配饰

……（仅供参考）

### 高级奖励

高级奖励需要玩家付费解锁，再通过做任务积攒进度获得。

手册的核心卖点是高性价比，玩家用较低价格购入再加上时间投入可以获得4~5倍售价的内容。

高级手册可以投放的奖励类型：

1. 较基础手册数量更多的普通货币和道具
2. 较为稀缺或价值更高的高级道具
3. 仅可通过高级手册获得的稀缺服饰、武器或特殊道具（通常会作为手册大奖）

## 注意事项

1. 手册一旦正式发布，不可更改任何配置信息。
2. 删除手册入口（目前仅开放界面控件进入的方式）可以起到手册下架的效果，玩家不会再触发手册界面，也不能继续完成任务和领取奖励。
3. 手册的配置可跟随草稿被复制到新草稿中，但是手册配置的游玩奖励属性商品不会被保留。
