# 地图盲盒

使用更多>地图商城>地图盲盒里的自定义盲盒功能，无需编写额外逻辑，只需配置奖池概率和具体奖品就可以给地图增加随机抽奖机制。

## 创建盲盒

进入地图盲盒功能后点击左下角`盲盒管理`新建盲盒。

盲盒管理列表中可以使用开关来控制盲盒的启用状态，开关为关时，试玩不会在地图商城中显示相关界面。

点击盲盒左侧的齿轮可以复制（原地创建一个配置相同的副本）和删除盲盒。

## 盲盒配置

进入盲盒界面后，可以在右侧界面配置盲盒的显示内容，点击右下角可以预览盲盒界面。

![盲盒界面显示预览](https://u5-creator.s3.game.163.com/manual/assets/gacha_view.Bo4bFYF8.png)

支持配置的盲盒属性如下：

| 属性名称 | 描述 |
| --- | --- |
| 是否启用 | 关闭后盲盒不会显示在地图商城中，玩家无法抽取 |
| 展示事件 | 触发展示事件会强制弹出盲盒抽取界面 |
| 货币类型 | 抽奖消耗的货币种类，支持乐园币、金豆子和属性规则中的玩家属性 |
| 单抽价格 | 抽取一次消耗的货币数量，范围 1-99999 |
| 十连抽折扣 | 十连抽的价格折扣，范围 0.3-1.0 |
| 大奖概率 | 单次抽取命中稀有池的概率，0-1之间 |
| 大奖保底 | 连续未中大奖的最大次数，达到后下一次必中大奖，范围 1-1000 |
| 启用限时 | 是否限制抽奖时间段，开启后可以设置具体开放时间段 |

## 奖品配置

商城道具和物品组件都支持作为奖品加入盲盒奖池。

商城道具来自于地图商城中创建的付费道具，物品来自于物品分类下的组件预设。

抽取盲盒获得的商城道具会显示在地图商城-地图背包中；获得的物品会显示在物品背包中，背包容量满时则会直接生成实体在角色旁边。

奖品支持在左侧奖池界面直接配置，也可以在右侧的盲盒属性界面切换到奖品配置页添加和修改商品。

| 奖品属性 | 描述 |
| --- | --- |
| 奖品权重 | 奖品权重越大，抽取概率越高。系统会自动计算当前奖品权重值/所属奖池中全部（未被抽取）奖品权重值之和得出当前奖品的抽取概率。 |
| 奖品数量 | 玩家抽取盲盒获得的奖品数量，范围 1-100。 例如投放的奖品是100金币道具，可以通过设置数量让玩家抽取到该奖品时获得3\*`100金币`或1\*`100金币`，无需设置多个道具预设也可以区分不同等级的奖励。 需要注意的是这里的奖品数量是对于玩家而言的获取数量而非投放数量。 |
| 是否放回（无限） | 该奖励是否无限投放。关闭时，玩家抽取奖品后，该奖品会被移出奖池，可能导致后续抽取奖品数量不足。此属性适合对永久获取类型道具开启开启时，该奖品将会无限补充库存。此属性适合对消耗/可叠加性质道具开启。 |
| 稀有奖品配置（是否作为大奖展示） | 仅稀有池奖品可开启，开启后该奖品将作为大奖展示。可以选择是展示预设图标还是自定义图片，类似换装道具的商品就可以使用自定义图片给玩家展示穿戴时的样子。 |

### 盲盒配置规则

1. 盲盒奖池分为稀有池和普通池，每个奖池可以配置多个奖品。通常来说，稀有奖品池会投放价值更高、种类更稀有的奖品。
2. 盲盒奖品不足时会拦截玩家的十连抽行为，因此尽量保证奖品池里投放了不限量的奖品。
3. 在奖池编辑界面长按奖品可以调整奖品顺序，稀有奖池第四个之后和普通奖池第十个之后的奖品在界面里会相对不够显眼。可以把吸引力高的奖品放在靠前的位置展示。
4. 默认情况下，奖池奖品右上角显示的概率是根据权重计算该奖品在所属奖池的概率；在奖池编辑右上角打开<查看最终概率>会显示出综合奖池命中率计算的奖品最终被玩家抽中的概率，盲盒描述中公示的概率也是最终概率。

### 奖池和奖品的概率配置

盲盒功能提供的默认抽奖机制是一个双轮盘结构盲盒，即分为稀有池和普通池两个奖池。

1. 每次抽取时，按照配置的奖池概率，先判断本次抽中的是稀有池还是普通池。若其中有一个奖池的奖品被全部抽完，则默认命中未抽完的奖池。
2. 概率命中具体奖池后，再按照作者配置的奖品权重抽取对应奖池内的奖品。概率越高越容易抽中，已抽中且不放回的奖品会被移出权重计算。
3. 盲盒使用通用保底机制：若玩家连续未抽中大奖的次数达到作者在盲盒配置设定的<大奖保底>次数，本次抽奖将强制命中稀有池，根据稀有池内剩余奖品的权重来抽取。玩家每次抽中稀有池奖品后，保底次数将会被重置。
4. 同一地图\同一房间内不同玩家的盲盒奖池奖品库存和概率是独立的，玩家的抽取结果不会影响其他玩家。

注意事项

稀有池概率为0时，试玩\发布地图时会拦截盲盒抽取行为，因此如果只想要启用普通池的情况下也不要把稀有池概率设置为0。在稀有池未抽取到奖品时依然会全部命中普通池。

## 盲盒入口设置

盲盒界面存在多种触发方式。

1. 地图商城盲盒界面：启用盲盒则该盲盒界面会自动在地图商城中显示，这个入口依赖玩家主动寻找。
2. 界面控件触发：使用编辑界面的盲盒控件，可以作为指定盲盒界面的入口，这个按钮会显示盲盒图标。
3. 事件触发：在盲盒设置界面设置<显示盲盒的事件>，之后玩家触发该自定义事件时会弹出该盲盒界面。
4. 蛋码触发：使用积木<打开指定盲盒>可以使用蛋码让指定玩家触发指定的盲盒界面。
