# 商品

在更多-地图商城功能里可以制作地图内购商品。

和【物品商店】里上架的“物品”不同，地图商城里的“商品”收入可以转化为作者收益。

物品商店功能通常代表游戏内的经济系统，而地图商城代表的是内购道具，玩家使用外部货币来交换地图权益。

## 商品创建与上架

商品一般指地图中直接售卖的商品。不过在工坊的不同功能模块中，商品根据使用场景拥有不同的形态，下表介绍了常见的名词概念。

| 名称 | 创建方式 | 使用方式 |
| --- | --- | --- |
| 道具 | 在地图商城-道具管理中直接创建 | 上架商店；地图盲盒奖品；包装礼包 |
| 商品 | 上架道具到商店中创建 | 商店直购，也可设置无需购买的获取方式 |
| 游玩奖励 | 在商店中将商品获取方式设置为游玩奖励 | 玩家属性兑换；手册奖品；签到奖励；任务奖励；成就奖励；蛋码给予；兑换码奖励 |

### 创建道具

在地图商城的道具管理界面可以新建道具草稿，这里创建的商城道具是商品的初级形态，用于定义“卖什么”。

![创建道具](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_goods_paiditemcreate.DofC-SR2.png)

| 基础属性 | 描述 |
| --- | --- |
| 名称 | 道具名称，直接上架则会作为商品名称 |
| 图标 | 道具的展示图标 |
| 简略描述 | 道具功能的简要描述，如果作为商品直接上架会显示为商品信息，用于描述核心功能 |
| 稀有度 | 道具的稀有度，对应游戏当中的稀有度背景图 |
| 详细描述 | 道具功能的详细描述，玩家长按道具时会显示 |
| 消耗方式 | 永久类道具无法被消耗；按数量消耗类道具使用一次消耗一个；按时间类消耗道具在使用后开始计时，到期后自动消失（不受游戏进出影响） |
| 货币类型 | 售卖所使用的货币，默认为乐园币。开通激励计划的作者可以选择金豆子作为价格单位 |
| 售价 | 乐园币范围为100~500；金豆子范围为5~2000 |
| 可在商城中使用 | 开启则能够在地图背包中使用，不开启则玩家不能主动使用道具。 |

### 上架商店

将制作完成的道具上架到商店中，就可以在商店中配置发放渠道了，在商店里配置的信息代表“怎么卖”。

![上架商品](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_goods_shopgoods.DCDqlW2u.png)

| 基础属性 | 描述 |
| --- | --- |
| 包装礼包 | 开启后将商品转换为包含多个道具的礼包 |
| 选择商品 | 更换商品使用的道具预设 |
| 是否在商城显示 | 关闭后，该商品不会在地图详情页和游玩时的地图商城显示，只会在生物互动中配置的商店显示 |
| 在商城显示事件 | 发出该事件后，原本不显示在商城的商品会显示在商城中 |
| 在商城隐藏事件 | 发出该事件后，原本显示在商城的商品会隐藏 |
| 获取方式 | <货币购买>通过消耗乐园币或金豆子可以直接购买；<观看推广>观看广告后可以获得该商品；<会员领取>乐园会员可以免费领取该奖励，限一次；<游玩奖励>该道具无法直接购买，需要通过游玩获得，可配置在签到、任务等多个功能中，也支持消耗玩家属性（如金币或其他自定义货币）兑换 |
| 商品折扣(仅货币购买类型) | 商品会显示进行折扣出售，最低三折 |
| 限时出售(仅货币购买类型) | 该商品只在一定时间内售卖，将根据服务器时间自动上架和下架，时间跨度不超过30天，以编辑地图的当前时间作为范围起始时间。 |
| 需要观看推广次数（仅观看推广类型） | 玩家获取该商品所需观看推广视频次数（需要连续观看，不宜设置过高），最大为3 |
| 消耗货币类型（仅游玩奖励类型） | 可以消耗玩家属性（在规则设置-玩法规则-属性规则中设置）购买商品，设置为无时商品不会显示在商城中；设置为玩家属性时下方会出现【消耗货币数量】属性，可以设置获得一次商品具体需要消耗的自定义货币数量。 |
| 限购数量 | <货币购买>类型下为购买该商品的限制次数；<观看推广>类型下为通过看广告获得商品的限制次数；<会员领取>和<游玩奖励>实际不受到该参数影响 |
| 限购类型 | 商品的限制购买方式：永久表示每个玩家终身只能购买限定次数，永远不会重置限购次数；单局表示玩家每次进入游戏，限购次数都会被重置，开启后该商品不会显示在地图详情页中，只能在游玩时购买 |
| 显示到推荐页 | 开启后商品会显示在商城第一页 |
| 显示热销标签 | 开启后商城里的商品左上角会被标记为热销，吸引玩家购买 |

上架到商城的商品，在试玩时可以进入地图商城购买。

### 包装礼包

礼包可以组合售卖多个商品，在商店商品设置中勾选【包装礼包】即可创建礼包类商品。

![包装礼包](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_goods_pack.IzaLQP-x.png)

| 礼包属性 | 描述 |
| --- | --- |
| 礼包内商品 | 此处可以添加【道具管理】里的付费道具作为礼包内容，支持配置多个道具（最多5种），消耗类道具最多可以配置99个， |
| 礼包名称 | 礼包的显示名称，如“新手礼包” |
| 礼包图标 | 礼包在商城中显示的图标 |
| 礼包简述 | 礼包在商城里显示的描述，建议描述礼包的主要卖点 |
| 详细描述 | 礼包在购买详情弹窗显示的描述，建议描述礼包的详细内容 |
| 售价 | 在获取方式为货币购买的情况下，礼包价格为礼包内所有道具价值的总和，不支持单独定价 |

## 商品发布与更新

根据相关规定，含有付费道具的地图需要经过官方审核后才能发布。

1. 道具进入审核后，作者无法更改道具信息（如售价等基础配置），但能更改道具上的蛋码功能。
2. 地图内所有道具都通过审核，地图才能正常发布；地图内有未通过审核的道具则需要对道具进行下架或修改，否则地图会停留在审核状态。
3. 作者无法自行下架含有金豆子道具的地图，需要通过地图蛋向官方申请并自行承担后果。
4. 地图发布后，已上架的商品可以进行下架，但是审核通过的道具无法删除。即作者可以更改销售方式，但不能影响已购买该道具的玩家的权益。
5. 地图商品数据不跟随草稿一起被复制，道具信息会保留，但是商品需要重新上架。

## 商品功能制作

玩家愿意给商品付费，往往是因为它们的作用能带来更好的游戏体验。

目前主要有两种方式可以赋予商品功能。

### 使用道具效果模版

在道具设置界面的【属性】分页，可以快速给道具添加预设效果。

![道具效果界面](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_goods_itemfunction.DvCrW5gz.png)

官方提供了以下功能模版，同一个道具上可以组合使用。

| 功能名称 | 描述 |
| --- | --- |
| 属性变化 | 可以提供蛋仔属性的变化，如攻击力、健康值等。自定义蛋仔属性在规则设置-玩法规则-属性规则中设置。 |
| 修改玩家属性 | 可以提供玩家属性的变化，如金币等。自定义玩家属性在规则设置-玩法规则-属性规则中设置。 |
| 获得预设 | 可以创建一个组件预设在玩家蛋仔脚下，通常用于给予玩家物品或道具。 |
| 获得效果 | 可以赋予玩家效果，如加速效果。自定义效果在预设编辑-效果库中添加。 |
| 获得技能 | 可以赋予玩家技能，如垫脚石技能。自定义技能在预设编辑-技能库中添加。 |
| 外观变化 | 可以更换玩家形象，给玩家穿cos服。自定义外观预设可以先保存一个自定义生物预设，再在该预设上修改自定义外观，根据情况在表现页选择模型是否显示。 |

道具的【使用时生效】属性若为关，则玩家获得道具就会立刻获得道具效果；若为关，玩家获得道具后需要在地图背包中主动使用方生效。

### 使用蛋码编写道具功能

在道具界面右下角的【编辑蛋码】中，可以编写道具预设上的蛋码。

道具预设所使用的事件有<获得当前付费道具>和<当前道具被消耗>

<获得当前付费道具>事件会在玩家进入游戏或获得道具时触发，通常用来触发永久获得类的效果如技能、属性等，优点是可以省略使用商品的步骤，立刻兑现道具的效果。

1. 如果商品显示在地图详情页商城中，玩家是可以在外部购买再进入地图的。
2. 由于每次进入地图都会触发，道具不会被消耗的情况下（如永久类型）可能会触发重复加成，破坏数值平衡。
3. 如果道具提供的效果具有很强的场景性，譬如只在地图中某个关卡可以正常生效；或者具有很强的限时性。那么不建议使用这条事件去实现道具效果。

如果想在购买道具后立刻消耗，可以按照以下逻辑编写蛋码。

![道具蛋码案例](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_goods_eggycode.BEA6a9ZC.png)

<当前道具被消耗>事件会在道具被玩家使用或蛋码<消耗付费道具>生效时触发，通常用于触发消耗类道具的效果，道具被消耗后数量会减少。

> 玩家主动在背包中使用一次只能消耗一个；使用蛋码<消耗付费道具>一次会消耗多个，编写蛋码时需要注意不要漏掉消耗多个的场景。

## 道具调试

编辑好道具功能后，建议先进行测试再上架到商店中。

在道具管理左上角找到【调试】，这里可以配置试玩时拥有的道具，用于直接测试道具的使用逻辑，免去了上架商店、进入商店购买的步骤。
