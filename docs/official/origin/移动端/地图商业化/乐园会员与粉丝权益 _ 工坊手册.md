# 乐园会员与粉丝权益

乐园会员和粉丝成员在地图游玩收益中占据更高的比重，他们往往是乐园的深度玩家，并且在游玩时的付费意愿也相对较强。

通过给乐园会员和粉丝成员提供地图中的特殊权益，可以更好地联系这部分受众。

在更多-地图商城-特殊权益中可以开启相关功能。

![特殊权益界面](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_privileges_setting.DrEsBvgP.png)

## 乐园会员权益

开启乐园会员权益后，未开通会员的玩家进入地图时会触发乐园会员开通界面。

你也可以在地图中发送【会员权益显示事件】主动给玩家推送乐园会员开通界面。

在地图商城权益配置界面中，你可以使用以下官方预设效果模版给会员玩家赋予专属权益，让他们享受更好的游玩的体验。

| 效果模版 | 描述 |
| --- | --- |
| 属性变化 | 可以提供蛋仔属性的变化，如攻击力、健康值等。自定义蛋仔属性在规则设置-玩法规则-属性规则中设置。 |
| 修改玩家属性 | 可以提供玩家属性的变化，如金币等。自定义玩家属性在规则设置-玩法规则-属性规则中设置。 |
| 获得预设 | 可以创建一个组件预设在玩家蛋仔脚下，通常用于给予玩家物品或道具。 |
| 获得效果 | 可以赋予玩家效果，如加速效果。自定义效果在预设编辑-效果库中添加。 |
| 获得技能 | 可以赋予玩家技能，如垫脚石技能。自定义技能在预设编辑-技能库中添加。 |
| 自定义效果 | 可以发送一个自定义事件，并填写自定义描述 |

作者添加的权益效果都会展示在乐园会员界面的【地图专享】页，在右下角点击【预览】可以直接查看界面表现。

![会员权益界面](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_privileges_membership.CBIW6GGK.png)

## 乐园会员领取商品

你还可以设置付费道具作为会员权益。

上架一个商品到商店当中，设置获取方式为【会员领取】，会员可以在商城中免费领取一次该商品。

![会员商品](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_privileges_goods.DrwKDsmk.png)

设置了会员权益的地图，商城中也会显示乐园会员的开通入口。

## 自定义乐园会员权益

你还可以使用蛋码，根据地图玩法编写特殊乐园权益。

如使用<是否为乐园会员>的条件积木，搭配<如果否则>的控制积木进行判断：

![会员权益编写案例](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_privileges_eggycode.Bfp4R_xO.png)

可以搭配蛋码<显示乐园会员界面>，在确认使用权益前展示给玩家开通入口。

自定义的蛋码权益不会自动显示在乐园会员的地图专享权益界面中，建议在地图商城的权益配置界面添加【自定义效果】，补充使用蛋码自制的权益内容展示给玩家。

另外，事件触发区域也具有乐园会员的专属功能，可以设置该事件触发区域只有会员蛋仔进出可以触发对应事件。

![事件触发区域会员](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_privileges_eventvolume.oOYsEYWI.png)

## 粉丝勋章权益

累计工匠点达到一万以上的作者将会开启粉丝团功能，作者可以命名自己的粉丝勋章名称，每个作者只能设置一次。

玩家在地图详情页进入作者主页花费10金豆购买【粉丝团券】道具即可成为作者的粉丝团成员，之后可以在个人信息/乐园主页装配粉丝勋章。玩家最多可以加入50个作者粉丝团，暂时没有退出机制。

以下是官方给作者粉丝团提供的默认粉丝权益：

![官方粉丝团权益1](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_privileges_fans_official1.Cw4n21j7.png)

![官方粉丝团权益1](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_privileges_fans_official2.Da_ps9Aa.png)

作者可以在自己的地图中设置粉丝团成员的地图专享权益。

进入更多-地图商城-特殊权益功能开启【粉丝勋章权益】

你可以通过在游玩时发送【显示事件】向玩家推送粉丝团权益弹窗，游玩时对专属权益和玩法的需求能强化玩家的购买动机。

与会员不同，粉丝勋章权益可以根据粉丝等级发放权益。

因此作者在编辑粉丝权益时，也需要配置不同等级可以获得的权益效果。

粉丝权益提供的官方效果模版基本和会员权益一致，但是每一级同一类型的效果最多开放一种，不能添加多次。

| 效果模版 | 描述 |
| --- | --- |
| 属性变化 | 可以提供蛋仔属性的变化，如攻击力、健康值等。自定义蛋仔属性在规则设置-玩法规则-属性规则中设置。 |
| 修改玩家属性 | 可以提供玩家属性的变化，如金币等。自定义玩家属性在规则设置-玩法规则-属性规则中设置。 |
| 获得预设 | 可以创建一个组件预设在玩家蛋仔脚下，通常用于给予玩家物品或道具。 |
| 获得效果 | 可以赋予玩家效果，如加速效果。自定义效果在预设编辑-效果库中添加。 |
| 获得技能 | 可以赋予玩家技能，如垫脚石技能。自定义技能在预设编辑-技能库中添加。 |

玩家可以通过游玩作者地图、消费作者地图商品提升粉丝等级。

## 自定义粉丝勋章权益

除了使用地图商城中官方提供的权益效果模版，你还可以使用蛋码编写自定义的粉丝权益。

在蛋码中找到<获取玩家工匠粉丝等级>积木，通常来说它需要搭配控制积木<如果否则>和条件积木<比较>对获得的玩家等级进行大小判断。

## 试玩时权益模拟

为了方便作者测试以上权益功能，我们提供试玩时模拟会员或粉丝团身份的快捷方式。

点击试玩按钮左上角的齿轮打开试玩设置界面，切换到【试玩权益】分类，可以设定试玩时模拟的情况，包括试玩时身份是否为乐园会员、粉丝团成员等级。

![权益试玩模拟](https://u5-creator.s3.game.163.com/manual/assets/ugcgoods_privileges_test.bUklbsuA.png)

> 仅模拟玩家1身份，填充AI测试时AI玩家无法设置试玩权益。

多人测试时，将按照参与玩家本身真实的权益获取情况作为根据发放权益。
