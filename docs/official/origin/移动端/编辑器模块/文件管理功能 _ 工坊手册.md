# 文件管理功能

## 作用

可以让作者自由上传图片、音频并在地图中使用

## 功能开放条件

历史最高工匠点达到 10000 点后开放

## 功能入口及文件上传流程

1. 从【更多】-【文件管理】入口打开文件管理界面

![](https://u5-creator.s3.game.163.com/manual/assets/filesystem1.RP9qdmkC.png)

2. 点击【上传图片/音频】按钮拉起手机的资源选择界面

![](https://u5-creator.s3.game.163.com/manual/assets/filesystem2.Hbrcm3ej.png)

3. 文件需要符合上传限制，不符合限制的文件需要修改后重新上传；以下为不同文件的限制

![](https://u5-creator.s3.game.163.com/manual/assets/filesystem3.DSNmpd9E.png)

| 类型 | 描述 |
| --- | --- |
| 图片 | 文件不大于3MB  尺寸不大于1920\*1080  仅支持png、jpg、jpeg格式 |
| 音频 | 文件不大于1MB  时长不超过60秒  仅支持mp3格式 |

![](https://u5-creator.s3.game.163.com/manual/assets/filesystem4.C86MXqvo.png)

4. 上传成功后可以界面浏览文件

![](https://u5-creator.s3.game.163.com/manual/assets/filesystem5.DEksY6Dj.png)

## 如何使用上传的文件

### 图片

在“编辑界面”功能中，通过【图片】-【自定义】分类可以选择自定义图片拖拽创建到界面画布中，进行使用

![](https://u5-creator.s3.game.163.com/manual/assets/filesystem6.C20YA3Vm.png)

在“预设编辑”功能中，将自定义图片作为技能、物品的图标使用

![](https://u5-creator.s3.game.163.com/manual/assets/filesystem7.BD80UYAf.png)

### 音频

在“剧情对话”中的“对话时播放声音”选择“音频”分类后选择自定义音频

![](https://u5-creator.s3.game.163.com/manual/assets/filesystem8.Czliyrhs.png)

通过“播放 2D 音效”蛋码选择自定义音频播放

![](https://u5-creator.s3.game.163.com/manual/assets/filesystem9.Do8YN4ar.png)
