# 表格编辑器

## 简介

表格编辑可以构造多个存储数据的表格，便于批量查阅修改大量数据

表格的数据可以通过蛋码直接修改和调用，方便游戏运行时的数据读写

## 入口

在【更多】【表格编辑器】中进入

![](https://u5-creator.s3.game.163.com/manual/assets/excel_1.C-oEQ37s.png)

刚进入时，没有文档，点击【新建文档】建立第一张表格

![](https://u5-creator.s3.game.163.com/manual/assets/excel_2.C99OWAhr.png)

## 如何编辑

在表格中，可以在左上侧修改该表格的名称，方便使用的时候查阅

![](https://u5-creator.s3.game.163.com/manual/assets/excel_3.C-9oVE9p.png)

表格的行和列都可以自由添加和修改

行名称只能使用整数来指代

列名称只能通过字符串来指代

为列选择一个类型，其下的格子才能填入对应的数据

![](https://u5-creator.s3.game.163.com/manual/assets/excel_4.CSMUPumn.png)

## 如何应用

构建好表格里的数据后，就可以在蛋码中对表格进行操作
