# 任务编辑器

任务可以给玩家提供更明确的目标，引导玩家获得游玩线索，是许多类型游戏中不可或缺的一环。

任务编辑器提供了快速配置任务的方法，你可以在这里编辑玩家可接取的任务列表、阶段目标、引导步骤以及任务奖励。

## 功能入口

1. 点击【更多】- 【任务】

![入口](https://u5-creator.s3.game.163.com/manual/assets/quest.YYeDWjeK.jpg)

2. 点击左侧“+”号创建一个任务

![新建任务](https://u5-creator.s3.game.163.com/manual/assets/newquest.DoBgGwLS.jpg)

3. 进入任务的编辑界面 ![任务编辑界面](https://u5-creator.s3.game.163.com/manual/assets/goal.D8uZzl9h.jpg)

## 任务编辑

### 任务状态

任务根据作者配置和玩家完成度分为多个状态。

| 任务状态 | 描述 |
| --- | --- |
| 待解锁 | 处于待解锁状态的任务无法被玩家所接取，需要先完成前置条件才能接取。 |
| 待接取 | 处于待接取状态的任务可以被玩家接取 |
| 进行中 | 处于进行中的任务可以被玩家跟踪并完成 |
| 待提交 | 处于待提交状态的任务可以被玩家提交任务而完成 |
| 已完成 | 成功或者失败都算作完成任务完成状态。  处于已完成状态的任务将会展示在任务看板完成栏中 |

蛋码也可以直接设置任务的状态。

* 任务描述

* 任务标签
  + 用于在任务看板中展示任务的任务类别，不同类别还会有不同的染色信息来区别。

![](https://u5-creator.s3.game.163.com/manual/assets/quest_11.kFr4fDAq.png)

* 管理标签
  + 以新建并管理任务标签，可以修改任务标签的展示排序，任务标签名称和任务标签颜色

![](https://u5-creator.s3.game.163.com/manual/assets/quest_12.CvA5OhAu.png)

* 支持从任务看板接取
  + 配置为开的任务会在任务处于待接取状态时在任务看板中展示。当有没有浏览过的新任务出现时，会在任务跟踪看板展示相关提示。

![](https://u5-creator.s3.game.163.com/manual/assets/quest_13.BSX1E_n4.png)

* 失败后可重复尝试任务

  + 当任务失败时会转回待接取状态
* 完成后自动提交任务

  + 当任务成功时不会进入待提交状态而会直接完成。否则在任务完成后需要玩家手动提交任务才能获得任务奖励
* 支持快速提交

  + 当任务打开支持快速提交时，点击任务跟踪面板中的待提交任务即可提交。
  + 当任务关闭支持快速提交时，需要到任务看板中的任务处进行提交。

![](https://u5-creator.s3.game.163.com/manual/assets/quest_14.CRWTZuOR.png)![](https://u5-creator.s3.game.163.com/manual/assets/quest_15.Dk-ipqcN.png)

* 接取任务事件

  + 接收该事件后玩家接取该任务，只有在待接取的任务在接受事件后才会被接取
* 接收事件后失败

  + 收该事件后玩家接取该任务，只有在待接取和进行中的任务在接受事件后才会变为失败
* 展示任务开始横幅

  + 展示任务开始的横幅效果，关闭则该任务开始时不展示

![](https://u5-creator.s3.game.163.com/manual/assets/quest_16.BnT7Eyz6.png)

* 展示任务结束横幅
  + 展示任务成功或失败时的横幅，关闭则该效果不展示

![](https://u5-creator.s3.game.163.com/manual/assets/quest_17.Dx-l9G7_.png)

* 前置条件

  + 如果任务配置了前置条件，那么在前置条件完成前都是待解锁状态。当任务存在多个前置条件时，需要所有的前置条件全部完成才会解锁任务。
* 条件类型: 可以配置不同的类型的前置条件

  + 完成任务：指定任务成功后解锁
  + 接收事件：接收事件后解锁
  + 指定阵营：角色处于指定阵营解锁

![](https://u5-creator.s3.game.163.com/manual/assets/quest_18.B5R0x6Mi.png)

* 奖励
  + 当完成任务后，可以获得对应的奖励，当角色当前无法拾取对应奖励时（如奖励为物品而角色的背包已满），奖励会创建在角色位置

## 步骤编辑

### 任务结构解释

一个任务由一个到多个步骤构成，每个步骤由一个到多个判定构成。

当任务进入进行中状态时，会从步骤0开始，当玩家完成步骤的任意一个判定后，会跳转到指定步骤/完成当前任务。

一个任务可以重复到达同一个步骤（如配置了一个判定：十秒内获取十个箱子，如果失败则重新开始当前步骤）。

### 步骤属性编辑

* 顺序

  + 决定了步骤在编辑时的排序，也支持蛋码获取玩家当前任务步骤数
* 到达步骤发送事件

  + 当玩家到达步骤时发送全局事件
* 指引点

  + 当玩家跟踪任务时，屏幕上会标记当前步骤的指引点

![](https://u5-creator.s3.game.163.com/manual/assets/quest_19.Bg9f7Rc-.png)

* 指引点类型

  + 坐标类指引点为固定坐标
  + 组件类指引点会实时显示在指定组件实体处
  + 预设类指引点会显示在所有预设处。如果预设组件被创建/销毁，指引点会随之创建和销毁。
* 指引点关闭事件

  + 当收到关闭事件时，该指引点会取消显示。注意该关闭事件仅对当前指引点次有效，如果后续任务重新开始当前步骤，则该指引点会被重置为显示。
* 判定列表

  + 该步骤所有的可达成判定，任意判定完成时，该步骤完成
* 展示目标进度

  + 当配置了展示判定进度时，会在任务跟踪面板处展示当前判定的实时进度。如果展示判定为复合条件，则可以分开设置每一个条件的是否展示实时进度

![](https://u5-creator.s3.game.163.com/manual/assets/quest_20.UpOzORkt.png)![](https://u5-creator.s3.game.163.com/manual/assets/quest_21.BFZ-ZkOq.png)

* 步骤名
  + 展示在任务跟踪面板的当前步骤名，如果当前展示进度为复合条件的判定，则可以给每一个子条件配置条件名

![](https://u5-creator.s3.game.163.com/manual/assets/quest_22.CRA8W4Qn.png)

## 判定编辑

### 判定结构解释

一个步骤可以有多个判定，当一个步骤的任意判定完成时，该步骤完成。

### 判定属性编辑

* 判定类型
  + 达成判定的条件，当选择复合条件时，玩家可以配置多个条件，只有多个条件同时达成时才会完成判定

![](https://u5-creator.s3.game.163.com/manual/assets/quest_23.CGIcZzhM.png)

* 判定完成进度

  + 当判定实时进度达到完成进度时，判定完成。
* 判定达成效果

  + 当前判定达成时对任务的状态修改，可以切换到任务下其他步骤，或者将当前任务设置为完成或失败。
* 目标完成描述

  + 当跳转到其他步骤时，任务跟踪面板会展示目标完成描述。在任务看板中的任务记录中也会展示完成描述。

![](https://u5-creator.s3.game.163.com/manual/assets/quest_24.cbBFkfn9.png)![](https://u5-creator.s3.game.163.com/manual/assets/quest_25.CNpVmh0U.png)

* 结局描述
  + 当任务完成时，任务横幅会展示结局描述。在任务看板中的历史记录中也会展示完成描述

![](https://u5-creator.s3.game.163.com/manual/assets/quest_26.4vnAk7FU.png)![](https://u5-creator.s3.game.163.com/manual/assets/quest_27.DfnjfW4K.png)

* 完成发送时间

  + 完成当前判定时会发送的全局事件
* 开启其他任务

  + 完成当前判定时会开启的其他任务

剧情对话支持通过对话选项来接取任务和完成任务判定。

只有任务处于待接取状态时，接取任务的选项才会显示，否则会隐藏。

只有任务处于正确的步骤时，完成该步骤判定的选项才会显示，否则会隐藏。

![](https://u5-creator.s3.game.163.com/manual/assets/quest_28.D66QMIke.png)
