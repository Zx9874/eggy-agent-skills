# 剧情对话编辑

剧情对话功能可以配置游戏中与生物/组件互动、或由事件触发的对话文本内容

## 入口及创建方式

1. 点击【更多】-【剧情对话】打开剧情对话编辑界面；

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation1.BDmFizBi.png)

2. 点击左侧"+"号创建剧情对话；

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation2.CeIr85L_.png)

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation3.0Sy2ICa1.png)

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation4.k7DonzzS.png)

## 编辑剧情对话

### 剧情对话属性的编辑

1. 点击左下角齿轮按钮打开剧情对话属性设置；

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation5.DyAKLD_V.png)

界面右侧可修改剧情对话以下属性：

| 属性 | 描述 |
| --- | --- |
| 剧情名称 | 剧情对话的名称 |
| 可由事件触发 | 此处配置的事件名对应事件触发时，将触发弹出该对话框 |
| 可结束时触发事件 | 剧情对话结束时，将触发该事件 |

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation6.Dxtk1I02.png)

### 单条对话属性的编辑

选中单条对话时，可以在右侧界面对单条对话的属性进行编辑；

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation7.BS58aTJj.png)

以下为单条对话可修改的属性：

| 属性 | 描述 |  |
| --- | --- | --- |
| 顺序 | 影响本条对话在整段剧情对话中的顺序 |  |
| 说话者类型 | 配置这条对话的说话者，可选择[生物，玩家，自定义]； | 剧情对话 |
|  | "生物"：当选择说话者为生物时，这条对话将由场景中的一个生物说出，可从场景中选择任意生物作为说话者；选择"触发生物"时，对话由哪个生物触发就由谁说出 | 剧情对话 |
|  | "玩家"：当选择说话者为玩家时，这条对话将由游玩的玩家说出； | 剧情对话 |
|  | "自定义"：当选择说话者为自定义时，将可以自由配置说话者的头像和名称 |  |
| 说话内容 | 对话的具体文本，最多可配置50个字符 |  |
| 对话样式 | 可用于配置该条对话的样式 | 剧情对话 |
| 蒙版透明度 | 影响对话期间，背景的不透明程度；当配置为0时，背景将完全可见 |  |
| 对话一次性显示 | 影响这条对话的文本是一次性显示还是逐个文字显示 |  |
| 对话时播放声音 | 影响对话时播放的音频，可从[无，音频，AI配音]中选择 *当历史最高工匠点达到10000时方可使用AI配音* | 剧情对话 |
|  | "无"：不播放任何音频 | 剧情对话 |
|  | "音频"：从官方提供的音频库中选择并播放2D音频 |  |
|  | "AI配音"：从官方提供的AI音色中，根据对话文本生成配音后播放2D音频 |  |
| 播放音量 | 若对话时播放音频，此处可配置其音量 |  |
| 对话期间可退出 | 可用于配置本条对话期间，是否可以点击右上角"退出"按钮直接退出对话 |  |

### 对话选项的编辑

在单条对话的编辑界面点击【增加选项】按钮可增加对话选项并对其进行编辑

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation14.BRNGwRE9.png)

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation15.BA54Rq3X.png)

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation16.uOQxItHk.png)

以下为对话选项可修改的属性：

| 顺序 | 影响选项的显示顺序 |
| --- | --- |
| 选项内容文本 | 选项的具体文本，最多可配置15个字符 |
| 触发事件 | 用于配置点击选项后触发的事件 |
| 跳转至 | 可用于配置点击该选项后的跳转方式，可选项[终止对话，其它剧情，其它对话] |
|  | "终止对话"：点击该选项后关闭剧情对话 |
|  | "其它剧情"：点击该选项后跳转至其它剧情对话 |
|  | "其它对话"：点击该选项后可跳转至本段剧情对话的指定序号的对话 |
| 默认显示 | 配置该选项是否默认显示 |
| 使选项显示的事件 | 配置使本选项可以显示的事件 |
| 使选项隐藏的事件 | 配置使本选项隐藏的事件 |

## 如何使用剧情对话

### 组件互动触发

1. 打开一个组件的设置界面并勾选"开启互动"

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation17.Xulb9-Ac.png)

2. 点击"添加互动"以增加一个互动

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation18.Cuo6eh3c.png)

3. 进入互动编辑界面，点击【编辑互动内容】按钮

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation19.vWaWEnCf.png)

4. 从剧情对话选择界面中选择编好的对话并点击【确认】

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation20.CJefYNDB.png)

### 事件触发

1. 在【剧情对话】界面中剧情对话的属性编辑界面设置"可由事件触发"属性为期望触发的事件名

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation21.CLc5dlwD.png)

2. 通过"事件触发区域"组件或其它方式触发该事件

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation6.Dxtk1I02.png)

### 通过蛋码触发

1. 在蛋码功能中搜索"开启对话"积木

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation23.CG6VMUgP.png)

2. 通过某个事件来触发此积木以触发对话

![剧情对话](https://u5-creator.s3.game.163.com/manual/assets/conversation24.iJq_mvu2.png)
