# 认识技能编辑器

在《蛋仔派对》游戏中，大部分决战技和道具技能都是使用技能编辑器制作的。技能可以赋予角色特殊能力，存在多种表现形式，如主动技能、被动技能、道具技能等。

技能编辑器位于【更多-预设编辑】功能左下角的【技能库】中。

技能以预设作为单位，一个预设就是一个技能模版，制作好技能后可以给角色装配它，玩家通过技能格控件触发技能使用。

## 技能预设

技能编辑器中提供了许多现成的技能预设，你可以直接使用它们，也可以作为模版进行改编。

### 模版技能

模版技能包含了各种简单的技能机制。如范围爆炸；直线攻击；闪现位移；索敌等。

在【基础】页查看技能描述，可以了解技能的使用效果，模版技能基本改编自官方玩法（如超燃竞技场）中使用过的技能。

![](https://u5-creator.s3.game.163.com/manual/assets/skill_temp1.BO9XkCyA.png)

你可以将技能模版存为自定义预设，在【施法】页修改其冷却时间、施法范围、施法特效等参数，改编成自己想要的效果。

![](https://u5-creator.s3.game.163.com/manual/assets/skill_temp2.DMOxyszR.png)

### 官方技能

技能预设中开放了一部分官方玩法技能，包括蛋仔决战技和道具技能。但是这里提供的技能预设是使用技能编辑器制作出来的版本，和决战技版本的原理、效果并不完全一致。

### 枪械技能

枪械技能通常用于物品装配，物品上的【选中物品时角色表现】可以辅助控制射击镜头。单独使用该技能时会朝着角色面对方向进行射击。

### 塔防技能

塔防玩法《艾比保卫战》中使用的塔防技能。

以塔防艾比为前缀的技能，基本是作为普攻技能使用的，即只能作为【攻击技能】使用，需要攻击范围里有敌人才能正常发动。

另一部分是配备给玩家使用的塔防全局技能，内置了部分未开放的技能逻辑，难以兼容其他玩法的地图。

### 自定义技能

在自定义分类下点击+号可以获得一个空白技能模版，方便进行自由创作。

## 技能的获取与使用

以下提供几种常用的技能获取方式。

### 角色预设添加技能

如果想让玩家在初始时就装配自制技能，可以在【预设编辑】里的【角色】分类中，给玩家蛋仔预设配备技能。

点击【新增技能】可以跳转到添加技能的界面，我们可以在这里选择使用技能编辑器制作的技能。

> * 决战技相关在蛋码和规则设置-玩法规则-附加规则中设置。
> * 第一个技能格为攻击技能，攻击技能与普通技能不同，攻击技能是一种普攻机制，需要敌人在施法范围圈内才能发动，普通技能主动性更强。

![](https://u5-creator.s3.game.163.com/manual/assets/skill_add_eggy.Bo6xWJfH.jpg)

配备技能后，还需要去界面编辑添加对应的技能格控件。

![](https://u5-creator.s3.game.163.com/manual/assets/skill_add_ui.CCwAgIdv.png)

一个技能格只能显示一个编号的技能，可以在技能格的高级设置中进行设置，技能编号通常从0开始计数（动态添加时，第一个技能往往是0）。添加技能的时候。可以设定技能在几号技能格里。

如果需要添加多个技能，就需要多设置几个技能格并赋予他们不同的编号。

### 生物添加技能

给生物添加技能与角色添加技能流程基本一致，但因为生物不依赖使用ui触发技能，所以不填写技能格编号也没问题。

![](https://u5-creator.s3.game.163.com/manual/assets/skill_creature.BJZLfBro.png) 在生物的AI编辑里可以编辑其搜敌行为，让生物主动使用技能，但搜敌行为里的技能必须要在生物技能列表中才能正常发动。

### 蛋码动态添加技能

使用蛋码可以给角色动态添加和移除技能。

以下是常用的给角色添加和移除技能的动作积木：

![](https://u5-creator.s3.game.163.com/manual/assets/skill_add_api.B4bWFXvy.png)

使用蛋码添加技能，同样需要提前在界面编辑中设置对应技能格。（默认情况下，添加的技能会从0号开始）指定槽位添加的技能会覆盖该编号技能格上原有的技能。

### 物品主动技能

通过给物品配置主动技能，可以实现角色拾取\穿戴装备后获得技能的效果。

![](https://u5-creator.s3.game.163.com/manual/assets/skill_add_item.COg-l6Jg.png)

首先在物品预设中给物品配置主动技能，并给它配置对应的技能格。

![](https://u5-creator.s3.game.163.com/manual/assets/skill_add_itemui.CvxHskAT.png)

物品和选中物品的技能格是独立的。物品技能是玩家获得物品后获得的常驻技能，可以选择对应到装配区或储物区中具体到编号的物品。

而选中物品技能代表的是玩家当前选中的物品的技能，同一时间只会有一个。
