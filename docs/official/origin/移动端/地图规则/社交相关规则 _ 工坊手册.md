# 社交相关规则

本节介绍规则设置中的附加规则、聊天规则和匹配规则，这部分规则通常关系到地图中多个玩家的互动体验。

## 附加规则

### 礼包码

开启后地图商城界面会增加礼包码兑换入口。

### 决战技

启用决战技后，玩家进入游戏将会弹出决战技选择界面，类似巅峰派对决战时的表现。

使用蛋码可以动态调起决战技界面。

### 整场拥有道具

设置角色整场拥有道具后可以让玩家从进入游戏开始就获得该道具，类似疯狂乱斗里默认所有玩家持有咸鱼道具。

持有道具会在拾取道具箱后被道具箱内的道具替代，但是消耗掉该道具后会再次获得拥有道具。

### 艾比

关闭允许召唤艾比后，玩家不能在地图里召唤艾比，也不能使用艾比球等道具。

### 社交载具

关闭允许使用社交载具后，玩家不能在地图里使用载具。

大部分社交载具具有飞行功能，关闭许可能够避免玩家使用载具进行作弊。

### 科技道具

科技道具指的是乐园商城中售卖的科技背包等能够帮助玩家过关的小道具。

使用科技道具会默认该玩家通关记录不能进入排行榜，关闭允许科技道具后玩家将没有使用途径。

### 魔法笔

玩家在游玩时可以使用魔法笔在地图中留言，其他玩家进入地图时会随机显示部分魔法笔痕迹。

魔法笔会显示留下记录的蛋仔的虚影及使用的动作，并且留言中可能包含地图的剧透和线索提示，作者可以视情况决定是否保留该功能。

### 特殊动作&玩具

关闭允许使用特殊动作&玩具后，玩家不能在地图中使用以下内容：

* 乐器玩具
* 载具玩具
* 烟花玩具
* 座椅玩具
* 互动玩具
* 多人互动动作

由于部分特殊动作和玩具的功能可能会给玩家添加诸如无敌状态之类的效果，影响游戏公平性，在重视竞技的地图里可以关掉这条。

### 显示终点

开启后玩家可以在左上角列表看到终点显示按钮，玩家点击该按钮后游玩时会出现终点指引点，辅助玩家找到胜利区域。

![观战](https://u5-creator.s3.game.163.com/manual/assets/rule_endui.B10neF1m.png)

为了保证基本的游玩体验，该按钮需要再游戏开始30秒后才能生效。

### 召唤功能

开启召唤功能后，玩家游玩地图时可以在左上角列表看到召唤按钮，点击后会向房间内其他玩家发起召唤，接受召唤的玩家将降临在该玩家角色旁边。

### 沉浸模式

允许开启沉浸模式后，玩家游玩地图时可以在左下角切换到沉浸模式。

沉浸模式下会减少界面的ui显示，增加画面的沉浸感。

![观战](https://u5-creator.s3.game.163.com/manual/assets/rule_flow.B_ARw5EI.png)

### 游戏内相机移动

关闭后，玩家在地图内使用相机拍照只能改变角度，无法移动相机位置。

关闭此条可以避免玩家通过移动相机看到作者不希望被看到的地图内容。

### 局内观战

打开后，局内玩家可以通过左上角的观战按钮随时观战其他玩家。

![观战](https://u5-creator.s3.game.163.com/manual/assets/rule_spectator1.D2KZNpLd.png)

实际游玩中，局内观战会受乐园房间设置影响。

![观战](https://u5-creator.s3.game.163.com/manual/assets/rule_spectator2.DDRwB3_p.png)

### 配音相关

关闭`角色语音开关`后,地图内将屏蔽角色配音，避免角色配音影响游玩沉浸感。

调节`角色语音音量系数`，能够在本地图内降低配音音频的相对音量。

### 语音相关

打开`阵营语音`开关后，地图语音频道将增加阵营频道。

## 聊天规则

关闭聊天规则后，地图局内聊天功能入口将被关闭。

| 功能 | 说明 |
| --- | --- |
| 允许所有人聊天 | 关闭后地图内聊天不会有`全部`频道。例如非对称玩法中关闭公屏聊天能避免不同阵营玩家交换情报。 |
| 显示对话气泡 | 开启后地图内玩家在所有人频道发言会和在蛋仔岛上一样出现对话气泡。 |
| 允许阵营单独聊天 | 打开后，地图内聊天可以切换到阵营频道，便于玩家跟同阵营玩家交流。 |
| 允许私聊 | 打开后，玩家可以在本地图中通过点击或抓举其他蛋仔来加好友或者私聊。 |

## 匹配及匹配参数

开启该规则可在地图详情界面添加匹配按钮，用于聚集玩家同时游戏。

启用精确匹配需使用一个整数类型的自定义进度参数，系统会优先匹配参数差值最小的玩家组队，并随时间逐步放宽至最大允许差值。参数上下限为0-3000。
