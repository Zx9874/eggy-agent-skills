# 规则设置

规则设置能够设定地图的游戏规则，包括胜利判定方式、计时方式、玩家及角色属性等。

此外，在规则设置中，还能够配置社交聊天、匹配等地图周边规则。

地图规则有两个入口：

1. 点击更多 - 高级功能 - 规则设置 也可以跳转到规则设置界面

![规则设置入口](https://u5-creator.s3.game.163.com/manual/assets/rules_entry1.DCCS5VRf.png)

2. 点击设置 - 地图设置 - 规则设置 - 编辑 即可跳转到规则设置界面

![规则设置入口](https://u5-creator.s3.game.163.com/manual/assets/rules_entry2.CRYOR2-e.png)

## 规则模版

规则模版决定了地图的胜利方式，不同模版下会显示的参数也不一样，并且规则模版会影响地图的存档和排行榜生效情况。

当地图中没有胜利区域、或关闭计时规则时，地图将切换为无规则地图，发布流程无需通关。

地图里存在胜利区域时只能设置为竞速模版，删除即可切换为其他模版，。

| 规则模版 | 说明 |
| --- | --- |
| 竞速 | 玩家到达胜利区域后会被判断为游戏胜利 自动配置计时180秒，显示通关人数ui，角色掉落后自动重生。 适合跑酷或者任意比较通关速度的玩法地图。 |
| 生存 | 玩家生存到游戏计时结束会被判断为游戏胜利  自动配置计时180秒，显示剩余人数ui，角色掉落后不会重生。 适合生存、擂台等玩法。 |
| 个人积分 | 每个玩家各自计分，有限时间内获得最多积分的玩家胜利。  自动配置计时300秒，显示个人积分ui，默认目标50分，角色掉落后自动重生。 |
| 团队积分 | 玩家按照阵营累计积分，有限时间内获得最多积分的阵营内玩家胜利。  自动配置计时180秒，显示团队积分ui，默认目标9999分，角色掉落后自动重生。 |
| 塔防 | 详见 [塔防编辑器](https://u5-creator.s3.game.163.com/manual/mobile/module/towerdefense.html) |
