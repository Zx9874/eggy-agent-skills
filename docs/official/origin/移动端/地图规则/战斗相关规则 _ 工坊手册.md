# 战斗相关规则

本页面介绍规则设置中的击败规则和伤害规则，这些规则会深度参与到游戏的胜负规则和战斗体验构建中。

## 击败规则

关闭击败规则后，玩家被击败后不再重生，直接出局，即所谓的"一命玩法"。

### 生命属性

属性相关中可以选择开启与战斗直接关联的几项生命属性。

| 属性 | 说明 |
| --- | --- |
| 最大命数 | 每个蛋仔可以重生的最大次数，小于等于0时为无限重生 命数可以通过击败（掉落或进入销毁区域）和蛋码直接扣除。 |
| 健康值 | 开启后蛋仔会有生命值计算，玩家界面底部会出现血条ui（如果想要角色头顶的3D血条ui，可以去角色预设里开启），生命值小于等于0时蛋仔进入被击败状态。 |
| 质量 | 开启后蛋仔会开启质量相关功能，受到伤害或碰撞时质量会下降，蛋仔体重变轻，更容易被击飞。 |
| 角色健康值 | 此处可以设置角色的最大健康值，需要注意这里的设定优先级高于在游戏初始化时使用蛋码设置角色最大健康值。 |

### 复活规则

| 属性 | 说明 |
| --- | --- |
| 复活时间 | 玩家被击败到复活的间隔时间，单位为秒；时间为0时会立刻复活；等待期间角色将被隐藏。 |
| 自动复活 | 开启时蛋仔被击败后会自动复活，否则需要作者使用相关蛋码触发角色复活。 |
| 复位 | 该地图是否支持使用复位功能。 |
| 倒计时 | 是否开启复活倒计时。 |
| 击败播报 | 蛋仔击败对方或者被击败时右上角会出现播报，和派对模式一致。 |

### 生存规则

开启最后存活获胜后，游戏结算将判定最后一名存活玩家胜利。

### 碰撞击败

开启碰撞行为导致击败开关后，角色或生物因为碰撞导致掉落或者进入销毁区域而被击败时，来源将视为碰撞来源，如果碰撞来源是组件会根据组件的所属玩家来决定。

## 伤害规则

伤害规则支持配置全局的伤害方案，只有使用蛋码<造成伤害(伤害规则)>才会使用伤害规则里配置的公式结算。

### 伤害公式

使用伤害公式可以配置自定义伤害计算表达式，用于结算一次攻击最终造成多少伤害。

![伤害公式](https://u5-creator.s3.game.163.com/manual/assets/rule_damage_edit.BIs8VPHs.png)

### 伤害方案

一局游戏里能够存在多套伤害方案，每个方案对应不同的伤害公式和护盾属性，在蛋码<造成伤害(伤害规则)>里，作者可以选择不同的模式来让不同的伤害方案生效。

每套伤害方案可以设置单独的伤害飘字颜色，方便玩家识别。

### 吸收伤害属性

吸收伤害属性能够实现护盾/减伤效果，此属性只能在伤害规则造成的伤害中生效。

例如：在伤害规则1中,配置吸收伤害属性A，再通过蛋码或者效果添加对应A的属性到角色或生物，若造成伤害时使用伤害规则1,那么会优先扣除它的吸收伤害值而非健康值。

| 参数 | 说明 |
| --- | --- |
| 吸收计算时机 | 伤害结算前：在伤害公式计算之前抵扣原始伤害，会影响伤害飘字； 伤害结算后：在扣血前结算实际伤害，不影响伤害飘字。 |
| 吸收比例 | 当受到伤害时，伤害中多少比例将用来和吸收伤害相扣除，范围为0~1。 例如伤害为100，吸收比例为0.3，那么有30点伤害会先考虑扣除吸收伤害而不是健康值，如果当前吸收伤害不足30，那么多余的部分会扣除健康值。 |
| 优先级 | 当角色或生物拥有多种吸收伤害属性时，优先级越大的关联属性将被优先消耗，如果优先级相同，排序靠前的优先消耗。 比如填了A和B两种属性作为吸收且吸收规则相同，A优先级5，B优先级10，那么B消耗完之前不会消耗A。 |

**关联属性**

作为这个吸收伤害属性的字符串标记，在效果属性中使用，无实际意义。

![步骤](https://u5-creator.s3.game.163.com/manual/assets/shield_steps.Cs_EqltG.png)

**护盾血条**

吸收伤害属性能够在富表现血条上显示（其他类型血条暂时不支持），可以给吸收伤害部分的血条设置显示颜色。

![预览](https://u5-creator.s3.game.163.com/manual/assets/shield_pic.CBE8oiVz.png)

富表现血条需要在预设编辑-角色预设-表现-健康属性中配置。

![血条](https://u5-creator.s3.game.163.com/manual/assets/rule_richhpui.D2nlJoF-.png)

### 伤害跳字

打开伤害跳字全局开关后，使用伤害规则造成的伤害都会出现飘字。

关闭情况下，可以在<造成伤害（伤害规则）>的蛋码里点击小齿轮打开飘字参数，使指定的伤害才显示飘字。
