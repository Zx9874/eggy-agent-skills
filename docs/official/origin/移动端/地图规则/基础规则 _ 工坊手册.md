# 基础规则

本节主要介绍规则设置中较为基础的一些规则，包括能决定游戏时长的计时规则，以及积分玩法会用到的积分规则，还有控制玩家视野的迷雾规则。

## 基础规则

关闭基础规则以下设置都会失效并被重置为默认状态，撤销可以回到之前的设置。

### 界面风格

提供定制的风格化ui，适配任务、成就、商城、物品商店、剧情对话、每日签到、背包界面。

界面风格预览（任务界面）

![预览](https://u5-creator.s3.game.163.com/manual/assets/ui_style1.Co4TMGp9.png)

### 显示模式

此处设置为竖屏可以将地图转为竖屏模式，详见[竖屏模式](https://u5-creator.s3.game.163.com/manual/mobile/UIeditor/uieditor.html#竖屏模式)

### 界面遮挡界面交互

开启后，界面ui将会遮蔽场景组件的屏幕互动响应，关闭则点击拖动组件的交互不会受到ui遮挡影响。

### 高性能物理

高性能模式下，高速运动的物理组件不会穿透其他组件。

### 角色提示标常态显示

关闭后，玩家角色头上的黄色三角标记将不会显示。

### 进/退场形式

| 参数 | 说明 |
| --- | --- |
| 胜利退场 | 选择无：达成胜利条件后，停留在原地； 选择呦呦退场：达成胜利条件后，蛋仔搭载yoyo飞走，类似派对积分图胜利。 |
| 掉落场地 | 选择复位：当蛋仔掉落至场景外时，恢复到出生点、存档点位置。 选择击败：当蛋仔掉落至场景外时，蛋仔进入击败状态，会扣除相应命数。 |
| 入场形式 | 选择无：角色将直接出生在出生点； 选择YOYO入场：蛋仔搭载yoyo从出生点降落，类似疯狂乱斗玩法。 |
| 复活形式 | 选择无：死亡后复活将在出生点、存档点复活； 选择YOYO：死亡后复活蛋仔搭载yoyo从出生点降落，类似疯狂乱斗玩法。 |

### 观战

观战不仅被地图规则控制，实际效果还会受到乐园房间设置影响。

| 参数 | 说明 |
| --- | --- |
| 胜利观战 | 玩家胜利后自动进入观战状态 |
| 淘汰观战 | 玩家淘汰后自动进入观战状态 |

## 计时规则

关闭计时规则后，地图会变成无规则地图，无需通关发布。

没有计时规则的地图理论上可以无限时间游玩，但是多人开房间游玩的情况下，由于房间会在开启游戏一小时后销毁，所以多人游戏的时间上限不能超过一小时，但单人可以无限时间游玩。

### 游玩时长

开启计时规则后，可以设定地图的游玩时长，单位为秒，上限为43200（12小时），但是多人游玩时长依然不能超过一小时。

### 游戏模式

计时规则还涉及到结算规则，有以下几种：

| 游戏模式 | 说明 |
| --- | --- |
| 时间结束胜利 | 达到最大游戏时长后，剩余存活玩家全部获得胜利 |
| 时间结束失败 | 达到最大游戏时长后，剩余存活玩家全部游戏失败 |
| 分数高的获胜 | 达到最大游戏时长后，剩余存活玩家阵营分数较高的一方获胜 |

## 积分规则

开启积分规则后，地图内的积分制玩法（进球积分\击杀积分）可以正常生效。

关闭不影响通过积分组件和蛋码获得积分。

| 参数 | 说明 |
| --- | --- |
| 目标积分 | 达到目标积分的玩家或阵营将会获胜 |
| 团队模式 | 开启后积分的获取和判断将以阵营为标准 |
| 击败积分 | 击败一个角色后，击败方玩家可以获得的积分 |
| 获胜后结束游戏 | 场上有玩家达到目标积分后游戏直接结算 |
| 积分界面显示 | 游玩界面会显示积分相关原生界面ui |

## 迷雾规则

迷雾规则可以影响玩家的视野，捣蛋鬼玩法中的关灯机制就使用了迷雾效果。

启用迷雾后，迷雾会在游玩时生效，开启预览为开的情况下，场景编辑界面也可以预览迷雾效果。

点击右下角开启场景预览，能够可视化调整迷雾规则的迷雾效果参数。

### 驱散范围亮度

驱散范围亮度越高，角色视野范围越亮，反之会接近黑色。

![预览](https://u5-creator.s3.game.163.com/manual/assets/battlefog1.DeQKUnDW.gif)

### 迷雾亮度

迷雾亮度越低，视野遮蔽效果越佳。

![预览](https://u5-creator.s3.game.163.com/manual/assets/battlefog2.CStCJxNA.gif)

### 驱散范围衰减最大值

驱散范围衰减最大值越大，驱散范围的边缘越模糊，反之则边缘变清晰。

![预览](https://u5-creator.s3.game.163.com/manual/assets/battlefog3.Bl2rECqY.gif)

### 驱散范围衰减最小值

驱散范围衰减最小值越大，驱散范围越小。最小值不能超过最大值。

![预览](https://u5-creator.s3.game.163.com/manual/assets/battlefog4.BgDzl0Zz.gif)

### 迷雾驱散光源

迷雾驱散点光源和迷雾驱散锥型光源组件也能起到驱散效果，参数等同于角色视野范围。

![预览](https://u5-creator.s3.game.163.com/manual/assets/rules_battlefog_light.DSyfY59d.png)
