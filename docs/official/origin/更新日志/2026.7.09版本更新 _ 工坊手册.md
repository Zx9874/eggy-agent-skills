# 2026.7.9 工坊/蛋仔编辑器更新公告

## 一、编辑器功能更新

### 现已支持对【环境光遮蔽】功能设置距离参数，开发者可以控制环境光遮蔽的具体生效范围

| 属性 | 详细说明 |
| --- | --- |
| 采样半径 | 产生阴影的范围大小，数值越大，阴影覆盖的区域越宽 |
| 深度偏移 | 减少阴影边缘噪点的程度，数值越大，边缘越干净平滑 |
| 遮蔽强度 | 控制阴影的深浅程度，数值越大，阴影颜色越深 |
| 淡出起点 | 环境光遮蔽开始淡出的位置 |
| 淡出终点 | 环境光遮蔽将在此距离完全失去效果 |
