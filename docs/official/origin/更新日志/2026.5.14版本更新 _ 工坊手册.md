# 2026.5.14 工坊/蛋仔编辑器更新公告

## 组件新增：“赛车”UGC载具组件

在本次更新中，右侧边栏【组件-组合-载具】新增【蛋仔飞车】玩法同款赛车载具

![](https://u5-creator.s3.game.163.com/manual/assets/1.DZ5GT1Yk.png)

【赛车载具】重构了原本的3C驾驶体验，预制了一套基于赛车游戏的驾驶逻辑，包括漂移、氮气加速等

![](https://u5-creator.s3.game.163.com/manual/assets/2.xApyZR86.png)

自定义载具 在右侧边栏的【组件-机关】下新增【载具】分类，支持将赛车核心组件和载具座椅组件组合可以生成自定义载具，结合其他组件可以自由创建不同外观造型的赛车。

![](https://u5-creator.s3.game.163.com/manual/assets/6.okgnUE1w.png)

自定义参数

| 属性 | 描述 |
| --- | --- |
| 最大线速度 | 赛车在平直路面上能够达到的最高前进速度 |
| 旋转角速度 | 赛车在正常行驶时转向的灵活程度，数值越高转弯越快 |
| 防滑加速度 | 当赛车出现打滑时用于恢复抓地力的反向加速度大小 |
| 防加速度 | 车辆在松油或制动时自然减速的阻力强度，数值越大减速越明显 |
| 加速度 | 赛车从静止或低速状态下提升速度的能力，决定起步和再加速表现 |
| 恢复旋转角加速度 | 漂移或失控结束后，车头回正到正常行驶方向时的旋转加速能力 |
| 旋转角加速度 | 赛车进入转向状态时的初始转向响应，影响转向的快慢节奏 |
| 加速额外速度 | 触发加速效果后获得的速度提升上限 |
| 加速额外加速度 | 触发加速效果期间的瞬时加速能力，影响爆发力 |
| 加速持续时间 | 一次加速效果所维持的总时长 |
| 加速冷却时间 | 两次加速效果之间需要等待的冷却间隔 |
| 地面距离状态 | 跳跃或飞坡落地后，赛车恢复正常操控所需的前进距离 |
| 加速减速系数 | 加速效果即将结束时速度衰减的缓急程度 |
| 漂移最大线速度 | 进入漂移状态后赛车能达到的最高速度，限制漂移中的速度上限 |
| 漂移旋转角速度 | 漂移过程中车身绕垂直轴的旋转速度，决定漂移的转向灵敏度 |
| 漂移旋转角加速度 | 漂移时改变旋转速度的快慢，影响漂移操控的敏捷性 |
| 扭转最大角度 | 赛车在转向时允许车头与行进方向的最大偏离角度 |
| 扭转旋转角速度 | 赛车进入扭转状态时的旋转速度，影响转向的激进程度 |
| 扭转恢复旋转角速度 | 扭转状态结束后车身回正到正常方向的旋转速度 |
| 扭转结束角度 | 判定扭转状态结束的车身角度阈值 |
| 漂移加速度 | 漂移过程中赛车持续提升速度的能力 |
| 漂移防加速度 | 漂移时松油或制动产生的自然减速强度 |
| 漂移防滑加速度 | 漂移中对抗打滑、恢复抓地力的反向加速度大小 |
