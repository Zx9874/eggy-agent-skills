# 2026.5.28 工坊/蛋仔编辑器更新公告

## 粉丝团新增:成员管理与主动退出功能

地图工匠可在【粉丝团-成员管理】功能中，搜索到对应成员进行成员管理。粉丝团成员现已支持主动退出已加入的粉丝团，退出后，该粉丝团喜爱度与勋章等级会被清空，再次加入该粉丝团需要等待24小时。对于粉丝团管理者，现已支持了主动踢除粉丝团成员的功能，方便粉丝团管理者做私域社群运营。

## PC端编辑器插件功能更新

插件窗口支持自定义名称：插件标题现在跟随 config.json 中的配置显示，方便创作者为不同插件设置清晰易分辨的窗口名称。本次更新增加两款官方插件示例【远端服务器通信】与【模型预览】。

【远端服务器通信】 插件支持与远端服务器进行 HTTP 通信，可发送 GET/POST 请求进行数据交互。方便开发者测试网络接口、实现动态数据拉取或上报等扩展功能。

【模型预览】 插件支持预览 Neox 引擎的模型（.gim）与特效（.sfx）文件。内置轨道相机控制，可从任意角度查看资源效果，便于美术资源的快速检视与调试。

## PC端编辑器天空背景功能优化

PC编辑器新增自定义天空背景预览功能，点击【天空背景】与【反射天空图】功能，会打开独立的窗口，方便开发者进行筛选预览。PC编辑器现已支持开发者上传更大的全景图文件作为【天空背景】。
