# 2026.8.06 蛋仔原点编辑器更新公告

## 一、编辑器功能更新

### 1.【界面编辑】功能更新

新增“透明度”属性，现已支持调节原生控件的透明度。

![](https://u5-creator.s3.game.163.com/manual/assets/transparency.BeSeIv77.png)

### 2.【文件管理】功能更新

【文件管理】界面现已支持查看并使用各类官方资源文件。

### 3.其他功能更新

新增快捷键，支持一键切换PC编辑器全屏模式。Mac 系统快捷键为 Ctrl + Command + F，Windows 系统为 F11。
