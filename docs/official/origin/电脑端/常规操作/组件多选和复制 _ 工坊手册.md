# 组件多选和复制

## 组件的多选

方法一：点击多选图标，再选中多个组件。

![](https://u5-creator.s3.game.163.com/manual/assets/multiselectunits.B5raMRBp.png)

方法二：多选图标快捷键为Ctrl，长按Ctrl选中多个组件。

## 组件的复制

方法一：点击复制的图标，选中组件点击移动图标，将组件想任意方向移动完成复制。

![](https://u5-creator.s3.game.163.com/manual/assets/duplicate.t56sEjyx.png)

方法二：复制图标的快捷键为Alt，长按Alt选中组件点击移动图标，将组件向任意方向移动完成复制。
