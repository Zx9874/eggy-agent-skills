# 自定义模型上传

## 导入流程

假设已经登录pc编辑器，并且已经进入地图编辑展示

### 1、点击菜单栏自定义文件功能

![](https://u5-creator.s3.game.163.com/manual/assets/1.BdiAK8sF.png)

### 2、点开左侧第四个页签

![](https://u5-creator.s3.game.163.com/manual/assets/2.Dm6102_f.png)

### 3、点击选择模型，并选择需要自己需要导入的模型文件

![](https://u5-creator.s3.game.163.com/manual/assets/3.irWd-t3e.png)

![](https://u5-creator.s3.game.163.com/manual/assets/4.C85Rt4E9.png)

### 4、导入完成后，显示如下界面

![](https://u5-creator.s3.game.163.com/manual/assets/5.DyrQtU1p.png)

### 5、如有材质文件，可以点击添加材质

![](https://u5-creator.s3.game.163.com/manual/assets/6.VonMP_fY.png)

### 6、然后点击右下角的确认按钮就行模型导入

![](https://u5-creator.s3.game.163.com/manual/assets/7.8yHOCaJf.png)

### 7、导入后，会在文件管理/自定义模型/待分类下面看到导入的自定义模型

（如果模型审核中，请耐心等待）

![](https://u5-creator.s3.game.163.com/manual/assets/8.Qln2HPD2.png)

### 8、选中自定义模型，然后右键，转化为组件预设

![](https://u5-creator.s3.game.163.com/manual/assets/9.CH3wvVhA.png)

### 9、然后就能在组件/用户自定义文件夹下看到对应的导入模型

![](https://u5-creator.s3.game.163.com/manual/assets/10.D7vkoF_L.png)

### 10、拖动组件到场景内，就可以创建对应组件

![](https://u5-creator.s3.game.163.com/manual/assets/11.D4TUGw4Y.png)

## 基础材质说明

### 通用材质说明

| 参数名 | 说明 |
| --- | --- |
| Tex0 | 颜色贴图：RGB通道为贴图颜色，A通道为半透明遮罩 |
| Tex1 | 法线贴图：RGB通道为法线颜色 |
| Tex2 | 混合贴图：R通道为AO，G通道为粗糙度，B通道为金属度，A通道为自发光遮罩 |

### 换色材质说明

| 参数名 | 说明 |
| --- | --- |
| Tex0 | 换色贴图：R通道为MaskColor1换色遮罩，G通道为MaskColor2换色遮罩，B通道为MaskColor3换色遮罩（MaskColor0为底色）；A通道为细节法线遮罩 |
| Tex1 | 法线贴图：RGB通道为法线，A通道为半透明遮罩 |
| Tex2 | 混合贴图：R通道为AO，G通道为粗糙度，B通道为金属度，A通道为自发光遮罩 |
| Tex4 | 细节法线贴图：RGB通道为法线，A通道为细节法线AO |

### 透明贴图

如果想要有镂空贴图，则需要再对应贴图的通道进行对应遮罩的绘制，并且将贴图模式修改为透明模式。

![](https://u5-creator.s3.game.163.com/manual/assets/12.Dy8TvZWk.png)

## 角色导入限制

导入角色模型时，资产必须带有骨骼和蒙皮信息。

导入的骨骼有一定的限制：

1.可以根据蛋仔类基础骨骼进行模型的绑定&蒙皮

## 可能遇到的问题

### Q1：导入后提示导入失败，如下图？

![](https://u5-creator.s3.game.163.com/manual/assets/13.58fNS6tq.png)

A1：导入的模型顶点数过多，建议作者缩减顶点数

A2: 可参考如下流程使用Blender进行减面(Blender3.4以上版本)：

1. 导入模型（示例模型有199564顶点与399426三角面）

![](https://u5-creator.s3.game.163.com/manual/assets/14.BbRFl8ae.png)

![](https://u5-creator.s3.game.163.com/manual/assets/15.sJvwQfeV.png)

2. 左键或者outliner选择模型

![](https://u5-creator.s3.game.163.com/manual/assets/16.DcoPThR_.png)

3. 按如下流程添加decimate modifier

![](https://u5-creator.s3.game.163.com/manual/assets/17.DFlRw9sJ.png)

![](https://u5-creator.s3.game.163.com/manual/assets/18.BbQC5mtQ.png)

4. 选择collapse模式，按照总面数和顶点数直接写入需要减到的百分比（0.0~1.0）

![](https://u5-creator.s3.game.163.com/manual/assets/19.3oCDaUlw.png)

5. 确保总面数和总顶点数合规即可导入后导入PC蛋编

![](https://u5-creator.s3.game.163.com/manual/assets/20.B584xbci.png)

![](https://u5-creator.s3.game.163.com/manual/assets/21.Dtky3-tS.png)

### Q2：导入后提示组件模型三角面数检查不通过？

![](https://u5-creator.s3.game.163.com/manual/assets/22.BgAeaB4x.png)

A2：导入的模型面数过多，建议作者缩减面数（参考Q1-A2）

### Q3：导入失败，弹到场景编辑界面

A3：排查解决

1、检查Documents/res/Neox目录下是否有tool文件

![](https://u5-creator.s3.game.163.com/manual/assets/23.B1BPpP6t.png)

2、如果没有，检查windows安全中心，关闭病毒与防护设置，关闭教程如下:

![](https://u5-creator.s3.game.163.com/manual/assets/24.Cb6mAzUp.png)

![](https://u5-creator.s3.game.163.com/manual/assets/25.CzS85r0D.png)

![](https://u5-creator.s3.game.163.com/manual/assets/27.D8d3vTqa.png)

![](https://u5-creator.s3.game.163.com/manual/assets/28.CziKWbzT.png)

![](https://u5-creator.s3.game.163.com/manual/assets/29.BCJBAULJ.png)

![](https://u5-creator.s3.game.163.com/manual/assets/30.BXjhKS2l.png)

![](https://u5-creator.s3.game.163.com/manual/assets/31.CLpVVF97.png)

3. 确保以下位置出现如下按钮：

![](https://u5-creator.s3.game.163.com/manual/assets/32.oDt5vW-K.png)

4. 右键删除空场景中的Cube模型

![](https://u5-creator.s3.game.163.com/manual/assets/33.Ckp8UU_u.png)

5. 导入出现问题的fbx文件

![](https://u5-creator.s3.game.163.com/manual/assets/34.8A02vmn1.png)

6. 左键选择需要修复的模型，并点击Reverse Face Vertices按钮 （如果完成，Blender会在视口最下方提示执行完成）

![](https://u5-creator.s3.game.163.com/manual/assets/36.BtUsXvE2.png)

![](https://u5-creator.s3.game.163.com/manual/assets/37.C-WMpOGZ.png)

7. 选择模型并原路径导出fbx

![](https://u5-creator.s3.game.163.com/manual/assets/38.B4EG10B4.png)

![](https://u5-creator.s3.game.163.com/manual/assets/39.Cec_lZmY.png)
