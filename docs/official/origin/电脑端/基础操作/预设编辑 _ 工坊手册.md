# 预设编辑

预设编辑可以修改组件预设的各项功能包括组件的基础外观，物理运动器和表现器等属性，在组件被创建之前，所有的相关数据都以预设的形式保存。修改组件预设属性等于修改未来创建组件的时候的默认属性。

![](https://u5-creator.s3.game.163.com/manual/assets/prefabentry.CNn-Yk08.png)

## 界面介绍

### 管理窗口

预设编辑中可编辑组件和创建面板组件类型一致，点击界面最左侧分类列表，在视窗处可以展示出相对应的组件。

![](https://u5-creator.s3.game.163.com/manual/assets/prefabwin.DGAm-wlS.png)

### 属性窗口

在最右侧的属性窗口中可以对组件进行预设编辑，包括组件的基础设置，物理属性，表现器功能，特殊功能，互动属性以及自定义属性等等。另外修改组件预设会被改为官方组件，建议先存为自定义再进行编辑。

![](https://u5-creator.s3.game.163.com/manual/assets/prefabsetting.CjohAhCB.png)

### 触发器

物体预设编辑中触发器又被称为对象触发器，是为当前组件赋予逻辑的地方。

![](https://u5-creator.s3.game.163.com/manual/assets/prefabtrigger.BhfGrGQ-.png)

## 功能介绍

【基础】组件的位置整体大小，遮挡玩家规则进行设置。

【物理】设置组件的物理碰撞，添加运动器，受外力作用等。

【表现】设置组件的皮肤颜色以及材质参数的调整，设置投影状态，添加组件表现器等。

【特殊功能】可以将组件设置为积分组件，触碰角色扣除生命值，技能冷却组件，触碰角色添加命数，组件添加释放技能等属性。

【互动】开启互动按钮给组件添加剧情对话。

【蛋码编辑】对所预设的组件赋予逻辑。
