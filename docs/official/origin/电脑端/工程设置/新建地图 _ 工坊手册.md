# 新建地图

## 如何新建地图

第一步：启动工程页右上角选择【新建地图】

![](https://u5-creator.s3.game.163.com/manual/assets/newproject.BPF8PK8c.png)

第二步：点击新建之后会弹出新建地图模版选择窗口，点击想要新建的地图模版点击【创建】

![](https://u5-creator.s3.game.163.com/manual/assets/newmap.D-eP7cdD.png)

第三步：点击创建后会弹出【创建地图】窗口，输入【项目名称】即为地图名称，点击【创建】，就可以跳转到新地图的编辑界面了。

![](https://u5-creator.s3.game.163.com/manual/assets/createmap.5TG5vb8b.png)

也可以在地图编辑界面左上角的文件栏选择新建地图进行创建。

![](https://u5-creator.s3.game.163.com/manual/assets/newfile.BAqbEYpQ.png)
