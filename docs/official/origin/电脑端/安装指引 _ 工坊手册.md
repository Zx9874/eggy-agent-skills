# 蛋仔PC编辑器安装指引

1. 下载并启动网易发烧游戏客户端；

>>> [获取网易发烧游戏](https://fever.163.com/?from=nietop)

2. 在商店中找到蛋仔派对游戏，点击获取后在`我的游戏`中下载并安装；

   ![下载游戏](https://u5-creator.s3.game.163.com/manual/assets/downloadgame.JV98MQ47.png)
3. 安装完成后，切换版本到`蛋仔派对编辑器`即可进入PC版本编辑器； ![打开编辑器](https://u5-creator.s3.game.163.com/manual/assets/pc_entry.EOYxhqZl.png)
4. 进入编辑器后登录游戏账号，登录成功会自动同步该账号手机端的地图草稿，在PC编辑器上传到云端的草稿也可以同步到移动端。

## 安装配置要求

**最低配置**

系统：Win10(版本19H2 内部版本18362)

空间：20GB可用存储空间

内存：8G内存

CPU：Intel CPU Core i5-8500 / AMD CPU Ryzen 5600G

GPU：不支持集成显卡，最低NVIDIA GTX 1050ti 或 同等级别独立显卡

**推荐配置**

系统：Win10(版本19H2 内部版本18362或更高)/Win11

空间：30GB可用存储空间，推荐使用ssd固态硬盘

内存：16G内存

CPU：Intel CPU Core i7-12700 / AMD CPU R7 5700X

GPU：推荐使用N卡，NVIDIA GTX 2060 或 同等级别独立显卡

## 卸载流程

在网易发烧游戏客户端游戏界面点击图示按钮，根据指引进行卸载即可。

![卸载编辑器](https://u5-creator.s3.game.163.com/manual/assets/uninstallgame.CaFYLDep.png)
