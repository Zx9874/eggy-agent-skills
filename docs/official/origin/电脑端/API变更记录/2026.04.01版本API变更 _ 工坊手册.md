## 新增

### GameAPI.create\_obstacle\_with\_anim

名称：带动效创建组件

方法：GameAPI.create\_obstacle\_with\_anim(\_anim\_type, \_u\_key, \_pos, \_duration, \_intensity, \_role, \_rotation, \_scale)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_anim\_type | Int | 动效类型 |
| \_u\_key | ObstacleKey | 组件编号 |
| \_pos | Point3 | 创建坐标 |
| \_duration | Fixed | 动画时长 |
| \_intensity | Fixed | 效果系数 |
| \_role | Role | 所属玩家 |
| \_rotation | Quaternion | 旋转 |
| \_scale | Vector3 | 缩放 |

#### 返回：

Obstacle 创建出的组件

### GameAPI.destroy\_obstacle\_with\_anim

名称：带动效销毁组件

方法：GameAPI.destroy\_obstacle\_with\_anim(\_anim\_type, \_obstacle, \_duration, \_intensity)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_anim\_type | Int | 动效类型 |
| \_obstacle | Obstacle | 目标组件 |
| \_duration | Fixed | 动画时长 |
| \_intensity | Fixed | 效果系数 |

### Role.set\_unit\_visible -> Role.set\_unit\_visible

#### 旧版本

* 名称：设置单位对玩家可见性
* 方法：Role.set\_unit\_visible(\_unit, \_is\_visible) | 参数 | 类型 | 说明 | | :--- | :--- | :--- | | \_unit | Unit | 单位 | | \_is\_visible | Bool | 是否显示 |

* 名称：设置单位对玩家可见性
