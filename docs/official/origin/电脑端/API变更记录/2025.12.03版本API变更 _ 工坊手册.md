## 新增

### Creature.set\_dragged\_plane\_type

名称：设置生物拖动平面

方法：Creature.set\_dragged\_plane\_type(\_value)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_value | PlaneType | 拖动平面 |

### GlobalAPI.get\_point\_to\_line\_perpendicular\_point

名称：获取点到直线的垂线交点

方法：GlobalAPI.get\_point\_to\_line\_perpendicular\_point(\_point\_1, \_point\_2, \_point\_3)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_point\_1 | Vector3 | 点1 |
| \_point\_2 | Vector3 | 点2 |
| \_point\_3 | Vector3 | 点3 |

#### 返回：

Vector3 交点坐标

### GlobalAPI.get\_lines\_intersection\_point\_on\_plane

名称：获取两条直线在指定平面的交点

方法：GlobalAPI.get\_lines\_intersection\_point\_on\_plane(\_point\_1, \_point\_2, \_point\_3, \_point\_4, \_value, \_plane\_type)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_point\_1 | Vector3 | 点1 |
| \_point\_2 | Vector3 | 点2 |
| \_point\_3 | Vector3 | 点3 |
| \_point\_4 | Vector3 | 点4 |
| \_value | Fixed | 校正值 |
| \_plane\_type | PlaneType | 平面 |

#### 返回：

Vector3 交点坐标
