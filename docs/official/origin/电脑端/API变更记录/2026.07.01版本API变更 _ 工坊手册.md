## 新增

### GameAPI.create\_editable\_image

名称：创建可编辑图片

方法：GameAPI.create\_editable\_image(\_width, \_height)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_width | Fixed | 宽 |
| \_height | Fixed | 高 |

#### 返回：

ImageKey 可编辑图像

### GameAPI.destroy\_editable\_image

名称：销毁可编辑图片

方法：GameAPI.destroy\_editable\_image(\_image\_key)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_image\_key | ImageKey | 可编辑图像 |

### GameAPI.apply\_editable\_image\_to\_unit

名称：将可编辑图片应用为单位模型贴图

方法：GameAPI.apply\_editable\_image\_to\_unit(\_unit, \_image\_key)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_unit | Unit | 单位 |
| \_image\_key | ImageKey | 可编辑图像 |

### GameAPI.blit\_editable\_image

名称：将可编辑图片内容拷贝到另一张可编辑图片

方法：GameAPI.blit\_editable\_image(\_src\_image\_key, \_dst\_image\_key)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_src\_image\_key | ImageKey | 源图像 |
| \_dst\_image\_key | ImageKey | 目标图像 |

### GameAPI.clear\_editable\_image

名称：清空可编辑图片(填充透明)

方法：GameAPI.clear\_editable\_image(\_image\_key)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_image\_key | ImageKey | 可编辑图像 |

### GameAPI.paint\_brush\_world

名称：在单位模型表面绘制一笔球形笔刷(世界坐标)

方法：GameAPI.paint\_brush\_world(\_unit, \_image\_key, \_point, \_radius, \_color)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_unit | Unit | 单位 |
| \_image\_key | ImageKey | 可编辑图像 |
| \_point | Vector3 | 世界坐标点 |
| \_radius | Fixed | 笔刷半径 |
| \_color | Color | 笔刷颜色 |

### GameAPI.fill\_editable\_image

名称：用纯色填充可编辑图片

方法：GameAPI.fill\_editable\_image(\_image\_key, \_color)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_image\_key | ImageKey | 可编辑图像 |
| \_color | Color | 颜色 |
