# API变更说明

## 版本号

版本 20260722

## 发布日期

2026-07-22

## 概述

新增三个商城道具相关的全局触发事件，用于监听指定道具被带入游戏、被消耗、被购买。

---

## 新增

### EVENT.SPEC\_COMMODITY\_BRING\_INTO\_GAME

名称：指定道具被带入游戏

事件主体：Default 多类型

方法：LuaAPI.global\_register\_trigger\_event({EVENT.SPEC\_COMMODITY\_BRING\_INTO\_GAME, \_commodity\_id}, \_callback)

#### 注册参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_commodity\_id | UgcCommodity | 商城道具 |

#### 回调参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| camp\_role\_owner | Role | 携带道具的玩家 |

### EVENT.SPEC\_COMMODITY\_CONSUME

名称：指定道具被消耗

事件主体：Default 多类型

方法：LuaAPI.global\_register\_trigger\_event({EVENT.SPEC\_COMMODITY\_CONSUME, \_commodity\_id}, \_callback)

#### 注册参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_commodity\_id | UgcCommodity | 商城道具 |

#### 回调参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| commodity\_id | UgcCommodity | 商城道具 |
| consume\_num | Int | 使用道具的数量 |
| consume\_role | Role | 使用道具的玩家 |

### EVENT.SPEC\_COMMODITY\_PURCHASE

名称：指定道具被购买

事件主体：Default 多类型

方法：LuaAPI.global\_register\_trigger\_event({EVENT.SPEC\_COMMODITY\_PURCHASE, \_commodity\_id}, \_callback)

#### 注册参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_commodity\_id | UgcCommodity | 商城道具 |

#### 回调参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| commodity\_id | UgcCommodity | 商城道具 |
| purchase\_role | Role | 购买道具的玩家 |
| purchase\_num | Int | 购买数量 |
