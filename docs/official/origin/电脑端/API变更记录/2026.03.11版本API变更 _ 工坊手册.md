## 新增

### DebugAPI.draw\_line

名称：绘制线段

方法：DebugAPI.draw\_line(\_start\_pos, \_end\_pos, \_color, \_duration)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_start\_pos | Vector3 | 起点 |
| \_end\_pos | Vector3 | 终点 |
| \_color | Color | 颜色 |
| \_duration | Fixed | 时长 |

### GameAPI.create\_vehicle

名称：创建载具

方法：GameAPI.create\_vehicle(\_vehicle\_key, \_pos, \_direction, \_role)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_vehicle\_key | VehicleKey | 载具编号 |
| \_pos | Point3 | 位置 |
| \_direction | Point3 | 朝向 |
| \_role | Role | 所属玩家 |

#### 返回：

Vehicle 载具

### GameAPI.destroy\_ugc\_vehicle

名称：删除载具

方法：GameAPI.destroy\_ugc\_vehicle(\_unit)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_unit | Vehicle | 载具 |

### GameAPI.get\_driving\_vehicle
