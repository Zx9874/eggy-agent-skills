## 新增

### Unit.model\_play\_anim

名称：播放动画

方法：Unit.model\_play\_anim(\_anim\_name, \_start\_time, \_is\_loop, \_play\_speed)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_anim\_name | Str | 动画名 |
| \_start\_time | Fixed | 开始时间 |
| \_is\_loop | Bool | 是否循环 |
| \_play\_speed | Fixed | 播放速度 |

方法：GameAPI.play\_link\_sfx(\_sfx\_key, \_unit, \_from\_socket\_name, \_target\_unit, \_target\_socket\_name, \_duration)

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_sfx\_key | SfxKey | 特效编号 |
| \_unit | Unit | 起点单位 |
| \_from\_socket\_name | Str | 起点节点 |
| \_target\_unit | Unit | 终点单位 |
| \_target\_socket\_name | Str | 终点节点 |
| \_duration | Fixed | 持续时间 |
