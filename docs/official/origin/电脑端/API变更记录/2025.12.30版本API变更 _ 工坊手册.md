## 新增

### Role.get\_archive\_sheetid

名称：获取表格存档

方法：Role.get\_archive\_sheetid(\_key)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_key | Archive | 存档 |

#### 返回：

SheetID 表格id

### GameAPI.create\_obstacle\_from\_geometry

名称：创建一个组件（自定义几何）

方法：GameAPI.create\_obstacle\_from\_geometry(\_u\_key, \_pos, \_rotation, \_scale, \_role, \_geometry\_path)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_u\_key | UnitKey | 组件编号 |
| \_pos | Vector3 | 位置 |
| \_rotation | Quaternion | 旋转 |
| \_scale | Vector3 | 缩放 |
| \_role | Role | 所属玩家 |
| \_geometry\_path | Str | 自定义几何体路径 |

#### 返回：

Obstacle 创建的组件

### Role.set\_archive\_sheetid

名称：设置表格存档

方法：Role.set\_archive\_sheetid(\_key, \_val)

#### 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| \_key | Archive | 存档 |
| \_val | SheetID | 表格id |
