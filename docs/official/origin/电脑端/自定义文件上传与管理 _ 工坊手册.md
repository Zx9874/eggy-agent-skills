# 自定义文件上传与管理

PC编辑器支持玩家导入本地资源并应用到地图中，玩家使用特效编辑器等制作的自定义特效也会作为自定义文件保存，你可以使用文件管理功能来上传和管理账号上的自定义文件。

## 功能入口

在pc编辑器顶部导航可以找到文件管理功能入口。

> 该功能目前只对历史工匠点达到10000以上的玩家开放

![](https://u5-creator.s3.game.163.com/manual/assets/entry.DKsJCC0w.png) PC编辑器与手机编辑器的文件管理功能基本一致，能够上传和管理自定义图片、音频等资源。上传的文件将跟随账号存储，在手机编辑器也可以使用。

> 自定义模型的导入功能为PC独有。

## 功能界面

文件管理功能界面如图，左侧导航栏根据文件类型进行分页管理，第一个分类为当前地图草稿内使用的自定义文件；左半部分为文件列表，右半部分为选中文件预览区域。 ![](https://u5-creator.s3.game.163.com/manual/assets/interface.BQjXvbuH.jpg)

### 云端存储容量

作者在云端能保存的文件容量根据历史最高工匠点数有所差异，当前容量限制为：

1万~10万点：200MB

10万点~100万点：500MB

100万点以上：2000MB

文件数量限制在一万个以内。

地图额外文件

额外文件指代一张地图中需要玩家额外下载的文件，包括应用在地图草稿中的文件管理里玩家上传的自定义文件以及地图制作过程中存储的自定义文件如：使用动作编辑器制作的自定义动作；使用拼贴画板制作的自定义贴图等。

和文件管理不同，额外文件里的自定义文件是跟随地图草稿存储，而文件管理的自定义文件是跟随账号存储。前者主要面向玩家体验；后者服务于作者编辑地图需要。

## 自定义文件使用指南

将根据自定义文件的类型介绍其使用场景

### 自定义图片

上传的自定义图片支持在编辑界面、物品、任务等系统使用，可以作为界面素材或者组件图标使用。

地图封面拍摄会限制自定义图片的显示，避免虚假封面现象。

上传标准：

* 单张图片不大于3MB，尺寸不大于1920\*1080
* 仅支持png\jpg\jpeg格式

### 自定义音频

上传的自定义音频支持在音效播放器和蛋码中使用。

上传标准：

* 单个音频文件大小不超过1MB，时长不超过60秒
* 仅支持mp3和wav格式
* 上传的音频不能包含封面信息

> 温馨提示：
>
> 出现-203错误码提示一般都是音频格式存在问题，可以使用格式工厂等工具转换音频格式。

### AI朗读

保存使用【音频生成】功能生成的AI配音文件，通常用于剧情对话和剧情动画中，也可以作为普通音频进行使用。

### 自定义材质

自定义材质\纹理可以上传贴图并导入材质后作为组件皮肤使用。

> 添加纹理后，要在文件管理里右键选择导入，才能显示在地图组件皮肤列表中。

渲染模式：

可以选择通用的通用材质，或四换色材质。

| 模式 | 效果 |
| --- | --- |
| 通用材质 | 使用贴图的颜色即为效果的颜色，不可进行换色。 |
| 四换色材质 | 通道为MaskColor1换色遮罩，G通道为MaskColor2换色遮罩，B通道为MaskColor3换色遮罩（MaskColor0为底色）；A通道为细节法线遮罩。 |

剔除模式：

剔除模式决定哪些面在渲染时被绘制。

| 模式 | 效果 |
| --- | --- |
| 不删除 | 模型的每一面都会被绘制，可能会导致性能下降，尤其是在复杂场景中。 |
| 正面剔除 | 只渲染背面面。朝向相机的面不会被绘制，这可以减少渲染负担，提高性能。 |
| 背面剔除 | 只渲染正面面。这是最常用的剔除模式，因为大多数情况下，模型的内部面是不可见的，仅需渲染可见的外部面，从而提高渲染效率。 |

贴图模式：

透明模式会决定该纹理在使用后的透明效果

| 模式 | 效果 |
| --- | --- |
| 不透明 | 此模式用于完全不透明的材质，所有内容都会被渲染。 |
| 透明 | 基础的透明，只会有透明和不透明的区分。 |
| 混合透明 | 支持有更细腻的透明度变化，但相对的性能开销会更大。 |
