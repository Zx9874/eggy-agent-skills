# 高级特性

这部分内容主要面向高级开发者。如果您需要进一步拓展地图表现力、定制玩家操作，或优化运行性能，可以参考以下章节。

* [高级特性：并行计算](https://u5-creator.s3.game.163.com/manual/pc_md/lua/lua_advance_parallel.html)：使用辅助计算线程处理复杂的纯计算任务。
* [高级特性：创建可变形组件](https://u5-creator.s3.game.163.com/manual/pc_md/lua/lua_advance_geometry.html)：在运行时动态创建曲线、曲面、圆环等几何体。
* [高级特性：玩家操作台（Terminal）](https://u5-creator.s3.game.163.com/manual/pc_md/lua/lua_advance_terminal.html)：读取精细输入、相机和设备信息，并向游戏世界线提交自定义操作。
