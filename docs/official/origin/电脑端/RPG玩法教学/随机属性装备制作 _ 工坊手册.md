# 随机属性装备制作

## 引言

在本教程中，我们将详细介绍如何创建一个灵活且可扩展的物品系统，包括物品定义、随机属性生成、装备继承和数据恢复的步骤。通过这些步骤，你可以为游戏中的物品设计出丰富的功能和特性。

## 第一步：打开物品商店并设置物品规则

1. 从菜单栏中访问物品商店。
2. 启用物品规则。

![](https://u5-creator.s3.game.163.com/manual/assets/101.Ds5bQg8B.png)

## 第二步：基础预设制作

1. 在物品预设中创建你想要的预设类型。

![](https://u5-creator.s3.game.163.com/manual/assets/102.C0WgejJB.png)

2. 使用标签来限制物品佩戴的部位，并将物品归类到不同类型的背包中。

![](https://u5-creator.s3.game.163.com/manual/assets/103.CXa6kYMb.png)![](https://u5-creator.s3.game.163.com/manual/assets/104.CfqGGb2P.png)

## 第三步：通过表格和蛋码实现多样化预设

1. 在表格中配置物品的名称、描述、部位和图标。

![](https://u5-creator.s3.game.163.com/manual/assets/105.D1EonN4O.png)

2. 在物品掉落和创建时，随机选取表中的物品序号，根据内容重新设置物品的基础信息（名称、描述、图标）。

![](https://u5-creator.s3.game.163.com/manual/assets/106.C2K5q4d6.png)

## 第四步：随机属性生成

1. 使用表格编辑器，在原有装备信息基础上新增一列主属性。这一列代表装备在获取时需赋予的核心属性。
2. 创建主属性表，以物品等级为第一列，后续内容为该等级下不同品质的属性数值范围（例如，设定为 5 档品质）。
3. 根据物品等级和品质制作出随机品质数值的装备，引入一个 0~1 的随机数作为数值的额外变化倍率。
4. 将品质和额外变化倍率存储为物品自定义属性。在获得和失去物品时，利用主属性和自定义属性的系数动态修改装备的效果。

![](https://u5-creator.s3.game.163.com/manual/assets/107.CAkJEKLa.png)

## 第五步：装备继承

1. 定义一个字符串格式来存储装备信息，包括装备 ID、品质、属性浮动和装备所在槽位。例如：`10;2;0.7;3` 表示 ID 为 10，品质为 2，属性浮动为 0.7，装备在背包的第 3 号位。
2. 注意，蛋仔编辑器的字符串存储限制为最大 25600 个字节。
3. 为了提高存储效率，将品质与属性浮动合并成新格式，例如 `10;2.7;3`（品质为正整数，属性浮动在 0~1 之间）。

## 数据恢复

在玩家进入游戏后，根据玩家的游玩进度，进行数据的解析和恢复

## 结论

通过本教程，你已经成功创建了一个灵活且可以继承的物品系统。你可以根据需要进一步扩展和优化系统，提升玩家体验。
